# 40003 LCD 출력 표시값 변경 결과

- 40003/PDU `0x0002`를 Supervisor 최대 범위에서 LCD 현재 출력 숫자(W 또는 %)로 변경.
- LCD가 출력한 숫자를 보관하고 `MenuScreen_GetDisplayedOutput()`로 반환한다.
  PLC 읽기가 표시 안정화 필터를 다시 실행하지 않아 통신 빈도에 영향을 받지 않는다.
- W/% 및 통신 중 VR 수동 미리보기의 표시 숫자를 그대로 반환한다.
  출력 표시가 없는 대기/설정/오류 화면과 부팅 화면은 0이다.
- FC03으로 읽으며 FC06/FC10 쓰기는 기존 읽기 전용 정책으로 거부한다.
- 기존 LCD 계산, 40002 쓰기/읽기 및 40004 전류 읽기는 유지했다.
  변경 전 소스와 비교하여 LCD 산술 및 Register 쓰기 경로 보존을 확인했다.
- 최대 1200W의 기존 표시 간격은 12W다. 66%=792W, 67%=804W이며 PLC도
  해당 숫자를 읽는다. 800W 단위 정밀도나 출력 제어 알고리즘을 새로 추가하지 않았다.

## 검증

- Release Build 성공: `release_build.log`.
- `test_host` 전체 8개 스크립트 통과: `test_host.log`.
- 기본 계산 시험 37개 통과. LCD 표시 상태 전달, 읽기 전용, 기존 전류/출력
  지령 유지 및 통신 예제 CRC의 소스 계약 검사 포함.
- 기존 RWX LOAD segment 링커 경고는 남아 있으며 이번 변경에서 추가된 경고가 아니다.
- UPDATE HEX checksum/주소 범위/Release BIN 일치 확인. 설정 Page 미포함.
- PLC 가이드 v1.5 DOCX/PDF 생성. PDF 14쪽의 모든 원본 문단과 요청 프레임을
  텍스트 추출로 대조하고 레지스터맵/40003 설명 페이지를 이미지로 확인했다.
- 전용 BAT의 고정 SHA-256, 출력 정지 확인, Writing/Verify/Reset/Run 옵션 확인.
- ZIP 내부 파일과 원본 파일의 바이트 일치 확인: `package_validation.log`.
- 보드 업로드 및 PLC 실제 통신 시험은 수행하지 않았다.
