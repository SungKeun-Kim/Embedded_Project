# LCD 출력값과 CT 전류 읽기 업데이트 (2026-10-16)

## 변경 내용

| PLC 주소 | PDU 주소 | 기능 |
| --- | --- | --- |
| 40002 | `0x0001` | 기존 출력 지령 0~500 읽기/쓰기 유지 |
| 40003 | `0x0002` | LCD 현재 출력 숫자(W 또는 %) 읽기 전용 |
| 40004 | `0x0003` | 기존 CT 실측 입력전류(A ×100) 읽기 유지 |
| 40006 | `0x0005` | 운전 상태, `0000`=정지 / `FF00`=운전 |

40003은 Supervisor의 최대 W가 아니라 현재 LCD에 표시한 숫자다.
화면이 800W이면 800, 65%이면 65를 읽는다. W 값은 볼륨 출력 지령의 표시
환산값이며 실제 전력 측정값은 아니다. CT 전류는 40004에서 별도로 읽는다.

## REMOTE 운전 중 PLC 읽기

1. Supervisor에서 원하는 최대 W 또는 PERCENT를 설정하고 메인 화면으로 나온다.
2. RUN_SW=OFF, PLC Local Lock=OFF 상태에서 REMOTE를 ON한다.
3. 전면 PWM 볼륨을 조절하고 LCD의 PL 숫자를 확인한다.
4. PLC에서 FC03, 시작 주소 2(0-based), 수량 1로 읽는다.
5. 수신값을 그대로 표시한다. W/% 단위는 본체 설정에 맞춘다.

Slave ID=1 읽기 요청: `01 03 00 02 00 01 25 CA`.
주소 0부터 D100에 연속 수신한다면 D102=LCD 출력, D103=전류(A ×100)다.
읽기 때문에 Local Lock을 켤 필요는 없다.

LCD의 기존 표시 간격은 유지한다. 최대 1200W 설정에서는 정수 % 환산으로
66%=792W, 67%=804W가 되므로 정확히 800W에 맞춰지지 않을 수 있다.
이때 PLC도 화면과 동일한 792 또는 804를 읽는다.

메인 화면 갱신은 약 200 ms다. 출력 숫자가 없는 대기/설정/오류 화면은
40003=0이다. 정지 상태에서도 PL을 표시하는 화면이면 그 숫자를 반환하므로
실제 운전 여부는 40006으로 확인한다. PLC 운전 중 볼륨 수동 인계로
`VR: nn% MANUAL`이 약 1.5초 표시될 때에는 40003도 그 % 숫자 nn을 반환한다.

## 업데이트 방법

1. ZIP을 풀고 BAT와 `US_MAIN_BOARD_UPDATE_V1.2.0.hex`를 같은 폴더에 둔다.
2. STM32CubeProgrammer가 설치된 PC에 ST-LINK와 보드를 연결한다.
3. 초음파 출력을 STOP하고 REMOTE 및 PLC RUN 명령을 OFF로 둔다.
4. CubeProgrammer GUI를 종료하고
   `program_update_V1.2.0_LCD40003_CURRENT40004_20261016.bat`을 실행한다.
5. 출력 정지를 확인한 뒤 `Y`를 누른다. 취소하려면 `N`을 누른다.
6. Writing, Verify, Reset/Run 성공과 마지막 `[PASS]`를 확인한다.
7. 기존 설정 유지 여부와 REMOTE 운전 시 LCD/PLC 숫자 일치를 확인한다.

BAT는 이번 HEX의 SHA-256을 검사한다. 다른 HEX로 교체하면 업로드를 거부한다.
Full chip erase를 사용하지 않으며 Factory HEX는 포함하지 않는다.
설정 Page `0x0800F800`을 제외한 UPDATE HEX로 기존 설정을 보존한다.
Programmer를 찾지 못하면 STM32CubeProgrammer를 설치하거나
`STM32_PROGRAMMER_CLI` 환경변수에 CLI 실행 파일의 전체 경로를 지정한다.

## 검증 범위

Release Build와 `test_host` 전체 시험을 통과했다. 이전 배포본의 40004 전류
읽기도 포함한다. 이 배포 작업에서는 실제 보드 업로드와 PLC 실기 시험을
수행하지 않았다. 상세 통신 사양은 함께 제공한 PLC 사용자 가이드 v1.5를 참고한다.
