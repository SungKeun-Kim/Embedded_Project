# 과전류 8 A 업데이트 완료 — 2026-10-14

빌드 구분: `V1.2.0_GDT200us_OC8A_20261014`. 펌웨어 기본 버전과 현장 HEX 파일명은 V1.2.0 유지.

## 변경 내용

- `include/params.h`: `CT_OVERCURRENT_LIMIT_CENTIAMP`를 700에서 800으로 변경.
- LCD와 동일한 1초 평균 RMS 전류가 8.00 A 이상으로 약 5초 지속되면 `OVER CURRENT` 보호 정지. 200 ms마다 판정하며 상한 미만이면 누적 횟수를 초기화한다.
- GDT 일반 정지의 200 us 유지시간과 100 us 동기화 제한시간은 유지했다. 사용자의 반복 시험에서 효과가 확인되었으나 시간을 더 늘리면 남은 잔상이 제거된다는 근거는 없어 변경하지 않았다.
- 계측 환산과 정상 계측범위 7 A 정규화 기준은 유지했다. 보호 판정은 정규화 값이 아닌 제한되지 않은 RMS 전류 값을 사용한다.
- 현행 안전/회로/PLC 문서와 과전류 경계값 시험을 8 A에 맞췄다. 이전 배포 이력 문서는 당시 값을 유지한다.

## 검증 결과

- Release Build 성공. 기존 LOAD segment RWX 링커 경고는 남아 있다.
- `test_host` 전체 8개 스크립트 통과(기본 논리 37/37 포함).
- 7.99 A 지속 시 미정지, 8.00 A 24회 미정지/25회 정지, 이전 7 A 미정지 및 상한 미만에서 누적 초기화 모델 검증 통과.
- HEX checksum/주소 검사 통과. Release HEX와 배포 HEX 일치.
- HEX 범위 `0x08000000..0x0800C7CF`; 설정 페이지 `0x0800F800..0x0800FFFF` 제외.
- 사용자가 출력 STOP 및 REMOTE·PLC RUN OFF 유지를 확인한 후 ST-LINK 업로드.
- ST-LINK `3B130913A218303030303032`: Writing/Verify 성공, Software Reset 및 Core run 성공.
- 설정 페이지 2048 bytes 업로드 전후 동일. 전체 지우기 및 Factory HEX 미사용.
- HotPlug 정지 상태 확인: TIM3 CCMR1=`0x4800`, CCR2=`0`, HRTIM OENR=`0`, GPIOA IDR=`0x4C04`/ODR=`0`. PA7/PA8/PA9/PA15 LOW.

실제 8 A 부하에서의 보호 동작 및 정지 과도 파형은 이번 작업에서 측정하지 않았다. 회로 참조 문서상 8 A는 ADC 입력의 보수적 여유가 작아지는 구간이므로 실제 전류계와 LCD 값의 일치 여부는 장비에서 확인해야 한다.
