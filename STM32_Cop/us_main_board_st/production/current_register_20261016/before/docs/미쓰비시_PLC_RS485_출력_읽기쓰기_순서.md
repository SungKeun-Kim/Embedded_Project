# 미쓰비시 PLC RS485 출력 읽기·쓰기 설명서

작성일: 2026-10-16 / 문서 버전: 1.0

대상: 현재 작업 폴더의 STM32 초음파 제어 보드 펌웨어. 미쓰비시 PLC의 CPU 및 RS485 모듈 모델은 미확정입니다. 이 문서는 보드에 보내야 할 Modbus 요청과 확인 순서를 설명합니다. 실제 PLC 포트 설정 화면, 통신 명령의 인수 및 완료 비트는 해당 모델의 매뉴얼에 맞춰 지정해야 합니다. 실기 통신 시험은 수행하지 않았습니다.

## 1. 먼저 알아둘 내용

PLC가 요청을 보내는 Master이고, 초음파 보드가 응답하는 Slave입니다. PLC 포트는 Modbus RTU Master로 사용합니다. RS485 배선만 연결하거나 보드에 읽기 요청을 보내는 것만으로는 PLC 출력 제어권이 생기지 않습니다. 출력 쓰기 전에 Local Lock을 설정해야 합니다.

이 보드는 Holding Register를 사용합니다. 읽기는 FC03, 한 개 쓰기는 FC06을 사용합니다. 아래의 ON/OFF 값도 Coil 명령이 아니라 FC06으로 Holding Register에 쓰는 값입니다.

| 구분 | 값 | 의미 |
| --- | --- | --- |
| 출력 설정값 | 0~500 | 크기를 지정하는 숫자 |
| 제어 ON | 0xFF00 = 65280 | Lock ON 또는 RUN ON |
| 제어 OFF | 0x0000 = 0 | Lock OFF 또는 RUN OFF |

제어 ON에 숫자 1을 쓰면 거부됩니다. 0xFF00을 사용하십시오. 출력 설정값과 ON/OFF 값은 서로 다른 용도입니다.

**출력 설정값 0은 정지 명령이 아닙니다.** 운전 중 설정값 0은 PA7 PWM 지령 5%에 해당하고, LCD에도 기본적으로 PL: 5%로 표시됩니다. 정지는 RUN 레지스터에 0을 써야 합니다.

## 2. 연결 및 통신 설정

1. 초음파 출력을 정지한 상태에서 PLC와 보드의 RS485 배선을 준비합니다.
2. PLC CPU 및 통신 모듈이 Modbus RTU Master 기능을 지원하는지 해당 모델 매뉴얼에서 확인합니다.
3. 보드 RS485 옵션보드를 장착합니다. 펌웨어가 옵션보드를 감지하지 못하면 읽기에도 응답하지 않습니다.
4. PLC 모듈 매뉴얼의 2선식 RS485 배선도에 따라 데이터선과 신호 기준선을 연결합니다. A/B 또는 SDA/SDB/RDA/RDB 등의 단자 이름만으로 극성을 추정하지 마십시오. 구체적인 단자 연결은 모듈 모델 확인 후 결정합니다.
5. 보드의 RUN_SW를 OFF로 놓고 LCD를 메인화면으로 둡니다. 처음 시험할 때 외부 REMOTE 입력도 OFF로 둡니다.
6. PLC와 보드의 통신 조건을 아래와 같이 일치시킵니다.

| 항목 | 보드 기본값 / PLC 설정 |
| --- | --- |
| 프로토콜 | Modbus RTU |
| PLC 역할 / 보드 역할 | Master / Slave |
| Slave ID | 기본 1. 보드에 저장된 실제 주소 사용 |
| Baud rate | 기본 9600 bps. 보드의 실제 설정과 일치 |
| Data / Parity / Stop | 8 bit / Even / 1 bit, 즉 8-E-1 |
| 응답 대기시간 | 500 ms를 초기 설정값으로 사용하고 현장에서 조정 |
| 주기 읽기 | 100 ms 이상을 초기 간격으로 사용 |

보드 메뉴에서 선택 가능한 속도는 9600, 19200, 38400, 57600, 115200 bps입니다. 주소와 속도는 보드에 저장된 설정을 우선합니다. 응답 대기시간과 읽기 주기는 PLC 프로그램의 권장 시작값이며, 펌웨어가 강제하는 설정값은 아닙니다.

한 요청의 정상 응답 또는 오류·Timeout 처리가 끝난 뒤 다음 요청을 보냅니다. 이 설명서에서는 응답 확인이 가능한 개별 Slave ID를 사용하며, 주소 0의 Broadcast는 사용하지 않습니다.

## 3. 주소를 입력하는 방법

아래 표의 PDU 주소는 실제 통신에 들어가는 0부터 시작하는 주소입니다. PLC의 통신 기능이 40001 방식 주소를 요구하는 경우에만 오른쪽 표기를 사용합니다. 두 표기를 혼용하지 마십시오.

| 기능 | PDU 주소(16진수) | PDU 주소(10진수) | 40001 방식 | 접근 |
| --- | --- | --- | --- | --- |
| 출력 설정값 | 0x0001 | 1 | 40002 | 읽기/쓰기, 0~500 |
| LCD 표시 범위 | 0x0002 | 2 | 40003 | 읽기, 100 또는 설정 최대 W |
| Local Lock | 0x0004 | 4 | 40005 | 읽기/쓰기, 0 또는 0xFF00 |
| RUN 상태/명령 | 0x0005 | 5 | 40006 | 읽기/쓰기, 0 또는 0xFF00 |
| 외부 REMOTE 입력 | 0x0006 | 6 | 40007 | 읽기, 0 또는 0xFF00 |
| 에러 상태/Reset | 0x0008 | 8 | 40009 | 읽기, 정지 중 0xFF00 쓰기로 Reset |
| 에러 코드 | 0x0009 | 9 | 40010 | 읽기 |
| 물리 RUN_SW 상태 | 0x000A | 10 | 40011 | 읽기, 0=OFF |
| 통신 제어 가능 상태 | 0x000B | 11 | 40012 | 읽기, 0xFF00=가능 |

출력값은 측정 전력이나 측정 전류가 아니라 MCU가 보유한 출력 지령값입니다. 정지 중에도 0이 아닌 설정값을 읽을 수 있습니다. 운전 여부는 반드시 RUN 상태로 확인합니다.

## 4. 처음 접속해서 출력을 읽는 순서

### 4.1 연결 확인

FC03으로 시작 주소 0x0010, 수량 3을 읽습니다. 기본 설정 보드의 응답 데이터는 다음과 같습니다.

| 주소 | 기본 응답 | 의미 |
| --- | --- | --- |
| 0x0010 | 1 | Slave ID 1 |
| 0x0011 | 0 | Baud index 0 = 9600 bps |
| 0x0012 | 1 | Even parity |

Baud index 0/1/2/3/4는 각각 9600/19200/38400/57600/115200 bps입니다. 여기서 읽는 Baud 값은 실제 속도 숫자가 아니라 인덱스입니다. 통신이 성공해야 읽을 수 있으므로 속도를 자동 탐색하는 요청은 아닙니다.

### 4.2 현재 출력 설정값 읽기

FC03으로 시작 주소 0x0001, 수량 1을 읽습니다. 예를 들어 응답값이 250이면 현재 출력 지령은 250입니다. 출력 설정값만 읽을 때는 Local Lock이 필요하지 않습니다.

### 4.3 상태를 함께 읽기

FC03으로 시작 주소 0x0000, 수량 12를 읽습니다. 아래 수신 버퍼 예처럼 순서대로 배치됩니다. D100~D111은 설명을 위한 PLC 메모리 배치 예시이며 실제 프로그램의 빈 영역을 사용하십시오.

| PLC 수신 위치 예 | 보드 주소 | 내용 |
| --- | --- | --- |
| D100 | 0x0000 | 현재 주파수, 0.1 kHz 단위 |
| D101 | 0x0001 | 출력 설정값, 0~500 |
| D102 | 0x0002 | LCD 표시 범위 |
| D103 | 0x0003 | Sweep 운전 주파수, 그 외 0 |
| D104 | 0x0004 | Local Lock |
| D105 | 0x0005 | RUN 상태 |
| D106 | 0x0006 | 외부 REMOTE 입력 상태 |
| D107 | 0x0007 | 물리 SWEEP 스위치 상태 |
| D108 | 0x0008 | 에러 상태 |
| D109 | 0x0009 | 에러 코드 |
| D110 | 0x000A | 물리 RUN_SW 상태 |
| D111 | 0x000B | 통신 제어 가능 상태 |

PDU 주소 0x000F는 정의되어 있지 않습니다. 상태와 통신 설정을 한 번에 읽으려고 0x0000부터 0x0012까지 요청하면 잘못된 주소 오류가 발생합니다. 상태 12개와 통신 설정 3개를 따로 읽으십시오.

## 5. 출력값을 쓰고 운전하는 순서

아래 예시는 출력값 250으로 운전하는 통신 절차입니다. 250은 통신 설명용 숫자이며 설비의 적정 출력값은 현장 운전 조건에 맞춰 정합니다.

### 5.1 제어 가능 상태 확인

상태 읽기 결과에서 RUN_SW=0, 통신 제어 가능 상태=0xFF00인지 확인합니다. 보드 감지, RUN_SW OFF, LCD 메인화면 조건을 모두 만족해야 합니다. 운전 시작 전 에러 상태도 0인지 확인합니다. 통신 제어 가능 상태에는 에러 유무가 포함되지 않으므로 에러는 별도로 확인해야 합니다.

### 5.2 PLC 제어권 확보 — Local Lock ON

FC06으로 주소 0x0004에 0xFF00을 씁니다. 정상 쓰기 응답을 받은 다음 FC03으로 주소 0x0004, 수량 2를 읽어 Lock=0xFF00, RUN=0인지 확인합니다.

Lock이 OFF에서 ON으로 바뀌면 기존 Local/REMOTE 운전이 정지하고 LCD에는 485 COMM과 K-SONICS가 표시됩니다. 현재 가변저항 위치가 초기 출력 설정값으로 인계됩니다. Lock ON 자체는 운전 시작 명령이 아닙니다.

이미 Lock이 ON인 상태에서 같은 Lock ON을 다시 써도 정지하지 않습니다. PLC 재접속 등으로 이미 운전 중이라면 RUN OFF를 별도로 보내고 정지를 확인한 후 설정 절차를 진행하십시오.

### 5.3 출력 설정값 쓰기

FC06으로 주소 0x0001에 250(0x00FA)을 씁니다. 반드시 정상 쓰기 응답을 확인합니다. 허용 범위는 0~500이며, 501 이상은 거부됩니다.

### 5.4 쓴 값 다시 읽어 확인

FC03으로 주소 0x0001, 수량 1을 읽습니다. 응답값이 250과 일치하는지 확인합니다. 불일치 또는 통신 오류라면 운전 시작 단계로 넘어가지 않습니다. 정지 중에는 LCD가 출력 숫자를 숨기므로 PLC 읽기로 확인해야 합니다.

### 5.5 RUN ON

운전 시작 조건이 충족되면 FC06으로 주소 0x0005에 0xFF00을 씁니다. 정상 응답을 받은 뒤 FC03으로 RUN 상태와 에러 상태를 읽습니다. RUN=0xFF00이고 에러=0이어야 운전 상태로 판정합니다.

이때 LCD는 485 ON과 PL 및 설정 주파수를 표시합니다. 출력값 250은 PA7 PWM 지령 52.5%에 해당하며, 퍼센트 표시 모드의 LCD에는 반올림하여 PL: 53%로 표시됩니다. PLC 통신 운전은 보드의 M/S 타이머로 자동 종료되지 않습니다.

### 5.6 운전 중 출력 변경 및 감시

출력을 바꾸려면 주소 0x0001에 새 값(0~500)을 FC06으로 씁니다. 다시 읽어 값이 반영됐는지 확인합니다. 설정값 변경을 위해 RUN ON을 다시 보낼 필요는 없습니다.

운전 중에는 FC03으로 주소 0x0000, 수량 12를 주기적으로 읽어 설정값, Lock, RUN, 에러를 확인합니다. 쓰기 명령은 작업자의 변경 요청 또는 제어 로직의 변경 시점에 보내고, 매 PLC 스캔마다 무조건 반복하지 않습니다.

### 5.7 출력 정지

FC06으로 주소 0x0005에 0x0000을 씁니다. FC03으로 RUN=0인지 확인합니다. Local Lock은 유지되고 LCD는 485 COMM / K-SONICS로 돌아갑니다. 출력 설정값은 남아 있을 수 있습니다.

통신 준비 상태로 계속 대기할 때는 이 상태를 유지합니다. 다음 운전 전에도 설정값과 에러 상태를 확인하십시오.

### 5.8 PLC 제어 종료 — 필요할 때만 Lock OFF

Local 조작으로 넘길 때는 먼저 RUN OFF 및 RUN=0을 확인합니다. 외부 REMOTE 입력도 실제 OFF이고 주소 0x0006 읽기값이 0인지 확인합니다. 그다음 FC06으로 주소 0x0004에 0을 쓰고 Lock=0을 읽어 확인합니다.

Lock 해제 후에는 가변저항과 외부 REMOTE 입력에 따른 제어로 돌아갑니다. REMOTE가 ON이면 보드가 다시 운전할 수 있습니다. Lock 해제 자체를 정지 명령으로 사용하지 마십시오.

## 6. PLC 프로그램용 순서 요약

아래는 통신 요청 순서이며, 특정 미쓰비시 기종에 그대로 붙여 넣는 Ladder 코드는 아닙니다. 각 행은 이전 요청의 완료와 확인 조건을 통과한 뒤 실행합니다.

| 순서 | 요청 | 주소 | 수량/쓰기값 | 다음 단계 조건 |
| --- | --- | --- | --- | --- |
| 1 | FC03 | 0x0010 | 수량 3 | 통신 설정 읽기 성공 |
| 2 | FC03 | 0x0000 | 수량 12 | RUN_SW OFF, 제어 가능, 에러 없음 |
| 3 | FC06 | 0x0004 | 0xFF00 | Lock 쓰기 정상 응답 |
| 4 | FC03 | 0x0004 | 수량 2 | Lock ON, RUN OFF. RUN ON이면 정지 후 재확인 |
| 5 | FC06 | 0x0001 | 250 | 출력 쓰기 정상 응답 |
| 6 | FC03 | 0x0001 | 수량 1 | 읽은 값 250 |
| 7 | FC06 | 0x0005 | 0xFF00 | RUN 쓰기 정상 응답 |
| 8 | FC03 | 0x0000 | 수량 12 | RUN ON, 에러 없음 확인 및 주기 감시 |
| 9 | FC06 | 0x0005 | 0 | 작업 종료 시 정지 명령 |
| 10 | FC03 | 0x0005 | 수량 1 | RUN OFF 확인 |
| 11 | FC03 | 0x0006 | 수량 1 | Local 복귀 시 REMOTE OFF 확인 |
| 12 | FC06 | 0x0004 | 0 | Local 복귀 시 Lock 해제 |
| 13 | FC03 | 0x0004 | 수량 2 | Lock OFF, RUN OFF 확인 |

PLC 프로그램은 요청 실행, 완료 대기, 응답값 검사, 다음 단계 이동을 분리합니다. 완료 응답이 없으면 다음 단계로 진행하지 않습니다. 통신 오류를 RUN OFF로 해석하지 말고 '현재 상태 확인 불가'로 처리합니다. 통신 복구 시에는 상태부터 다시 읽고 운전 재시작을 판단합니다.

## 7. 설정값과 LCD 표시의 관계

| PLC 출력 설정값 | 운전 중 PA7 PWM 지령 | 운전 중 LCD 퍼센트 표시 | PLC 다시 읽기 |
| --- | --- | --- | --- |
| 0 | 5.0% | PL: 5% | 0 |
| 100 | 24.0% | PL: 24% | 100 |
| 250 | 52.5% | PL: 53% | 250 |
| 500 | 100.0% | PL: 100% | 500 |

PA7 PWM 지령의 환산 개념은 5 + 95 × (출력값 / 500) [%]입니다. 실제 펌웨어는 정수 계산을 사용하며, LCD는 먼저 출력값을 정수 퍼센트로 반올림한 뒤 5~100%로 변환하고 다시 정수로 반올림합니다. 따라서 일부 중간값에서는 이 식을 한 번만 반올림한 값과 LCD가 다를 수 있습니다.

W 표시 모드에서는 LCD에 표시할 정수 퍼센트에 설정 최대 W를 곱합니다. 최대 1000W 설정 시 출력값 0은 50W, 출력값 250은 530W로 표시됩니다. 이 W 값은 설정값을 환산한 표시이며 실측 전력이 아닙니다. 현재 Modbus에는 실제 측정 전력·전류 레지스터가 없습니다.

위 표는 통신 운전 중 일반 PL 화면 기준입니다. 정지 중에는 PL 숫자를 숨기고, 가변저항 조작 직후에는 VR MANUAL 화면이 잠시 나타날 수 있습니다.

## 8. 운전 중 알아야 할 보드 동작

- Local Lock 중에는 외부 PA10 REMOTE 입력이 운전을 제어하지 않습니다. 다만 입력 상태 읽기는 가능합니다.
- Local Lock이 모든 현장 조작을 막는 것은 아닙니다. PLC 쓰기 이후 가변저항을 기준점에서 약 5% 이상 움직이면 가변저항 값이 출력 지령으로 반영됩니다. 이후 작은 움직임도 반영되며 PLC가 다시 쓰면 PLC 값이 우선됩니다.
- 물리 RUN_SW를 전환하면 Local 제어로 넘어갈 수 있으므로 주기 읽기에서 Lock과 RUN_SW를 함께 확인합니다.
- 통신선이 끊겼다는 이유만으로 자동 정지하는 통신 Timeout 정지 기능은 현재 코드에 없습니다. PLC 운전은 계속될 수 있습니다. 응답 대기시간 500 ms는 PLC의 통신 오류 판정 시간이며 보드의 자동 정지 시간이 아닙니다.
- RS485 옵션보드 자체가 분리되어 감지가 해제되는 경우에는 Lock 상태에서 출력 정지 및 Lock 해제를 수행합니다. 케이블 단선과 옵션보드 분리는 다른 조건입니다.
- PLC 운전이 필요한 동안 보드 타이머만으로 종료될 것으로 기대하지 말고, 종료 시 RUN OFF를 전송하고 확인합니다.

## 9. 통신 오류 및 해결 순서

| 증상 | 확인 내용 |
| --- | --- |
| 응답 없음 | Slave ID, Baud, 8-E-1, 배선, RS485 옵션보드 감지, CRC, 요청 간격 확인 |
| 읽기는 되는데 출력 쓰기 거부 | Lock ON, RUN_SW OFF, 메인화면, 출력값 0~500 확인 |
| RUN ON 거부 | 위 조건에 더해 에러 상태 확인. ON 값이 1이 아닌 0xFF00인지 확인 |
| 쓰기 후 값이 달라짐 | 가변저항 조작, Lock 해제, 다른 Master의 쓰기 여부 확인 |
| 출력값 0인데 5% 표시 | 정상 환산 동작. 정지하려면 RUN 주소에 0 쓰기 |
| 정지 후에도 출력값이 남음 | 설정값은 남을 수 있음. RUN 상태가 0인지 확인 |
| Lock 해제 후 재운전 | 외부 REMOTE가 ON인지 확인 |

Modbus 예외 응답의 주요 코드는 0x01=지원하지 않는 Function, 0x02=지원하지 않는 주소/읽기 전용 주소 쓰기, 0x03=값 또는 현재 제어 조건 부적합, 0x04=명령 실행 실패입니다. 예를 들어 FC06의 값 오류는 응답 Function 0x86, 예외 코드 0x03으로 나타납니다. 이를 정상 쓰기 응답으로 처리하지 마십시오.

에러 Reset이 필요하면 먼저 원인을 확인하고 RUN OFF 및 정지 상태를 확인합니다. 그다음 FC06으로 주소 0x0008에 0xFF00을 쓰고 에러 상태를 다시 읽습니다. Reset 성공 자체는 운전 시작이 아니므로, 재운전 조건을 확인한 뒤 별도로 RUN ON을 실행합니다.

## 10. 미쓰비시 PLC 적용 시 확인 항목

현재 확인된 제조사는 미쓰비시이며 CPU와 RS485 모듈 모델은 아직 확인되지 않았습니다. 먼저 CPU 명판과 통신 모듈 명판을 확인하고 해당 모델의 Modbus RTU Master 지원 및 포트 파라미터를 확인합니다.

FX5 계열의 공식 MODBUS Communication 매뉴얼에서는 Master 통신에 ADPRW 명령을 설명합니다. 이 명령을 다른 시리즈에 그대로 적용하지 마십시오. 실제 사용 기종에 맞춰 Slave ID, Function, 주소, 수량, 송수신 데이터 영역, 완료/오류 판정 방법을 확정해야 합니다. 참고: [미쓰비시 FX5 MODBUS Communication 공식 매뉴얼](https://dl.mitsubishielectric.com/dl/fa/document/manual/plcf/jy997d56101/jy997d56101h.pdf).

0xFF00은 16-bit 패턴입니다. PLC 모니터가 signed 16-bit로 표시하면 -256으로 보일 수 있지만, unsigned로는 65280입니다. 비교 시 16진수 FF00 패턴을 기준으로 확인하면 혼동을 줄일 수 있습니다.

PLC 메모리 D101과 보드 주소 0x0001은 같은 주소가 아닙니다. D101은 PLC가 받은 값을 저장할 예시 위치이고, 0x0001은 요청 프레임에 넣는 보드 레지스터 주소입니다.

## 11. 펌웨어 확인 근거

- include/params.h: 기본 통신 설정, 출력값 범위, 0xFF00 Boolean, PA7 최소 5%.
- include/modbus_regs.h: Holding Register 주소 정의.
- src/modbus_regs.c: 읽기/쓰기 허용 조건, Lock/RUN 처리, 옵션보드 분리 처리.
- src/modbus_rtu.c: FC03/FC06/FC10 처리, 예외 코드, 옵션보드 감지.
- src/ultrasonic_ctrl.c: 출력값 저장, 가변저항 인계, PLC 타이머 없는 운전.
- src/ultrasonic_pwm.c: PA7 PWM 변환 및 출력 정지.
- src/menu_screen.c: PL 퍼센트/W 환산, 485 COMM/485 ON 화면.
- src/menu.c: Lock 해제 후 REMOTE 입력 및 물리 RUN_SW 처리.

이 문서는 위 소스를 읽어 작성했습니다. 펌웨어 수정·업로드는 수행하지 않았으며, 실제 보드에 설치된 펌웨어가 다른 경우 동작을 다시 확인해야 합니다.
