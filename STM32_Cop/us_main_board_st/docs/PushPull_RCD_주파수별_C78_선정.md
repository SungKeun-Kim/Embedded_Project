# Push-Pull GDT 1차 RCD 클램프 — 주파수별 C78 선정

TR2 1차 Push-Pull(Q5A/Q5B, IRF7341) 클램프 회로의 **R57·C78** 값을
운용 주파수(20~168 kHz)에 맞게 선택하기 위한 참조 문서.

---

## 1. 대상 회로

```text
+28V ─── R57 ───● Clamp Node ─── C78 ─── GND
                 │
           D21 ──┤ (Q5A Drain / TR2 Pin1)
           D22 ──┘ (Q5B Drain / TR2 Pin5)
```

| 부품 | 권장 사양 | 비고 |
|------|-----------|------|
| **R57** | **750 Ω / 2 W** | 1.5 kΩ 금속피막 칩 × 2 병렬 |
| **C78** | **220 nF / 50 V / X7R / 1210** | **5개** 병렬 실장, 주파수별 1~5개 사용 |
| D21, D22 | US1G (초고속) | — |

---

## 2. 설계 기준

### 2.1 검증된 기준점

| 주파수 | C78 (실측) | 결과 |
|--------|------------|------|
| **20 kHz** | 1 µF (≈ 1000 nF) | **정상 동작 확인** |
| **40 kHz** | 1 µF (≈ 1000 nF) | **정상 동작 확인** |

### 2.2 이론 최적 용량

20 kHz / 1 µF 검증점에서 스너버 손실을 일정하게 유지하려면 \(C \propto 1/f\):

\[
C_{opt}(f) = 1000\,\text{nF} \times \frac{20\,\text{kHz}}{f}
\]

| 주파수 (kHz) | \(C_{opt}\) (nF) | 220 nF 병렬 후보 | **최적 조합** | 실제 (nF) | 오차 |
|-------------|-----------------|-----------------|--------------|----------|------|
| **20** | 1000 | 4×(880), **5×(1100)** | **5×** | **1100** | +10 % |
| **28** | 714 | 3×(660), **4×(880)** | **4×** | **880** | +23 % |
| **40** | 500 | 2×(440), **3×(660)** | **3×** | **660** | +32 % † |
| **68** | 294 | **1×(220)**, 2×(440) | **1×** | **220** | −25 % |
| **80** | 250 | **1×(220)** | **1×** | **220** | −12 % |
| **120** | 167 | **1×(220)** | **1×** | **220** | +32 % |
| **168** | 119 | **1×(220)** | **1×** | **220** | +85 % † |

† 40 kHz·168 kHz는 **실측값(1 µF) 또는 R57 발열** 기준으로 한 단계 큰/작은 표준 조합을 채택.
40 kHz는 1 µF 검증 이력상 **660 nF(3×)** 가 440 nF(2×)보다 안전.
168 kHz는 220 nF가 330 nF보다 손실 적음 (220 nF = 최소 표준 칩).

### 2.3 RC 시정수 (\(\tau = R \times C\), R57 = 750 Ω)

| C78 (220 nF × n) | 합산 | \(\tau\) | 20 kHz \(\tau/T\) | 168 kHz \(\tau/T\) |
|------------------|------|----------|-------------------|---------------------|
| 5× | 1100 nF | 825 µs | 16.5 | — |
| 4× | 880 nF | 660 µs | — | — |
| 3× | 660 nF | 495 µs | — | — |
| 2× | 440 nF | 330 µs | — | — |
| 1× | 220 nF | 165 µs | — | **27.7** |

> 2× (440 nF)는 본 운용 주파수 목록에서 **최적점 없음** — 40 kHz(너무 작음)·68 kHz(너무 큼) 사이에 걸침.

## 3. 220 nF × 5 병렬 마운트 전략 (권장)

기판에 **220 nF 칩 5개**를 병렬로 실장하고, 주파수에 따라 **1개씩 제거**한다.

```text
Clamp Node ──┬── C78-1  220nF ── GND
             ├── C78-2  220nF ── GND
             ├── C78-3  220nF ── GND   ← 주파수 ↑ 시 순차 제거
             ├── C78-4  220nF ── GND
             └── C78-5  220nF ── GND
```

| 장착 | 합산 | 대응 주파수 |
|------|------|------------|
| **5×** | **1100 nF** | **20 kHz** |
| **4×** | **880 nF** | **28 kHz** |
| **3×** | **660 nF** | **40 kHz** |
| ~~2×~~ | ~~440 nF~~ | *(운용 목록에 최적 주파수 없음 — 사용 안 함)* |
| **1×** | **220 nF** | **68, 80, 120, 168 kHz** |

### 제거 순서 (현장)

```text
20 kHz   → 5개 모두
28 kHz   → 1개 제거 (5→4)
40 kHz   → 1개 더 제거 (4→3)
68 kHz↑  → 2개 더 제거 (3→1)   ※ 3→2 거치지 않고 1개만 남김
```

> **팁:** 3개→1개로 바로 줄일 때 440 nF(2×) 구간을 거치지 않도록, **C78-4·C78-5**부터 제거.

> **장기 권장:** 0 Ω 저항 + 솔더 브릿지, 또는 DNP(Do Not Populate) 슬롯으로 **재납땜 없이** 전환.

## 5. 주파수별 상세

### 5.1 20 kHz

| 항목 | 값 |
|------|-----|
| **권장** | **5× 220 nF = 1100 nF** |
| \(C_{opt}\) | 1000 nF |
| 대안 | 4× (880 nF) — 스파이크 여유 약간 감소 |
| R57 발열 | 매우 낮음 |
| 확인 | Q5A Drain VDS 피크 **< 45 V** |

기존 1 µF(1000 nF) 검증과 **1100 nF(+10 %)** 로 동등 이상.

### 5.2 28 kHz (주 사용)

| 항목 | 값 |
|------|-----|
| **권장** | **4× 220 nF = 880 nF** |
| \(C_{opt}\) | 714 nF |
| 대안 | 5× (1100 nF) — R57 미온·VDS 여유 최대 |
| 대안 | 3× (660 nF) — R57·VDS 실측 OK 시 |

### 5.3 40 kHz (주 사용)

| 항목 | 값 |
|------|-----|
| **권장** | **3× 220 nF = 660 nF** |
| \(C_{opt}\) | 500 nF |
| 비권장 | 2× (440 nF) — 1 µF 검증 대비 용량 **56 %**, VDS 스파이크↑ |
| 대안 | 4× (880 nF) — R57 온도 낮을 때 |

### 5.4 68 kHz

| 항목 | 값 |
|------|-----|
| **권장** | **1× 220 nF = 220 nF** |
| \(C_{opt}\) | 294 nF |
| 대안 | 2× (440 nF) — VDS > 50 V 일 때만 (R57 발열↑) |

### 5.5 80 kHz

| 항목 | 값 |
|------|-----|
| **권장** | **1× 220 nF = 220 nF** |
| \(C_{opt}\) | 250 nF — 220 nF가 가장 근접 |

### 5.6 120 kHz

| 항목 | 값 |
|------|-----|
| **권장** | **1× 220 nF = 220 nF** |
| \(C_{opt}\) | 167 nF |
| 참고 | Full-Bridge(TR1) 120 kHz 검증과 **Push-Pull TR2는 별도** 확인 |

### 5.7 168 kHz

| 항목 | 값 |
|------|-----|
| **권장** | **1× 220 nF = 220 nF** |
| \(C_{opt}\) | 119 nF — 220 nF가 330 nF보다 **손실·발열 유리** |
| R57 | 2 W 필수, 표면 **< 85 °C** |
| 기타 | IR2104 deadtime(520 ns) 손실 ≈ 17.5 %, TR2 코어·2차 IRFP460 실측 |

## 6. 330 nF × 3 방식 (대안)

기존에 330 nF 칩만 보유한 경우:

| 주파수 | 330 nF 조합 | 합산 |
|--------|------------|------|
| 20, 28 kHz | 3× | 990 nF |
| 40, 68 kHz | 2× | 660 nF |
| 80, 120, 168 kHz | 1× | 330 nF |

220 nF × 5 방식이 **주파수별 분해능**(880 / 660 / 220 nF)과 **168 kHz 손실** 면에서 더 유리.

---

## 7. R57 (고정)

모든 주파수 **R57 = 750 Ω / 2 W** (1.5 kΩ × 2 병렬) 유지.

168 kHz에서 R57 과열 시:

- C78 **220 nF 유지** — 이미 최소
- R57 **820 Ω ~ 910 Ω / 2 W** 검토

---

## 8. 시험·점검 체크리스트

1. **Q5A/Q5B Drain** — OFF VDS 피크 **< 45 V** (절대 55 V 미만)
2. **R57 온도** — **< 85 °C** (168 kHz)
3. **Clamp Node** — DC 드리프트 없음
4. **TR2 2차** — IRFP460 Q6/Q7 게이트 링
5. **출력** — TR3 / 초음파 부하

### 트러블슈팅

| 즹상 | 조치 |
|------|------|
| VDS > 50 V | C78 **+1칩** (220 nF 단계↑) |
| R57 과열 | C78 **−1칩** (이미 1×이면 R57 820 Ω↑) |
| 40 kHz 스파이크 | 3× → **4×** (660 → 880 nF) |
| 68 kHz 스파이크 | 1× → **2×** (220 → 440 nF), 발열 확인 |
