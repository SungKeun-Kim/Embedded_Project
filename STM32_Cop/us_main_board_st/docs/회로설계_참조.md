# Full-Bridge TR1 1차 회로 설계 참조

> STM32G474CBT6 제어보드와 12 V Full-Bridge(TR1) 구동부의 현재 회로도 기준 설계 결정 요약.

**작성 기준:** 2026-08-05\
**대상 보드:** STM32G474CBT6 기반 초음파 전원 (`us_main_board_st`)

---

## 1. 적용 범위

| 구분            | 내용                                                               |
| --------------- | ------------------------------------------------------------------ |
| **본 문서**     | TR1(EI2218) 1차의 12 V 풀브리지 구동                               |
| **포함**        | HRTIM, 74AHCT125, IR2104 2개, IRF7351 듀얼 N-MOSFET 2개, bootstrap |
| **제외**        | TR1 2차 정류/부하, 고전압 출력단의 별도 공진 네트워크              |
| **폐기된 기준** | +28 V 센터탭 TR2 푸시풀, TC4427, FDS2582, RCD(C78/R57) 전용 설계   |

운용 목표 주파수는 15~128 kHz이다. 중심주파수 기준 스윕은 최대 +/-1 kHz로 하고, 실제 출력 주파수는 이 범위를 넘지 않게 제한한다.

$$
f_{out}=\operatorname{clamp}(f_{center}+f_{offset}, 15\ \mathrm{kHz}, 128\ \mathrm{kHz})
$$

완전한 +/-1 kHz 스윕을 보장하는 중심주파수 범위는 16~127 kHz이다.

---

## 2. 현재 제어보드 I/O 기준

아래 표는 현재 회로도 U2(STM32G474CBT6, LQFP48)의 Net 이름을 기준으로 한다. 이전 RB/RC LQFP64 핀맵과 PB0/PB1 RS485 방향 제어 배정은 이 보드에 적용하지 않는다.

| 기능 그룹       | MCU 핀             | 회로도 Net                 | 설정/비고                                       |
| --------------- | ------------------ | -------------------------- | ----------------------------------------------- |
| 아날로그 입력   | PA0, PA1, PA6, PB1 | COMP_V, COMP_I, CT_ADC, PWM_VR | PB1=ADC1_IN12 가변저항 입력, PA6=ADC2_IN3 CT 입력 |
| 풀브리지 PWM    | PA8, PA9           | CHA1, CHA2                 | HRTIM1_CHA1/CHA2(AF13), 게이트 드라이버 INA/INB |
| 게이트 Enable   | PA15               | SONIC_ON                   | IR2104 두 개의 SD 직접 공통 제어, 외부 pull-down 장착 |
| PWM 파형 출력   | PA7                | PWM_OUTPUT                 | TIM3_CH2(AF2), 3 kHz 출력                        |
| 부저 출력       | PA5                | BZ_OUT                     | TIM2_CH1(AF1), 수동형 부저 2.7 kHz PWM           |
| RS485 데이터    | PA2, PA3           | USART2_TX, USART2_RX       | TX=U6C 3.3→5 V, RX=U6D+PA3 외부 pull-up 4.7 kohm |
| RS485 방향      | PB4, PB5           | DE_RS485, /RE_RS485        | 독립 GPIO 출력                                  |
| RS485 부가 제어 | PB2, PB3           | RTERM, 485BD_DETECT        | PB2=출력, PB3=외부 pull-up Active LOW 입력      |
| 예비 신호       | PC15               | SPARE                      | 기능 확정 전까지 입력(`GPIO_NOPULL`)             |
| 버튼            | PB6, PB7, PB8, PB9 | MODE, DOWN, UP, START_STOP | 외부 pull-up 장착, Active LOW, `GPIO_NOPULL`    |
| 외부 제어 입력  | PA10, PA11, PA12   | REMOTE, RUN_SW, SWEEP_SW   | 외부 pull-up 장착, Active LOW, `GPIO_NOPULL`    |
| 시스템 RUN LED  | PA4                | RUN_LED                    | GPIO 출력, 정상 동작 중 heartbeat 주기 토글    |
| 상태/알림 출력  | PC13, PC14         | GOING, END_BZ              | 정상 발진, 타이머 종료 2초                      |
| LCD1602 데이터  | PB10~PB15          | LCD_RS, LCD_E, LCD_D4~D7   | 74HCT574 D 입력 6개, Q 출력에서 LCD 구동        |
| LCD Latch Clock | PB0                | CLK_LCD                    | 74HCT574 CP, 상승 에지 저장, 초기 상태 LOW      |
| SWD             | PA13, PA14, NRST   | SWDIO, SWCLK, NRST         | SWD 전용으로 예약                               |

RS485의 안전한 기본 상태는 `DE_RS485=LOW`, `/RE_RS485=LOW`이다. PB4와 PB5에 각각 외부 풀다운을 두어 MCU 리셋 중에도 송신 드라이버를 끄고 수신 상태를 유지한다.

> **LCD RS/E 회로 주의**: MCU 쪽 Net 이름은 `PB10=LCD_RS`, `PB11=LCD_E`로 적혀 있지만 U5 출력은 `Q0→LCD RS`, `Q1→LCD E`이다. U5는 `D0→Q0`, `D1→Q1`이므로 실제 펌웨어 기능은 `PB11→D0/Q0→LCD RS`, `PB10→D1/Q1→LCD E`로 설정해야 한다. `.ioc` 라벨도 실제 LCD 기능에 맞춰 PB10=LCD_E, PB11=LCD_RS로 기록한다.

`MODE`, `DOWN`, `UP`, `START_STOP`, `REMOTE`, `RUN_SW`, `SWEEP_SW`는 모두 보드에 외부 pull-up 저항이 장착되어 있다. 따라서 눌림/접점 ON은 LOW, 해제/OFF는 HIGH로 해석하고 MCU GPIO는 내부 pull-up을 중복 사용하지 않는 `GPIO_NOPULL`로 초기화한다. `PB3/485BD_DETECT`와 `PA3/USART2_RX`도 아래 RS485 회로의 외부 pull-up을 사용하므로 `GPIO_NOPULL`이다.

> **변경된 회로도/펌웨어 기준**: `PB1=PWM_VR(ADC1_IN12)`, `PA7=PWM_OUTPUT(TIM3_CH2)`, `PB0=CLK_LCD`, `PA5=BZ_OUT`, `PC13=GOING`, `PC14=END_BZ`, `PC15=SPARE`, `PA4=RUN_LED`를 사용한다. PA7은 PWM 출력 전용이므로 ADC2_IN4/COMP2_INP로 동시에 사용할 수 없다.

### 회로도 확인 항목

- J3가 표준 10핀 Cortex Debug(SWD) 커넥터라면 `nRESET`은 10번 핀에 연결한다. 9번 NRST 배정을 유지하면 커스텀 핀 배열임을 커넥터와 생산 문서에 명확히 표기한다.
- `PB4`는 JTRST 대체 기능이 있으나 SWD는 PA13/PA14만 사용하므로 `DE_RS485` GPIO 출력으로 사용해도 된다.
- HSE의 33 pF 부하 커패시터는 Y1의 데이터시트 부하용량과 PCB 기생용량을 합산해 검증한다.
- `PB0/CLK_LCD`는 74HCT574 CP에 연결하고 외부 10 kohm pull-down을 두어 MCU reset 중 LOW를 유지한다. PB0과 CP 사이에는 100~330 ohm 직렬저항을 선택 적용하고 74HCT574 전원 핀에는 100 nF를 근접 배치한다.
- LCD 데이터(PB10~PB15)를 먼저 안정시킨 다음 `CLK_LCD`에 LOW->HIGH 상승 에지를 주고 다시 LOW로 복귀한다. 74HCT574의 미사용 D 입력은 부동 상태로 두지 않는다.
- `PA4/RUN_LED`는 GPIO push-pull 출력으로 사용한다. 정상 main loop 또는 주기 task에서 non-blocking 방식으로 토글하고, LED 전류는 직렬저항을 사용해 수 mA 이하로 제한한다.
- `PA5/BZ_OUT`은 내부 발진회로가 없는 수동형 부저이므로 `TIM2_CH1(AF1)`의
  2.7 kHz, 50% PWM으로 구동한다. 버튼의 디바운스된 눌림 시점마다 70 ms 동안
  비차단 방식으로 재생한다. MCU 직접 구동 전류가 크면 트랜지스터 드라이버를
  사용하고 부저 구동단의 극성과 정격을 확인한다.
- PC13~PC15는 LSE를 사용하지 않을 때 GPIO로 사용할 수 있다. PC13/PC14는 저전류 상태 출력으로 사용하고, PC15는 `SPARE` 입력으로 둔다.
- PA10은 UCPD1_DBCC2, PA11/PA12는 USB DM/DP 겸용이다. USB-C/USB 기능을 사용하지 않는다는 전제에서 GPIO 입력으로 사용할 수 있으며, 해당 주변장치는 초기화하지 않는다.
- `PB6~PB9`와 `PA10~PA12`의 외부 pull-up 저항 실장과 접점-GND 배선을 확인한다. 펌웨어는 일곱 입력을 모두 Active LOW 및 `GPIO_NOPULL`로 처리한다.
- `PB1/PWM_VR`은 5 V tolerant 디지털 입력으로 해석하지 말고 ADC 입력 전압을 `0~VDDA(3.3 V)` 안에 제한한다. 권장 시작 회로는 `3.3 V--10 kohm VR--AGND`, wiper에서 PB1까지 1 kohm 직렬저항, PB1 근처 100 nF to AGND이다. 외부 패널 배선이 길면 ESD/서지 보호를 추가한다.
- `PA7/PWM_OUTPUT`에는 TIM3_CH2의 3 kHz push-pull 파형이 출력된다. 수신 회로의 입력 전압·논리 임계값을 확인하고 필요하면 47~220 ohm 직렬저항 또는 3.3 V→5 V level shifter를 사용한다. PA7에 가변저항의 아날로그 wiper를 연결하지 않는다.
- ADC1/ADC2는 170 MHz kernel clock을 `DIV4`하여 42.5 MHz로 사용한다. 이는 3.3 V에서 ADC1과 ADC2를 함께 사용하는 최대 52 MHz 조건 안이다.

### 2.1 기존 5 V MAX485 옵션보드 재사용

기존 MAX485 옵션보드는 5 V 로직이므로 STM32G474CBT6의 3.3 V I/O에 직접 연결하지 않는다. 남는 `74AHCT125` 채널을 아래처럼 사용한다.

```text
PA2 / USART2_TX ──> U6C A(pin 9)
U6C /OE(pin 10) ──> GND
U6C Y(pin 8) ──> 옵션보드 TX ──> 기존 74AHC02 ──> MAX485 DI

MAX485 RO(5 V) ──> U6D /OE(pin 13)
U6D A(pin 12) ──> GND
U6D Y(pin 11) ──> PA3 / USART2_RX
                         |
                   R80 4.7 kohm
                         |
                       +3.3 V
```

U6D는 일반적인 데이터 입력 버퍼가 아니라 `/OE`를 데이터 입력처럼 사용한다. `RO=LOW`이면 U6D가 활성화되어 A의 LOW를 PA3에 출력하고, `RO=HIGH`이면 U6D 출력이 Hi-Z가 되어 R80이 PA3을 3.3 V로 올린다. 따라서 논리 반전 없이 5 V RO를 3.3 V RX로 변환한다.

| MAX485 RO | U6D 상태 | PA3/USART2_RX |
| --------- | -------- | -------------- |
| LOW       | Enable, A=LOW 출력 | LOW |
| HIGH      | Hi-Z     | R80에 의해 HIGH |

- `PA3`은 `USART2_RX(AF7)`, `GPIO_NOPULL`로 설정한다. R80 4.7 kohm 외부 pull-up이 있으므로 내부 pull-up을 켜지 않는다.
- STM32G474CBT6의 PA3에 MAX485 RO 5 V를 직접 연결하지 않는다.
- `PB3/485BD_DETECT`는 MCU 보드의 외부 3.3 V pull-up을 사용한다. 옵션보드의 J12 pin 8이 GND이므로 보드 미연결=HIGH, 연결=LOW인 Active LOW 감지 신호다. 펌웨어는 `GPIO_NOPULL`로 설정하고 LOW일 때 보드가 있다고 판단한다.
- Legacy 옵션보드의 `SPARE1`은 MCU에 연결하지 않는다. 옵션보드 내부 RT3 10 kohm가 `SPARE1`을 5 V HIGH로 유지하여 기존 74AHC02의 정상 TX 통과 조건을 만들기 때문에 PC15에 직접 연결할 수 없다. 기존 커넥터 신호는 `SPARE1/NC` 또는 `RESERVED`로 유지하며 GND에도 연결하지 않는다.
- `PC15/SPARE_RS485`는 legacy `SPARE1`과 분리된 3.3 V 예비 GPIO다. RS485 보드 커넥터에 배선할 경우 5 V pull-up이나 5 V logic과 연결되지 않은 별도 spare pin을 사용하며, 필요 시 level shifter를 추가한다.
- `PB4/DE`, `PB5(/RE)`는 외부 pull-down이 장착된 push-pull 출력이다. 부팅 및 대기 상태는 둘 다 LOW, 송신 시 `/RE=HIGH` 후 `DE=HIGH`, USART TC 확인 후 `DE=LOW`, `/RE=LOW` 순서로 복귀한다.
- `PB2/RTERM`은 KRC105M을 통한 종단저항 릴레이/스위치 제어 출력이다.

## 3. TR1 풀브리지 1차 구조

```text
                    +12 V
                      |
             Q4A -----+----- Q4B
              |                 |
Bridge A ------+--- TR1 1차 ----+------ Bridge B
              |                 |
             Q3A -----+----- Q3B
                      |
                     GND

U3 IR2104: HO -> Q4A, LO -> Q3A, IN <- CHA1
U7 IR2104: HO -> Q4B, LO -> Q3B, IN <- CHA2
```

TR1 1차의 양 끝은 두 하프브리지 중점(Bridge A, Bridge B)에 연결한다. 대각선 MOSFET 쌍이 번갈아 켜져 1차에 양극성 전압을 인가한다.

| 구간     | Bridge A        | Bridge B        | TR1 1차 전압 |
| -------- | --------------- | --------------- | ------------ |
| 반주기 A | Q4A ON          | Q3B ON          | +12 V        |
| deadtime | 두 레그 전환 중 | 두 레그 전환 중 | 0 V          |
| 반주기 B | Q3A ON          | Q4B ON          | -12 V        |

센터탭 푸시풀과 달리 TR1 1차는 센터탭을 사용하지 않는다. 이전 푸시풀용 RCD 클램프(C78/R57/D21/D22), TC4427, FDS2582와 TR2 관련 부품은 이 토폴로지의 BOM과 시험 기준에서 제외한다.

## 4. 게이트 구동 체인

```text
PA8 / HRTIM1_CHA1 -- R11 47 ohm --+-- 74AHCT125 U6A -- U3 IN
                                  +-- C39 22 pF -- GND

PA9 / HRTIM1_CHA2 -- R13 47 ohm --+-- 74AHCT125 U6B -- U7 IN
                                  +-- C40 22 pF -- GND

PA15 / SONIC_ON -- [100 ohm option] --+-- U3/U7 SD
                                      +-- 10 kohm pull-down -- GND

U3 HO/LO -> R52/R53 47 ohm -> Q4A/Q3A gate
U7 HO/LO -> R55/R56 47 ohm -> Q4B/Q3B gate
```

| 단계                | 부품                        | 역할                                           |
| ------------------- | --------------------------- | ---------------------------------------------- |
| PWM 생성            | HRTIM1 Timer A              | CHA1/CHA2의 주파수, 위상, 동기 갱신            |
| 레벨 변환           | 74AHCT125 U6A/U6B @5 V      | STM32 3.3 V PWM을 5 V 논리로 비반전 전달       |
| 하프브리지 드라이버 | IRS2104STRPBF 2개           | 각 레그의 HO/LO 상보 구동, 고정 deadtime, UVLO |
| MOSFET              | IRF7351 계열 듀얼 N채널 2개 | 각 패키지로 하프브리지 1개 구성                |
| bootstrap           | D19/D20 SS24 + C72/C73      | 각 고측 HO 공급 전압 생성                      |
| Gate transformer    | TR1 47T:42T                 | +12 V 입력에서 이상적 2차 약 +/-10.7 V         |

`74AHCT125`의 `/OE`는 LOW에서 출력이 활성화된다. U6A/U6B의 `/OE`를 GND로 묶는 것은 정상 Enable 상태다. U6C는 USART2 TX의 3.3→5 V 변환에 사용하고, U6D는 앞 절의 PA3 RX 변환에 사용한다.

`PA15/SONIC_ON`은 74AHCT125를 거치지 않고 두 IR2104의 `SD`에 직접 공통 연결한다. IR2104의 HIGH 입력 최소값은 3.0 V이므로 3.3 V GPIO로 제어할 수 있다. PA15/공통 SD net에는 외부 pull-down 저항이 장착되어 있어 MCU reset 또는 PA15이 Hi-Z인 동안 SD를 LOW로 유지한다. 필요하면 PA15와 SD 사이에 100 ohm 직렬저항을 배치한다. 펌웨어는 PA15을 push-pull output, `GPIO_NOPULL`로 설정하며, 초기화 전에 output data를 LOW로 준비한다. HRTIM·deadtime·fault 설정이 끝난 뒤 마지막에 HIGH로 올리고, Fault/정지 시에는 PA15을 먼저 LOW로 내린 뒤 HRTIM 출력을 정지한다.

## 5. HRTIM 파형 및 안전 조건

### 5.1 두 입력의 관계

IR2104는 `IN` 한 개로 해당 하프브리지의 HO/LO 상보 신호와 내부 고정 deadtime을 생성한다. HRTIM은 HO/LO 네 신호를 직접 만들지 않고 두 레그 입력만 생성한다.

```text
CHA1 -> U3 IN -> Q4A/Q3A 레그
CHA2 -> U7 IN -> Q4B/Q3B 레그
```

- CHA1과 CHA2는 50% 기준의 hardware complementary pair로 설정한다.
- IR2104 내부 deadtime이 각 레그의 Q4/Q3 동시 도통을 방지한다.
- HRTIM은 중심주파수 72.0 kHz 미만에서 CHA1/CHA2에 1.4 us, 72.0 kHz 이상에서 0.8 us positive dead-time을 삽입한다. 두 출력이 모두 LOW인 구간에 두 IR2104는 Low-side 상태로 천이하여 TR1 1차에 0 V zero-vector를 만든다.
- 기존 SG3525 양산값(RD=47 ohm/10 nF 약 1.4 us, 120 kHz용 RD=22 ohm/10 nF 약 0.7 us)과 IRFP460 4병렬·개별 Gate 22 ohm 구성을 기준으로 정했다. 메뉴의 68 kHz 대역 최대 71.0 kHz와 80 kHz 대역 최소 77.0 kHz 사이인 72.0 kHz를 경계로 사용한다.
- TA2는 dead-time block이 TA1로부터 만드는 complementary 출력이므로 독립적인 SET/RESET source를 사용하지 않는다.
- 주파수 변경 시 period와 두 채널 compare/위상 값을 동기 업데이트한다. 한 채널만 먼저 바뀌면 순간 DC volt-second 불균형으로 트랜스 포화 위험이 있다.
- 두 반주기의 on-time은 항상 대칭으로 유지한다. 출력 레벨 제어는 비대칭 듀티보다 버스 전압 또는 burst 제어를 우선 검토한다.

### 5.2 시작 조건

IR2104의 내부 deadtime은 부품 데이터시트 기준 약 0.5 us급이다. 고주파용 HRTIM 0.8 us zero-vector를 적용하면 각 극성의 명령 ON 구간은 120 kHz에서 약 3.37 us, 128 kHz에서 약 3.11 us가 된다. 고주파 운전 전에는 반드시 IRFP460을 연결한 상태에서 실제 VGS, VDS, TR1 1차 전류와 DC bus current spike를 측정한다.

15~128 kHz, 50% 교번 구동에서는 매 반주기 저측 MOSFET이 켜져 bootstrap capacitor가 충전된다. 고측을 계속 ON으로 유지하는 DC 구동은 bootstrap 방식에서 허용하지 않는다.

### 5.3 정지 및 Fault

| 상태            | CHA1/CHA2  | PA15/SONIC_ON | U3/U7 SD | 결과           |
| --------------- | ---------- | ------------- | -------- | -------------- |
| 리셋/초기화     | 정지       | LOW           | LOW      | HO/LO 모두 OFF |
| 정상 운전       | 180도 교번 | HIGH          | HIGH     | 풀브리지 구동  |
| 명령 정지/Fault | 즉시 정지  | LOW           | LOW      | HO/LO 모두 OFF |

PA15에는 외부 pull-down 저항이 이미 장착되어 있어 reset/Hi-Z 상태의 기본값은 LOW다. 이 pull-down은 부동 방지용이며 능동적인 Fault 차단을 대신하지 않으므로, 과전류 또는 드라이버 전원 이상 시 펌웨어와 무관하게 `SD`를 LOW로 내리는 별도 하드웨어 차단 경로는 계속 권장한다.

## 7. 시험 및 커미셔닝

1. MOSFET 없이 U3/U7의 HO/LO 파형을 확인한다. 각 레그 내부 deadtime과 SD LOW 차단을 확인한다.
2. 저전압 current-limited +12 V에서 MOSFET을 장착하고, TR1 1차 양단의 양극성 전압과 DC 성분이 없는지 확인한다.
3. 15 kHz, 28 kHz, 40 kHz, 80 kHz, 128 kHz 순서로 올리며 네 MOSFET의 VGS와 각 bridge midpoint VDS를 측정한다.
4. 128 kHz에서 bootstrap VBS가 UVLO 아래로 떨어지지 않는지, gate 상승/하강과 VDS 링잉이 허용 범위인지 확인한다.
5. 중심주파수 +/-1 kHz 스윕 중에도 두 레그의 위상 관계와 TR1 1차의 DC bias가 유지되는지 확인한다.
6. `SONIC_ON=LOW`, MCU reset, 과전류 Fault 각각에서 HO/LO가 모두 OFF인지 확인한다.

## 8. AC 입력 CT 전류 검출 및 공진 입력

### 8.1 SCT-13W AC 입력 전류 검출

220 VAC 입력 전류의 크기 및 보호 판단에는 `SCT-13W` 저주파 CT를 사용한다. 적용 부품은 니켈합금 strip-wound ZCT 코어, AC 250 V/50~60 Hz용, 최대 측정전류 20 A, 권선비 1:1000인 **전류출력형이며 내부 burden이 없는 사양**을 전제로 한다. 입고 부품의 모델 suffix나 데이터시트가 이 조건과 다르면 아래 값을 그대로 적용하지 않는다.

```text
SCT-13W 2차 pin 3 ──+── R29 240 ohm ──+── pin 4 / 1.65 V_BIAS
                    +── R30 240 ohm ──+

pin 3 ── R57 1 kohm ── PA6 / ADC2_IN3
                         |
                       C33 100 nF
                         |
                        GND

ADC2_IN3 ── Schottky clamp ── VDDA / GND
```

| 항목 | 확정값/조건 |
| --- | --- |
| CT | SCT-13W, AC 250 V, 20 A max, 1:1000, 50/60 Hz 전류출력형, 내부 burden 없음 |
| 시스템 선형 측정범위 | 0.2~7 A RMS 목표; CT의 20 A 정격과 구분 |
| Burden | R29/R30 = 240 ohm 1% 2개 병렬, 합성 120 ohm |
| Bias | R27/R28 = 10 kohm/10 kohm, 1.65 V; C31 10 uF + C34 100 nF |
| ADC 보호/필터 | R57 1 kohm, C33 100 nF, BAT54WS 상·하 rail clamp |
| 미장착 | 기존 R14/R15 footprint는 유지하되 DNP 및 BOM/Pick & Place 제외 |

권선비 1:1000, burden 120 ohm의 이상적 계산값은 아래와 같다.

| 1차 RMS 전류 | 2차 RMS 전류 | Burden RMS 전압 | ADC peak 범위(1.65 V 중심) |
| ---: | ---: | ---: | ---: |
| 0.2 A | 0.2 mA | 24 mV | 약 1.616~1.684 V |
| 1 A | 1 mA | 120 mV | 약 1.480~1.820 V |
| 7 A | 7 mA | 840 mV | 약 0.462~2.838 V |

7 A에서 burden 전체 손실은 약 5.88 mW이고, 240 ohm 저항 1개당 약 2.94 mW이다. `R57=1 kohm`은 ADC의 높은 입력 임피던스 때문에 60 Hz 신호를 저항분압하지 않으며, C33 100 nF와 만든 저역통과필터의 60 Hz 감쇠도 약 0.1% 이하다.

`20 A max`는 CT 자체의 정격이고 현재 ADC 회로의 선형 측정범위가 아니다. 120 ohm burden에서 1.65 V 중심 신호가 이상적으로 0~3.3 V에 닿는 전류는 약 9.7 A RMS이며, 0.3~3.0 V의 보수적 정상범위를 적용하면 약 8 A RMS부터 여유가 사라진다. 따라서 정상 계측/제어범위는 0.2~7 A로 제한하고, 그 이상은 rail clamp가 동작할 수 있는 과전류 영역으로 취급한다. 20 A까지 선형 측정해야 한다면 burden을 약 47 ohm 이하로 다시 설계하고 저전류 분해능을 재검증해야 한다.

정류회로는 사용하지 않는다. ADC는 1.65 V 중심의 AC 파형을 timer trigger + DMA로 고정 주기 샘플링하고, offset 제거 후 RMS를 계산한다. 구현값은 4 kSPS, 200 ms(800 sample) window이며 200 ms에는 50 Hz 10주기 또는 60 Hz 12주기가 포함된다. 200 ms RMS 결과 5개를 다시 이동평균하여 LCD 표시와 과전류 보호에는 동일한 1초 평균 RMS 전류를 사용한다. 단순 raw 이동평균은 약 1.65 V로 수렴하므로 전류 계산에 사용하지 않는다. `src/adc_control.c`는 `TIM6 TRGO → ADC2 → DMA1_Channel1 circular`로 구현되어 있다.

과전류 보호는 ADC 절대 peak를 사용하지 않는다. 1초 평균 RMS 전류가 7.00 A 이상인 상태가 약 5초 연속 유지될 때 출력과 Signal을 정지한다. 이 방식은 초음파 스위칭으로 생기는 짧은 ADC spike를 과전류로 잘못 판정하는 현상을 줄인다.

CT 2차는 운전 중 개방하지 않는다. R29/R30은 CT 단자 가까이에 배치하고, R57/C33/rail clamp는 PA6 가까이에 배치한다. 최초 시제품은 0.2/1/3/5/7 A에서 선형성, offset, 온도오차를 측정하여 최종 gain 보정값과 과전류 threshold를 정한다.

### 8.2 공진 탐색용 위상 입력

```text
T2 2차 전압 -> 300 kohm/1 kohm 감쇠 + bias/보호 -> PA0 / ADC1_IN1 / COMP3_INP (COMP_V)
초음파 출력전류 -> 고주파 CT + burden/bias/보호 -> PA1 / ADC1_IN2 / COMP1_INP (COMP_I)
COMP3_INM <- DAC3_CH1 (COMP_V 실측 중심전압)
COMP1_INM <- DAC1_CH1 (COMP_I 실측 중심전압)
```

#### 확정 핀 및 내부 아날로그 블록

| 신호 | MCU 핀 | LQFP48 핀# | ADC 기능 | COMP 기능 | INM 기준 |
| --- | --- | ---: | --- | --- | --- |
| COMP_V | PA0 | 8 | ADC1_IN1 | COMP3_INP | DAC3_CH1, 초기값 약 1.618 V |
| COMP_I | PA1 | 9 | ADC1_IN2 | COMP1_INP | DAC1_CH1, 초기값 약 1.623 V |

- PA0은 `COMP1_INM` 겸용이지만 이 회로에서는 반드시 `COMP3_INP`로 선택한다.
- PA1은 `COMP1_INP`로 선택한다. PA0/PA1은 현재 ADC 배선을 유지한 채 ADC offset/진폭 측정과 COMP zero-cross 검출에 함께 사용한다.
- CubeMX `.ioc`는 한 핀의 대표 기능 하나만 기록하므로 PA0/PA1을 `COMP3_INP/COMP1_INP`로 지정한다. ADC1_IN1/IN2 offset 측정 채널은 `HAL_ADC_ConfigChannel()` 등 펌웨어 초기화에서 명시하고, CubeMX 재생성 시 해당 user code가 유지되는지 확인한다.
- COMP1과 COMP3에 서로 다른 내부 DAC 채널을 배정하여 두 채널의 기준전압을 독립 보정한다. 외부 DAC 출력 핀은 필요하지 않다.
- PB1은 `ADC1_IN12/PWM_VR`, PA7은 `TIM3_CH2/PWM_OUTPUT` 전용으로 유지한다. PA7을 `COMP2_INP`로 초기화하지 않는다.
- `SCT-13W/PA6` 경로는 220 VAC 입력전류의 RMS/보호용이다. 초음파 출력 위상 검출용 고주파 CT의 모델·권선비·burden 확정은 이 절의 핀 배정과 별도 검증한다.

#### 전압 채널 기준

T2는 +312 V half-bridge의 18:32 권선비이며, 이상적인 2차 전압은 약 555 Vpp이다. 회로도 표기는 `50~550 Vpp nominal` 또는 `50~555 Vpp`를 사용한다. 전압 채널은 R35/R38/R39=100 kohm 직렬, R41=1 kohm bias 귀환, R59=1 kohm 직렬 보호, C49=22 pF 및 BAT54WS rail clamp 기준이다. R35/R38/R39은 각 0.25 W 이상과 충분한 working voltage를 사용한다.

R33/R34=10 kohm과 전압 분압기의 DC 부하를 포함한 계산상 bias는 약 1.623 V이며, PA0의 중심전압은 약 1.618 V이다. 출력 범위별 예상값은 아래와 같다.

| T2 출력 | PA0 AC 전압 | PA0 예상 범위 |
| ---: | ---: | ---: |
| 50 Vpp | 약 0.166 Vpp | 약 1.535~1.701 V |
| 550 Vpp | 약 1.827 Vpp | 약 0.704~2.531 V |
| 555 Vpp | 약 1.844 Vpp | 약 0.696~2.539 V |

R34/R41은 AC 진폭을 증폭하지 않는다. R34는 공통 bias를 만들고, 15~128 kHz에서 C46/C47로 AC ground가 된 bias node에 연결된 R41이 300 kohm 상단 저항열의 하단 분압저항으로 동작한다. ADC/COMP 입력의 DC 중심만 양전압으로 이동한다.

#### 펌웨어 설정 및 위상 측정 주의점

1. PA0/PA1 GPIO는 `Analog`, `No pull`로 설정하고 COMP는 high-speed mode, non-inverted polarity로 시작한다. hysteresis는 `None` 또는 `Low`부터 검증한다.
2. ADC 사용 전 single-ended calibration을 수행한다. 출력 정지/무전류 상태에서 PA0/PA1 중심전압을 여러 번 평균 측정한 뒤 DAC3_CH1/DAC1_CH1 threshold에 각각 반영한다. 1.618 V/1.623 V는 계산 초기값일 뿐 고정 상수가 아니다. DAC 출력이 안정된 뒤 COMP를 enable하고 pending EXTI/capture flag를 지운 후 capture를 시작한다.
3. comparator threshold를 일괄 1.65 V로 설정하지 않는다. 특히 50 Vpp 저진폭에서는 수십 mV offset이 큰 위상오차가 된다.
4. COMP 출력은 main loop에서 polling하지 않고 timer input capture 또는 HRTIM 내부 event/capture로 timestamp한다. 사용할 내부 interconnect는 RM0440과 CubeMX에서 실제 선택 가능 여부를 확인하며, 기존 `TIM2 COMP1/COMP2 듀얼 캡처` 가정을 사용하지 않는다.
5. 같은 시간축에서 `T = 연속 COMP_V edge 차이`, `delta = COMP_I edge - COMP_V edge`, `phase = 360 * delta / T`로 계산하고 delta는 `-T/2~+T/2`로 wrap한다.
6. 상승/하강 edge를 모두 측정해 평균하고, CT 극성에 따른 180도 반전과 채널별 RC·clamp·comparator 지연을 실측 보정한다. 신호 진폭이 최소 기준보다 작거나 edge chatter가 발생한 구간은 PLL 입력에서 제외한다.
7. C48/C49=22 pF, BAT54WS 접합용량과 PCB 기생용량이 채널별 위상지연을 만든다. 초도 보드에서 15 kHz와 128 kHz 양 끝을 포함해 COMP_V/COMP_I 지연을 측정하고 필요하면 C footprint를 DNP/10 pF/22 pF로 조정한다.

### 8.3 운전 메뉴와 계측 신호 사용 기준

16×2 LCD와 네 버튼(`MODE/DOWN/UP/START_STOP`)의 권장 메뉴는 다음 다섯 항목으로
제한한다. 운전 중에는 메인/진단 화면만 전환하고 설정값 편집은 출력 정지 상태에서만
허용한다.

| 메뉴 | 설정 범위 | 실제 하드웨어/신호 |
| --- | --- | --- |
| TIME | 1~99 MIN/SEC, CONT | 기존 운전 timer |
| FREQUENCY | 28k/40k/68k/80k+ Band, 중심주파수 | PA8/PA9 HRTIM1 출력 |
| TUNING | Manual 또는 Auto | PA6 RMS 후보값, PA0/PA1 위상 기준 |
| SWEEP | 폭 ±100~±1000 Hz, 왕복률 50~200 Hz | HRTIM period 동기 갱신 |
| OUTPUT CTRL | PHASE/VOLUME 또는 CONST CURRENT 1.0~6.0 A | PB1, PA7, PA6 |

출력 정지 상태에서 `MODE`를 누르면 `MAIN → TIME → MAIN`으로
이동한다. 주파수와 튜닝 관련 설정은 오조작을 막기 위해 메인 화면에서
`RUN_SW=OFF`일 때 `MODE+UP`을 2초 이상 유지해야 진입한다. 보호 설정은
`FREQUENCY → SWEEP WIDTH → SWEEP SPEED → TUNE SELECT → 선택된 TUNE 화면 →
OUTPUT MODE → (CONST I 선택 시 CURRENT SET) → FREQUENCY` 순서로 계속 순환한다.
`UP/DOWN=선택·증감`, `MODE=다음 화면`, `MODE+UP 2초=메인 복귀`로 사용한다.
Auto-Tuning은 출력 정지 상태의 전용 준비 화면에서만
START 3초 유지로 시작한다. START 장기 누름을 일반 운전 비상정지로 사용하지
않으며 PA11/RUN_SW 토글로 출력을 정지하고 Local 제어로 전환한다. 설정 중
REMOTE/Fault/과전류가 발생하면 저장하지 않고 즉시 출력을 차단한다.

| 순서 | LCD 첫째 줄 | 둘째 줄/조작 |
| ---: | --- | --- |
| 일반 | `MODE    TIME:xx` | UP/DOWN 시간, START M/S/CONT |
| 보호 1 | `1.FREQUENCY` | UP/DOWN 28/40/68/80k+ |
| 보호 2 | `2.SWEEP WIDTH` | ±100~±1000 Hz |
| 보호 3 | `3.SWEEP SPEED` | 50~200 Hz |
| 보호 4 | `4.TUNING MODE` | UP/DOWN MANUAL/AUTO |
| 보호 4A | `MANUAL SWEEP` | UP/DOWN 100 Hz, START Sweep 시험출력 |
| 보호 4B | `AUTO TUNE READY` | START 3초, 진행/결과 표시 |
| 보호 5 | `5.OUTPUT MODE` | VOLUME/CONST I |
| 보호 6 | `6.CURRENT SET` | CONST I 선택 시 1.0~6.0 A |

Flash settings v3에는 타이머/통신 설정과 마지막 선택 Band, 네 Band별 중심주파수를
함께 저장한다. 기존 v1/v2 설정은 읽은 뒤 새 필드를 기본값으로 보완한다. Sweep·
출력방식·목표전류는 아직 RAM에 유지된다. CONST I 화면은 목표값 편집까지이며 실제
정전류 feedback loop는 실측 전류 교정과 보호조건 검증 후 활성화한다.

#### 주파수 Band와 튜닝

- `28k`, `40k`, `68k`는 nominal center와 검증된 탐색 상·하한을 함께 선택한다.
- `80k+` 선택 시 nominal center를 77.0~128.0 kHz에서 설정하여 80 kHz 아래쪽도
  다른 Band처럼 탐색할 수 있다.
- Manual Tune은 선택 Band 내부에서 100 Hz 단위로 조정하고 전류계와 PA6 RMS 값을
  함께 확인한다. START를 누르면 외부 SWEEP_SW 상태와 무관하게 앞 화면에서 설정한
  폭과 속도의 Sweep이 PA8/PA9에 출력되고, 다시 START로 정지하거나 MODE로 나갈 때
  해당 Band 값이 저장된다. 예: 40 kHz Band를 38.5 kHz로 맞추면 다음 선택에도
  38.5 kHz가 나온다.
- 현 보드는 기존 CD4046 VCO 수동 튜닝 경험에 따라 PA6 입력 소비전류의 국부
  최저점을 러프 공진 후보로 사용한다. 중심주파수 ±1 kHz를 100 Hz 간격으로
  scan하고, 주파수별로 새 PA6 200 ms RMS window 2개를 기다린다.
- 러프 후보 주변 ±300 Hz에서는 PA0/COMP3 전압위상과 PA1/COMP1 전류위상을 같은
  HRTIM Timer A 시간축으로 capture하여 위상차 절대값이 가장 작은 지점을 정밀
  공진점으로 선택한다. 허용 위상차 45도 초과나 위상 무효 시에는 러프 결과임을
  표시하고 자동 정밀 판정으로 간주하지 않는다.
- PA6 최저점이 Band scan 양 끝에 있거나 입력전류가 0.05 A 미만이면 국부 최저점이
  아니거나 CT 무신호일 가능성이 있으므로 결과로 채택하지 않는다.

#### Sweep 구현 기준

Sweep 폭은 저장 중심주파수 기준 양쪽 폭이다. 예를 들어 `28.0 kHz ±500 Hz`는
27.5~28.5 kHz를 PA8/PA9에서 삼각형으로 왕복한다. Sweep rate 100 Hz는
`최저→최고→최저`를 초당 100회 수행한다는 의미로 정의한다. 50~200 Hz에서 파형이
계단지거나 끝점에서 jump하지 않도록 TIM7 10 kHz와 32-bit phase accumulator를
사용한다. HRTIM Timer A update를 잠근 상태에서 PER/CMP1 preload를 기록하고,
다음 repetition event(PWM 주기 경계)에서 두 값을 동시에 반영한다. 출력 중
비동기 software update를 사용하지 않으므로 진행 중인 주기가 잘려 설정값보다
짧은 고주파 펄스가 생기지 않는다. PA8(TA1)/PA9(TA2)의 50% 역위상 관계를
유지하며 TIM3 CH2는 PA7 출력에 예약되어 있으므로 Sweep tick에 사용하지 않는다.
Timer A는 `HRTIM_PRESCALERRATIO_MUL4`의 680 MHz counter를 사용한다. 따라서
15~128 kHz의 PER 값은 약 45333~5312이고, 100 kHz 이상에서도 50% 두 출력의
edge 및 주파수 변경 해상도를 충분히 확보한다. PA8/PA9 GPIO는 Very High speed로
설정한다.

#### 정전류 제어 구현 전 필수 조건

1. PA6 ADC2를 `TIM6 TRGO + DMA1_Channel1 circular`로 4 kSPS 수집한다. (구현 완료)
2. 1.65 V offset을 window 평균으로 제거한 200 ms RMS를 0.01 A 단위로 환산한다.
   (이상적 1:1000/120 ohm 환산 구현 완료, 실측 gain 교정 필요)
3. 0.2/1/3/5/6/7 A 실측값으로 gain과 오차를 확인한다.
4. 목표 1.0~6.0 A, deadband, 출력 slew-rate, PWM clamp, anti-windup 및 센서
   단선/포화 보호를 적용한다.
5. Sweep 중 정전류 loop는 여러 Sweep cycle의 평균값을 제어하고, Sweep 폭 자동
   변경은 별도 저속 supervisory loop로 제한한다. 두 loop가 동시에 빠르게 보정해
   hunting을 일으키지 않게 한다.

위상/볼륨 모드의 LCD `PL`은 PB1 가변저항값을 표시한다. 정전류 모드의 `PL`은
PA7로 실제 출력되는 제어 명령을 표시하며 PB1은 로컬 최대 출력 limit으로 남긴다.
PB1 limit 때문에 목표 전류에 도달하지 못하는 상태는 `LIMIT`으로 표시하고, 펌웨어가
작업자 설정을 무시한 채 자동으로 최대 출력까지 올리지 않게 한다.

저장 항목은 Band, 중심주파수, Sweep 폭/속도, 출력 제어 모드, 목표 전류와 기존
타이머/통신 설정이다. Flash에는 사용자의 저장 확인 또는 Auto-Tuning 결과 승인
시에만 기록하며 주파수 scan의 각 step마다 기록하지 않는다.
