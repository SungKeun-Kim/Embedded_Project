# LCD 기본 조작 화면 구성

> `기본조작 매뉴얼_STM32G474.pdf`의 운전 순서를 STM32G474CBT6와
> LCD1602(16자 × 2행)에 맞춰 구현한 화면/접점 기준이다. PDF의 긴 예시는
> 의미를 유지하면서 16자 안에 들어오도록 축약했다.

## 전원 인가

전원 인가 후 2초 동안 아래 화면을 표시한다.

```text
   ULTRASONIC
K-SONICS
```

이후 마지막으로 저장한 `M`, `S`, `CONT` 설정을 불러온다. 저장값이 없으면
기본값은 `08 M`이다.

```text
STANDBY TIME:08M
K-SONICS
```

## Supervisor 설정

전원을 넣을 때 `MODE+DOWN`을 함께 누르고 있으면 일반 부팅 화면 대신 아래
화면으로 진입한다. 화면이 나타난 뒤 두 버튼을 놓고 `MODE`를 한 번 누른다.

```text
SUPERVISOR MODE
MODE: SETTINGS
```

첫 화면에서 `UP/DOWN`으로 `PERCENT` 또는 `300~2500W`를 100W 단위로
선택한다. W 범위를 저장하면 일반 운전 화면의 `PL:100%`가 설정한 최대
전력값으로 환산되어 `PL:2500W`와 같이 표시된다.

```text
PL SETTING
PWR RNG: PERCENT
```

`PB3/485BD_DETECT=LOW`이면 `MODE`를 누를 때 RS485 설정 화면이 이어진다.

```text
RS485 SETTING
BAUD RATE:9600

RS485 SETTING
ADDR :1

RS485 SETTING
TERM:UNMOUNTED
```

- Baud: `9600/19200/38400/57600/115200`
- Address: `1~16`
- Termination: `UNMOUNTED/MOUNTED`; `MOUNTED`이면 `PB2/RTERM=HIGH`
- 각 화면의 `MODE`: 다음 화면으로 이동
- 마지막 화면의 `MODE`: 전력 범위와 RS485 설정을 Flash에 함께 저장하고 적용

RS485 옵션보드가 감지되지 않으면 PL 화면에서 `MODE`를 누를 때 전력 범위만
저장하고 일반 화면으로 복귀한다. 저장값은 다음 전원 투입 시 다시 적용된다.

## 시간 설정

`RUN_SW=OFF`, 출력 정지 상태에서 `MODE`를 누르면 시간 설정 화면으로
진입한다.

```text
MODE    TIME:09M
TIME SET: 09 MIN
```

- `UP`/`DOWN`: 1~99 범위의 숫자 변경
- `START_STOP`: `M → S → CONT → M` 순서로 단위 변경
- `MODE`: 설정을 Flash에 저장하고 STANDBY로 복귀
- `MODE` 1초 이상: 저장하지 않고 STANDBY로 복귀

`CONT`는 시간 제한 없이 운전한다.

## 수동 운전 (`RUN_SW=OFF`)

`REMOTE=ON`인 동안 출력하고 `REMOTE=OFF`가 되면 즉시 정지한다. 수동
운전은 설정 타이머를 사용하지 않는다. 전원을 켤 때 이미 `REMOTE=ON`이면
2초 부팅 화면이 끝난 뒤 운전을 시작한다.

```text
RUN/SWP RemoteON
PL:100%     28.0kHz
```

`SWEEP_SW=OFF`이면 첫째 줄의 `/SWP` 부분을 표시하지 않는다.

둘째 줄의 `PL`은 `PB1/ADC1_IN12(PWM_VR)` 가변저항 입력을 0~100%로
정규화한 뒤 `OUTPUT_VALUE/500` 배율을 곱해 실제 PA7 지령과 같게 표시한다.
같은 값이 PA7 PWM 출력에도 사용되므로 PB1 또는 RS485 출력값을 조정하면
`PL`과 PWM 듀티가 함께 변한다.
`PA6/ADC2_IN3` CT 입력은 전류 측정과 보호용이며 `PL` 표시에는 사용하지 않는다.

`RUN_SW=OFF`에서 정상 Modbus Frame이 들어오면 `RemoteON` 자리에는 1.5초간
`485 COMM`을 표시한다. PLC가 Polling하는 동안에는 표시가 계속 유지된다.
Sweep 운전 중 `RUN` 옆 문자는 `| / - \\` 순서로 회전하며 수동 REMOTE와
RS485 운전에도 동일하게 적용된다.

## 자동 운전 (`RUN_SW=ON`)

`RUN_SW`를 ON으로 바꾸면 출력 대기 상태가 된다. 이 상태에서는
`MODE`, `UP`, `DOWN` 입력을 무시한다.

```text
RDY/SWP TIME:20M
PL:100%     00.0kHz
```

`START_STOP`을 누르거나 `REMOTE`가 OFF에서 ON으로 바뀔 때마다 운전을
시작/정지한다. 설정 시간 전에 정지하면 남은 시간은 설정값으로 RESET된다.

```text
RUN/SWP TIME:19M
PL: 90%     26.0kHz
```

운전 중 `/` 문자는 `| / - \` 순서로 회전하여 동작 중임을 표시한다.
설정 시간이 끝나면 출력을 끄고 `PC14/END_BZ`를 2초간 ON한다.

```text
RDY/SWP TIMEOVER
PL:100%     00.0kHz
```

`START_STOP` 또는 `REMOTE`를 다시 누르면 설정 시간부터 새로 운전한다.
운전 중 `RUN_SW=OFF`로 바꾸면 즉시 정지하며 수동 REMOTE 제어로 전환한다.

## 핀 및 전기 조건

| 기능           | 핀        | `.ioc` 설정          | 동작 논리                |
| -------------- | --------- | -------------------- | ------------------------ |
| MODE           | PB6       | GPIO Input / No pull | 외부 pull-up, Active LOW |
| DOWN           | PB7       | GPIO Input / No pull | 외부 pull-up, Active LOW |
| UP             | PB8/BOOT0 | GPIO Input / No pull | 외부 pull-up, Active LOW |
| START_STOP     | PB9       | GPIO Input / No pull | 외부 pull-up, Active LOW |
| REMOTE         | PA10      | GPIO Input / No pull | 접점 ON=LOW              |
| RUN_SW         | PA11      | GPIO Input / No pull | 자동 모드 ON=LOW         |
| SWEEP_SW       | PA12      | GPIO Input / No pull | Sweep ON=LOW             |
| CLK_LCD        | PB0       | GPIO Output          | 74HCT574 상승 에지 Latch |
| LCD_RS/E/D4~D7 | PB10~PB15 | GPIO Output          | 74HCT574 입력 Bus        |

외부 접점에는 30 ms 소프트웨어 디바운스를 적용한다.

## PB1 PWM_VR 입력과 PA7 PWM_OUTPUT

`PB1/ADC1_IN12`는 0~3.3 V 가변저항 입력이며 내부 로컬 Duty limit
`0~90%`로 변환된다. `PA7/TIM3_CH2`는 3 kHz PWM 파형을 출력한다.
실제 내부 지령은 `PB1 로컬 Duty limit × OUTPUT_VALUE / 500`이고, PA7에서는
이를 `5~100%` PWM으로 선형 변환한다. 예를 들어 `OUTPUT_VALUE=500`일 때
PB1이 최소/중간/최대이면 PA7은 약 `5/52.5/100%`가 된다. 출력 정지
상태에서도 PB1 가변저항 값이 PA7 듀티에 즉시 반영된다.

## PB8/BOOT0 필수 Option Byte

PB8은 `UP` 버튼의 외부 pull-up 때문에 reset 순간 HIGH이다. STM32G474의
기본 `nSWBOOT0=1` 상태에서는 이 신호를 BOOT0로 읽어 System Memory
Bootloader로 진입하므로 LCD와 애플리케이션이 실행되지 않는다. 새 MCU 또는
Option Byte 초기화 후에는 다음 설정을 한 번 적용한다.

```powershell
STM32_Programmer_CLI -c port=SWD mode=HOTPLUG -ob nSWBOOT0=0 nBOOT0=1
```

이 설정은 PB8의 GPIO/UP 버튼 기능에는 영향을 주지 않고 reset 시 Boot source만
User Flash로 고정한다. 정상 실행 여부는 SWD의 PC 주소가 `0x0800xxxx`인지로
확인할 수 있다. `0x1FFFxxxx`이면 아직 System Memory Bootloader 상태다.
