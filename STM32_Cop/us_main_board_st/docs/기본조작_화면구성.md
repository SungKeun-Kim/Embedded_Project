# LCD 기본 조작 화면 구성

> `기본조작 매뉴얼_STM32G474.pdf`의 운전 순서를 STM32G474CBT6와
> LCD1602(16자 × 2행)에 맞춰 구현한 화면/접점 기준이다. PDF의 긴 예시는
> 의미를 유지하면서 16자 안에 들어오도록 축약했다.

## 전원 인가

전원 인가 후 2초 동안 아래 화면을 표시한다.

```text
   ULTRASONIC
K-SONICS
```

이후 마지막으로 저장한 `M`, `S`, `CONT` 설정을 불러온다. 저장값이 없으면
기본값은 `10 M`이다.

```text
STANDBY TIME:10M
K-SONICS
```

## Supervisor 설정

전원을 넣을 때 `MODE+DOWN`을 함께 누르고 있으면 일반 부팅 화면 대신 아래
화면으로 진입한다. 화면이 나타난 뒤 두 버튼을 놓고 `MODE`를 한 번 누른다.

```text
SUPERVISOR MODE
MODE: SETTINGS
```

첫 화면에서 `UP/DOWN`으로 `PERCENT` 또는 `300~2500W`를 100W 단위로
선택한다. W 범위를 저장하면 일반 운전 화면의 `PL:100%`가 설정한 최대
전력값으로 환산되어 `PL:2500W`와 같이 표시된다.

```text
PL SETTING
PWR RNG: PERCENT
```

`PB3/485BD_DETECT=LOW`이면 `MODE`를 누를 때 RS485 설정 화면이 이어진다.

```text
RS485 SETTING
BAUD RATE:9600

RS485 SETTING
ADDR :1

RS485 SETTING
TERM:UNMOUNTED
```

- Baud: `9600/19200/38400/57600/115200`
- Address: `1~16`
- Termination: `UNMOUNTED/MOUNTED`; `MOUNTED`이면 `PB2/RTERM=HIGH`
- 각 화면의 `MODE`: 다음 화면으로 이동
- 마지막 화면의 `MODE`: 전력 범위와 RS485 설정을 Flash에 함께 저장하고 적용

RS485 옵션보드가 감지되지 않으면 PL 화면에서 `MODE`를 누를 때 전력 범위만
저장하고 일반 화면으로 복귀한다. 저장값은 다음 전원 투입 시 다시 적용된다.

## 시간 설정

`RUN_SW=OFF`, 출력 정지 상태에서 `MODE`를 누르면 시간 설정 화면으로
진입한다.

```text
MODE    TIME:09M
TIME SET: 09 MIN
```

- `UP`/`DOWN`: 1~99 범위의 숫자 변경
- `START_STOP`: `M → S → CONT → M` 순서로 단위 변경
- `MODE`: 설정을 Flash에 저장하고 STANDBY로 복귀
- `MODE` 1초 이상: 저장하지 않고 STANDBY로 복귀

`CONT`는 시간 제한 없이 운전한다.

## 보호 설정 메뉴

주파수와 튜닝 설정은 오조작을 막기 위해 일반 `MODE` 메뉴에서 분리되어 있다.
`RUN_SW=OFF`, 출력 정지, 메인 화면 상태에서 `MODE+UP`을 2초 이상 함께 누르면
보호 설정 메뉴로 진입한다. 화면이 바뀐 뒤 두 버튼을 놓는다.

`MODE`를 누를 때마다 다음 순서로 이동한다.

1. `1.FREQUENCY`: `UP/DOWN`으로 28/40/68/80k+ 대역 선택
2. `2.SWEEP WIDTH`: 중심주파수 기준 Sweep 폭 설정
3. `3.SWEEP SPEED`: Sweep 왕복 속도 설정
4. `4.TUNING MODE`: `MANUAL/AUTO` 선택
5. 선택된 튜닝 실행 화면
6. `5.OUTPUT MODE`: `VOLUME/CONST I` 선택
7. `6.CURRENT SET`: `CONST I`를 선택한 경우 목표 전류 설정

수동 튜닝 화면에서는 `UP/DOWN`으로 중심주파수를 100 Hz 단위로 조정한다.
`START_STOP`을 누르면 앞 화면에서 정한 Sweep 폭과 속도로 시험출력을 시작하고,
다시 누르면 정지한다. 외부 `SWEEP_SW` 상태는 이 시험출력에 영향을 주지 않는다.
자동 튜닝 화면에서는 기존과 같이 `START_STOP`을 3초 유지해 시작한다.
마지막 항목에서 `MODE`를 누르면 다시 `1.FREQUENCY`로 돌아가 계속 순환한다.
보호 설정 메뉴를 종료하려면 어느 화면에서든 `MODE+UP`을 2초 이상 함께 누른다.
수동·자동 시험출력 중 종료하면 출력을 먼저 정지하고 메인 화면으로 복귀한다.

## 수동 운전 (`RUN_SW=OFF`)

`REMOTE=ON`인 동안 출력하고 `REMOTE=OFF`가 되면 즉시 정지한다. 수동
운전은 설정 타이머를 사용하지 않는다. 전원을 켤 때 이미 `REMOTE=ON`이면
2초 부팅 화면이 끝난 뒤 운전을 시작한다.

```text
RUN/SWP RemoteON
PL:100%  28.0kHz
```

`SWEEP_SW=ON`이면 회전 문자 뒤에 `SWP`를 표시한다. `SWEEP_SW=OFF`여도
정지 준비 상태에는 `RDY/`, 운전 중에는 `RUN|`, `RUN/`, `RUN-`, `RUN\\`처럼
회전 문자를 계속 표시한다.

Local 제어에서 둘째 줄의 `PL`은 `PB1/ADC1_IN12(PWM_VR)` 가변저항 입력을
실제 PA7 출력 범위와 같은 5~100%로 환산해 표시한다. 가변저항 최소/중간/최대는
각각 약 5/53/100%로 표시된다.
`PA6/ADC2_IN3` CT 입력은 전류 측정과 보호용이며 `PL` 표시에는 사용하지 않는다.

정상 Modbus Frame 수신만으로 화면을 바꾸지는 않는다. 따라서 Lock 해제 직후
`485 COMM` 화면이 잠시 남았다가 Local 화면으로 바뀌는 중간 표시가 발생하지 않는다.
통신 명령으로 RUN ON하면 `RemoteON` 대신 `485 ON`을 계속 표시한다.
통신 준비는 `PB3/485BD_DETECT=LOW`, `PA11/RUN_SW=OFF`, 메인화면에서만
허용한다. Local Lock ON 순간 기존 출력을 정지하고 다음처럼 표시한다.

```text
STANDBY 485 COMM
K-SONICS
```

이 준비/OFF 화면에서는 출력 Level과 주파수를 숨기며 Modbus RUN ON 상태에서만
둘째 줄에 `PL`과 주파수를 표시한다.
운전 화면의 `485 ON`, `RemoteON` 및 `xx.xkHz` 표시는 Local/통신 구분 없이
LCD 16번째 마지막 칸을 기준으로 오른쪽 정렬한다.
Local Lock 순간에는 현재 PB1 출력을 통신 출력 초기값으로 인계한다. 이후
`OUTPUT_VALUE=0~500`과 PB1 중 마지막으로 조작한 값이 실제 출력에 반영된다.
주소 1을 쓰지 않고 통신 RUN하면 인계된 PB1 볼륨값을 그대로 사용하고, 별도
출력이 필요할 때만 주소 1을 쓴다.
통신 중 PB1을 약 5% 이상 돌리면 수동으로 인계되어 작은 변화도 연속 반영되고,
1.5초 동안 `VR: xxx% MANUAL`로
표시한다. 운전 중 주소 `4=0` 또는 `PA11/RUN_SW` 반고정 스위치 상태 변경으로 Lock을 해제할 수
있다. RUN OFF는 출력만 정지하고 `485 COMM` 준비 상태를 유지하므로 다시 ON할 수
있으며, Lock을 해제하면 최신 PB1 값과 MODE/타이머/REMOTE 입력이 다시 동작한다.

Local Lock은 전체 조작부를 잠그지 않는다. 통신 중 충돌할 수 있는 외부
`PA10/REMOTE` ON/OFF만 무시하며 PB1 가변저항과 정지 중 설정 버튼은 계속
사용할 수 있다. `PA11/RUN_SW` 상태를 바꾸면 Local 제어권으로 전환한다.
`PB9/START_STOP`은 운전 시작·정지 버튼이며 Lock 해제 버튼이 아니다.
Sweep 운전 중 `RUN` 옆 문자는 `| / - \\` 순서로 회전하며 수동 REMOTE와
RS485 운전에도 동일하게 적용된다.

## 자동 운전 (`RUN_SW=ON`)

`RUN_SW`를 ON으로 바꾸면 출력 대기 상태가 된다. 이 상태에서는
`MODE`, `UP`, `DOWN` 입력을 무시한다.

```text
RDY/SWP TIME:20M
PL:100%  00.0kHz
```

`START_STOP`을 누르거나 `REMOTE`가 OFF에서 ON으로 바뀔 때마다 운전을
시작/정지한다. 설정 시간 전에 정지하면 남은 시간은 설정값으로 RESET된다.
출력 정지 중에는 주파수를 `00.0kHz`로 표시한다. 운전을 시작하면 설정
주파수를 표시하고, PA7 출력 지령은 최소값에서 현재 볼륨 목표값까지 1.5초 동안
선형으로 상승한다.

```text
RUN/SWP TIME:19M
PL: 90%  26.0kHz
```

운전 중 `/` 위치 문자는 `| / - \` 순서로 200 ms마다 회전하여 동작 중임을
표시한다. Sweep이 꺼져 있어도 동일하게 회전한다.
설정 시간이 끝나면 출력을 끄고 `PC14/END_BZ`를 2초간 ON한다.

```text
RDY/SWP TIMEOVER
PL:100%  00.0kHz
```

`START_STOP` 또는 `REMOTE`를 다시 누르면 설정 시간부터 새로 운전한다.
운전 중 `RUN_SW=OFF`로 바꾸면 즉시 정지하며 수동 REMOTE 제어로 전환한다.
`START_STOP` 장기 누름은 일반 운전 비상정지로 사용하지 않으며, Auto-Tuning
화면에서 3초 유지 입력으로만 사용한다. 긴급 출력 정지 및 Local 전환은
`PA11/RUN_SW` 반고정 스위치를 토글한다.

## 핀 및 전기 조건

| 기능           | 핀        | `.ioc` 설정          | 동작 논리                |
| -------------- | --------- | -------------------- | ------------------------ |
| MODE           | PB6       | GPIO Input / No pull | 외부 pull-up, Active LOW |
| DOWN           | PB7       | GPIO Input / No pull | 외부 pull-up, Active LOW |
| UP             | PB8/BOOT0 | GPIO Input / No pull | 외부 pull-up, Active LOW |
| START_STOP     | PB9       | GPIO Input / No pull | 외부 pull-up, Active LOW |
| REMOTE         | PA10      | GPIO Input / No pull | 접점 ON=LOW              |
| RUN_SW         | PA11      | GPIO Input / No pull | 자동 모드 ON=LOW         |
| SWEEP_SW       | PA12      | GPIO Input / No pull | Sweep ON=LOW             |
| CLK_LCD        | PB0       | GPIO Output          | 74HCT574 상승 에지 Latch |
| LCD_RS/E/D4~D7 | PB10~PB15 | GPIO Output          | 74HCT574 입력 Bus        |

외부 접점에는 30 ms 소프트웨어 디바운스를 적용한다.

## PB1 PWM_VR 입력과 PA7 PWM_OUTPUT

`PB1/ADC1_IN12`는 0~3.3 V 가변저항 입력이며 Local 내부 Duty `0~90%`로
변환된다. `PA7/TIM3_CH2`는 3 kHz PWM 파형을 출력한다. Local 상태에서는
PB1 최소/중간/최대가 PA7 약 `5/52.5/100%`에 대응하며, 출력 정지 상태에도
PB1 값이 PA7 듀티에 즉시 반영된다. 통신 제어에서는 `OUTPUT_VALUE=0/250/500`이
같은 PA7 비율에 대응한다. 통신 중 PB1이 마지막 기준점에서 약 5% 움직이면
Local 값으로 인계되고 이후 작은 변화도 연속 반영된다.

## PB8/BOOT0 필수 Option Byte

PB8은 `UP` 버튼의 외부 pull-up 때문에 reset 순간 HIGH이다. STM32G474의
기본 `nSWBOOT0=1` 상태에서는 이 신호를 BOOT0로 읽어 System Memory
Bootloader로 진입하므로 LCD와 애플리케이션이 실행되지 않는다. 새 MCU 또는
Option Byte 초기화 후에는 다음 설정을 한 번 적용한다.

```powershell
STM32_Programmer_CLI -c port=SWD mode=HOTPLUG -ob nSWBOOT0=0 nBOOT0=1
```

이 설정은 PB8의 GPIO/UP 버튼 기능에는 영향을 주지 않고 reset 시 Boot source만
User Flash로 고정한다. 정상 실행 여부는 SWD의 PC 주소가 `0x0800xxxx`인지로
확인할 수 있다. `0x1FFFxxxx`이면 아직 System Memory Bootloader 상태다.
