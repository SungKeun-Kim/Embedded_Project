# 프로젝트 작업 지침

- 사용자는 초보 임베디드 개발자이며 회로 설계와 Artwork를 중심으로 작업한다.
- 코딩 작업은 초보자도 이해할 수 있도록 단계와 이유를 한글로 설명한다.
- 지침서, 설명서, 작업 요약과 코드 리뷰 메모는 가능한 한 한글로 작성한다.
- 파일명, 함수명, 명령어와 표준 용어처럼 영문이 더 정확한 부분은 영문을 유지한다.
- 기존 한글 주석을 유지하고 새 주석도 자연스러우면 한글로 작성한다.
- Firmware 수정 후 Release Build와 `test_host` 전체 시험을 실행한다.
- 현장 업데이트에는 `US_MAIN_BOARD_UPDATE_V1.2.0.hex`를 사용한다.
- 명시적인 전체 초기화 요청이 없으면 Full chip erase와 Factory HEX를 사용하지 않는다.
- ST-LINK 업로드 전 초음파 출력을 정지하고, Writing 후 Verify와 Reset/Run 결과를 확인한다.
