# 메가소닉 메인보드 회로 참조 (64pin 재편성)

> 대상: STM32G474RETx LQFP64 기반 메가소닉 메인보드
> 기준: 기능 우선 + 아트웍 편의(물리적 핀 군집화)
> 레거시 80핀 문서: docs/circuit_ref_80pin.md

---

## 1. 문서 목적

이 문서는 기존 80핀 배치에서 64핀 패키지로 전환할 때 필요한 회로/핀맵 재편성 기준을 정리한다.
핵심 목표는 다음 2가지다.

- 기능 유지: HRTIM, ADC, RS-485, LCD/LED 래치, 알람/릴레이, 외부입력 기능을 동일하게 유지
- 아트웍 최적화: 신호 성격별로 핀을 가능한 한 같은 포트/인접 군으로 배치해 배선 단순화

## 3. 핀 재편성 원칙

### 3.1 기능 우선 원칙

- 고속/타이밍 민감 신호는 유지
- HRTIM PWM: PA8/PA9 유지
- ADC 4채널: PA0/PA1/PA6/PA7 유지
- RS-485: PA2/PA3 + PB0/PB1 유지

### 3.2 아트웍 편의 원칙

- 디스플레이 버스 군집화:
  - PC14/PC15 + PB10~PB15로 통일
- 외부 입력 군집화:
  - PC10/PC11/PC12 + PD2(SENSOR)
- 릴레이 군집화:
  - LC 릴레이는 PC6~PC9 유지
  - 알람 릴레이는 PA10/PA11/PA12/PB3/PB4 유지

#### 4.8.1 공진 튜닝 인덕턴스 조합표 (고정 + 릴레이 4개)

자동 공진 탐색에서 저인덕턴스(2MHz 근처) 분해능을 높이기 위해,
2진 가중(2/4/8/16uH) 대신 고정 인덕턴스 + 릴레이 조합 구조를 사용한다.

- 고정 인덕턴스:
  - L_BASE = 3.3uH || 4.7uH = **1.94uH** (근사)
- 릴레이 분기 인덕턴스 (아트웍 배선 역순 반영):
  - bit0 (LC_RELAY1, PC9): L1 = 1uH || 2.2uH = **0.69uH**
  - bit1 (LC_RELAY2, PC8): L2 = **2.2uH**
  - bit2 (LC_RELAY3, PC7): L3 = **4.7uH**
  - bit3 (LC_RELAY4, PC6): L4 = **6.8uH**

총 인덕턴스:

- L_total = L_BASE + (bit0?L1:0) + (bit1?L2:0) + (bit2?L3:0) + (bit3?L4:0)
- 범위: **1.94uH ~ 16.33uH** (16조합)

주요 타깃 근사:

- 2.64uH 목표: 0001 -> 2.63uH (2MHz / 2.4nF PZT)
- 16.35uH 목표: 1111 -> 16.33uH (1MHz / 1.55nF PZT)

### 4.10 L7987 BUCK 대체 설계 메모

L7987로 BUCK 단을 교체하면서 STM32G474의 DAC1_OUT1(PA4)을 계속 사용하려면,
DAC 전압을 FB 노드에 저항으로 주입하는 기존 제어 철학은 유지하되 L7987의 FB 기준전압 0.8V에 맞춰
분압 저항을 다시 잡아야 한다.

목표 조건:

- DAC = 0.0V -> VOUT = 40V
- DAC = 3.3V -> VOUT = 10V
- STM32 출력: PA4 = DAC1_OUT1
- ADC 전압 측정: PA7 = ADC2_IN4

기본 식:

- VOUT = 0.8 x (1 + R_FB_TOP / R_FB_BOT) + (0.8 - VDAC) x (R_FB_TOP / R_DAC_INJ)
- 권장 시작 설계식: VOUT ~= 40.01 - 9.09 x VDAC
- DAC 코드 기준 환산식: VOUT ~= 40.01 - 30.00 x (DAC_CODE / 4095)

#### 4.10.2 PA7 전압 분압표 (ADC2_IN4, 40V 대응)

PA7 전압 읽기는 40V 최대 출력 기준으로 여유 있게 잡는 편이 안전하다.
현재 회로 메모 기준으로는 R27=75k, R33=4.99k 조합이 40V에서 약 2.50V를 만들어 적절하다.

- 권장 분압 상단: 75k
- 권장 분압 하단: 4.99k
- 분압비: 4.99 / (75 + 4.99) ~= 0.06238
- 펌웨어 반영 시 상수: ADC_VOL_DIV_TOP_OHM = 75000, ADC_VOL_DIV_BOTTOM_OHM = 4990

| VOUT | PA7 전압 | 3.3V 대비 마진 | 비고           |
| ---: | -------: | -------------: | -------------- |
|  10V |   0.624V |         2.676V | 저출력 영역    |
|  20V |   1.248V |         2.052V | 중간 영역      |
|  30V |   1.871V |         1.429V | 고출력 영역    |
|  40V |   2.495V |         0.805V | 최대 목표 출력 |

ADC 환산 메모:

- VOUT ~= VPA7 x 16.03
- ADC 1카운트당 VOUT 환산 분해능 ~= 12.9mV/count

#### 4.10.4 START 안전 로직 메모

최근 시동 과전류/FET 손상 대응으로 START 시퀀스를 아래처럼 보수적으로 운용한다.

- 일반 START는 현재 S값에 대응하는 Buck 목표 전압이 준비된 뒤에만 PWM을 허용한다.
- LM5005 보호를 위해 START 준비 전압은 최소 18V로 유지한다.
- START 직전 PA7 기준 Buck 전압이 목표보다 높거나 낮게 남아 있으면 START를 금지한다.
- Buck 명령이 이미 준비 전압에 도달한 상태에서 PWM을 시작하므로 START 순간 DAC 명령이 다시 급점프하지 않는다.
- PA8/PA9 게이트 파형은 START 직후 10%에서 시작해서 3초 동안 25%까지 상승한다.

실무 의미:

- 전원 재투입 직후 출력 캐패시터 잔류 전압이 높거나, 반대로 Buck 전압이 아직 충분히 올라오지 않았으면 PWM을 내보내지 않는다.
- 일반 START는 S값 목표 전압 준비가 완료될 때까지 대기하므로 저전압 대전류 구간에서 FET를 몰아붙이지 않는다.
- 과전류 원인 추적 시 START 직전 PA7 전압이 S값 목표 전압 근처인지 먼저 확인한다.

#### 4.10.5 RUN W 보정 메모

RUN 중 W값 자동 보정은 아래 우선순위로 동작하도록 정리한다.

- CH09(2.0MHz)에서는 gate duty 탐색 범위를 15%~40%로 제한한다.
- START 직후 또는 UP/DOWN 변경 직후에는 gate duty를 1% step으로만 움직여 목표 W 접근을 먼저 시도한다.
- 측정 W가 설정값의 10% 이내에 들어오면 추가 자동 보정은 멈추고, 다음 UP/DOWN 입력 또는 장시간 drift 감시로만 다시 시작한다.
- RUN 중 W가 10% band를 3회 연속 벗어날 때만 자동 재튜닝을 재개한다.
- duty만으로 10% band 진입에 실패하면 주파수를 옮긴 뒤 다시 duty를 맞추고, 이 과정을 3회 반복한 뒤에도 실패하면 마지막에만 Buck 전압을 소폭 보정한다.
- START 직후에는 약 80ms 안정화 후 W를 직접 샘플링해서 이미 10% 이내면 retune 예약 자체를 만들지 않는다.
- 주파수 스캔이나 전압 fallback 도중에도 10% band에 들어오는 즉시 더 이상의 추가 탐색을 중단한다.

## 5. 물리적 군집 관점 라우팅 가이드 (64pin)

> 아래 군집은 배선 난이도/길이/크로스토크를 줄이기 위한 권장 배치다.

### 5.1 디스플레이 군집 (하측/우하측 권장)

- PC14, PC15, PB10~PB15
- 20핀 커넥터를 MCU 인접에 배치하고, DATA+CLK를 한 면에서 바로 인출

### 5.2 외부입력 군집 (하측/좌하측 권장)

- PA15, PC10~PC12, PD2
- 광커플러(TLP281-4 + TLP181) 입력단을 같은 영역으로 묶어 GND 리턴 경로 단순화

### 5.3 전력/고속 군집

- HRTIM: PA8/PA9는 UCC21520까지 최단거리
- ADC: PA0/PA1/PA6/PA7은 아날로그 섬으로 분리
- RS-485: PA2/PA3 + PB0/PB1는 트랜시버 근접 배치

## 7. 설계 체크리스트 (64pin)

- [ ] LCD/LED 래치 클럭이 PC14/PC15로 반영되었는지 확인
- [ ] SENSOR 입력이 PD2로 반영되었는지 확인
- [ ] BUZZER가 PC5로 반영되었는지 확인
- [ ] 디스플레이 커넥터가 PC14/15 및 PB10~PB15 근접 배치인지 확인
- [ ] 외부입력 광커플러가 PA15, PC10~PC12, PD2 중심으로 배치되었는지 확인
- [ ] BOOT0(PB8)-J5 점퍼 연결이 의도대로 반영되었는지 확인
- [ ] HRTIM PWM 트레이스(PA8/PA9) 최단거리 배선 확인
- [ ] ADC 입력 라인과 디지털 스위칭 라인 분리 확인
