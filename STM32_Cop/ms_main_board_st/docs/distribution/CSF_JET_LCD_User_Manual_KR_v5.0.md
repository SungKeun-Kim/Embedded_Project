# 1. 적용 범위와 기능 상태

이 문서는 현재 펌웨어의 조작 방법을 설명합니다. 장비의 입력 전원, 출력 정격, 허용 부하, 환경 조건은 장비 명판과 제조사가 승인한 사양을 따릅니다. 화면에서 설정할 수 있는 수치가 모든 노즐·공정에서 허용되는 운전 범위를 뜻하지는 않습니다.

## 현재 적용본에서 확인해야 할 사항

| 항목 | 현재 상태 | 사용 시 의미 |
| --- | --- | --- |
| SENSOR 인터록 | 비활성 | SENSOR가 OPEN이어도 자동 시작 금지·정지를 기대할 수 없음. |
| LOW / HIGH 알람 | 설정 저장 가능<br>알람 정지는 비활성 | LOW/HIGH 값은 출력 프로파일 범위에도 사용됨. 보호 정지 기능으로 사용하지 않음. |
| Auto Tuning | 비활성 | START(3SEC):AUTO 문구가 보여도 자동 튜닝은 시작되지 않음. |
| 자동 주파수 재튜닝 | 비활성 | 승인된 주파수·프로파일을 사용하고 임의 최적화를 기대하지 않음. |
| 알람 / GO / OPERATE 접점 | 현재 코드에 운전·알람 연동 구동 없음 | 외부 PLC의 운전 확인·안전 차단 신호로 사용 전 제조사 검증 필요. |
| TERM / TX RX LED | 종단 하드웨어 전환·통신 LED 연동 없음 | 실제 종단 저항과 통신 응답으로 접속을 확인. |

> SENSOR·알람 접점에 의한 자동 차단이 필요한 설비는 해당 보호 동작을 제조사와 확인한 뒤 사용하세요. 본 문서는 보호 기능을 활성화하거나 장비의 출고 검증을 대신하지 않습니다.

# 2. 버튼과 상태 표시

## 버튼은 현재 화면에 따라 기능이 달라집니다

| 버튼 | 정지 / 선택 화면 | RUN 화면 | 설정 화면 |
| --- | --- | --- | --- |
| START/STOP | 짧게 눌렀다 놓으면 시작 | 짧게 눌렀다 놓으면 정지 | 현재판에서 Auto Tuning 시작 안 함 |
| MODE 짧게 | 초기 화면 → 선택 모드<br>MODE → FREQ CH → 8 POWER | 출력 조정 ↔ 주파수 조정 | 편집 항목 이동 |
| MODE 길게 | 약 1.5초: 설정 메뉴 진입 | 설정 메뉴 진입 안 함 | 하위 설정에서 저장 후 상위 메뉴 복귀 |
| UP / DOWN | 선택 중인 모드·채널 변경 | 선택된 조정값 증가 / 감소 | 편집값 증가 / 감소 |
| SET 짧게 | 확정 및 저장 | 현재 조정 지점 저장<br>저장 중 출력 일시 정지 가능 | 확정 및 저장 |
| SET 길게 | 선택 모드에서 초기 화면 복귀 | 복귀 조작으로 사용하지 않음 | 약 3초 유지: 저장 후 초기 화면 복귀 |

UP/DOWN은 길게 누르면 반복 입력됩니다. START/STOP은 짧게 눌렀다 놓아야 일반 시작·정지 이벤트가 발생합니다. 정지하려고 계속 누르고 있지 마세요.

## LED 읽는 방법

| 표시 | 현재 동작 |
| --- | --- |
| NORMAL / REMOTE / EXT | 선택된 모드의 LED가 정지 중 켜지고 RUN 중 점멸합니다. |
| H/L SET | POWER SET에서 LOW 또는 HIGH를 편집할 때 켜집니다. 알람 발생 표시가 아닙니다. |
| 8 POWER | 8 POWER 선택 또는 POWER SET의 CH/DEF 편집 중 켜집니다. |
| TX RX | 현재 소프트웨어에서 송수신 점멸 표시를 제공하지 않습니다. |

## 비프음

| 소리 | 의미 |
| --- | --- |
| 짧게 1회 | 일반 조작 인식 |
| 길게 1회 | 길게 누름 인식 또는 알람. 화면 표시와 함께 구분. |
| 2회 | SET 저장 성공 |
| 3회 | 저장 실패. 재시도 후에도 반복되면 점검 요청. |

> 기판에 인쇄된 ADDR/BPS 또는 버튼 연결선은 현재 펌웨어의 동시 누름 조작을 뜻하지 않습니다. 통신 조건은 EXT:RS485 메뉴에서 설정하세요.

# 3. LCD 화면과 기본 운전

아래는 표시 형식을 설명하는 예시입니다. 숫자는 장비 상태에 따라 달라집니다. RUN 화면의 회전 표시는 예시에서 *로 나타냈습니다.

정지 기본 화면

```text
0.50W    0000kHz
V12.5 STOP C01
```

RUN 기본 화면

```text
0.48W*   0400kHz
I0040mA V12.5
```

| 표시 | 읽는 방법 |
| --- | --- |
| W | 정지 중: 선택한 프로파일의 설정값. RUN 중: 전류·전압 기반 추정 전력. |
| kHz | 정지 기본 화면은 0000kHz. 채널 설정값은 FREQ CH 선택 화면에서 확인. |
| RUN 주파수 | 하드웨어 설정으로 계산된 출력 주파수. 설정 분해능 때문에 입력값과 조금 다를 수 있음. |
| I / V / C | I=전류 mA, V=정지 시 목표 전압·RUN 시 계측 전압, C=주파수 채널. |

## NORMAL 운전 순서

| 단계 | 조작 |
| --- | --- |
| 1 | 배선·부하·공급 조건을 확인하고 전원을 켭니다. 외부 REMOTE 명령은 OFF로 둡니다. |
| 2 | 정지 화면에서 MODE를 짧게 눌러 선택 모드로 들어갑니다. UP/DOWN으로 NORMAL 선택 → SET. |
| 3 | MODE로 FREQ CH 선택 → UP/DOWN으로 승인된 채널 선택 → SET. |
| 4 | MODE로 8 POWER 선택 → UP/DOWN으로 승인된 PWR 선택 → SET. |
| 5 | START/STOP을 짧게 눌렀다 놓습니다. 시작 전압 준비 후 모드 LED 점멸·계측 표시를 확인합니다. |
| 6 | 정지는 START/STOP을 짧게 눌렀다 놓습니다. STOP 표시와 모드 LED의 연속 점등을 확인합니다. |

> RUN의 W 표시는 교정된 초음파 출력 보증값이 아닙니다. 시작 준비 중에는 연속으로 버튼을 누르지 말고 화면과 알람을 확인하세요.

설정 흐름: STOP → MODE 길게 → SETTING MODE → UP/DOWN으로 메뉴 선택 → SET 진입 → MODE로 항목 이동 → UP/DOWN 변경 → SET 저장 → SET 약 3초로 초기 화면 복귀.

# 4. 설치와 외부 연결

장비 전원을 끈 상태에서 지정된 전원·보호접지·노즐/트랜스듀서·출력 케이블을 연결합니다. 케이블 종류·길이와 부하는 제조사 승인 조건을 따르고, 통풍을 확보하세요. 출력 케이블을 분리한 상태에서 시작하지 마세요.

## 25pin D-SUB 신호표

핀 번호는 참고 매뉴얼 기준입니다. 실제 장비의 커넥터 각인·출고 배선도와 대조하세요. 커넥터 정면과 배선면은 좌우가 바뀌므로 그림의 방향만 보고 연결하지 마세요.

| 핀 번호 | 신호 | 연결 의미 / 현재 적용 상태 |
| --- | --- | --- |
| 1 – 14 | LOW ALARM | 저출력 알람용 릴레이 접점 명칭. 현재 자동 구동 미구현. |
| 2 – 15 | GO | 출력 정상 범위 표시용 접점 명칭. 현재 자동 구동 미구현. |
| 3 – 16 | HIGH ALARM | 고출력 알람용 접점 명칭. 현재 자동 구동 미구현. |
| 6 – 19 | TRANSDUCER | 진동자 알람용 접점 명칭. 현재 자동 구동 미구현. |
| 7 – 20 | OPERATE | 통합 상태용 접점 명칭. 현재 정상/알람 상태 연동 미구현. |
| 9 | COM | REMOTE 및 BCD 입력 공통 |
| 22 | REMOTE | 9번 COM과 접점 연결. REMOTE 모드의 시작/정지 입력. |
| 11 | BCD1 | 8 POWER 선택의 최하위 비트 |
| 23 | BCD2 | 8 POWER 선택의 중간 비트 |
| 10 | BCD3 | 8 POWER 선택의 최상위 비트 |
| 13 – 25 | SENSOR | 정상 신호는 SHORT. 현재 펌웨어에서는 시작/정지 인터록 비활성. |
| 4, 5, 8, 12,<br>17, 18, 21, 24 | N.C. | 연결하지 않음 |
| 커넥터 셸 | SHIELD | 장비 배선도에 따른 쉴드 연결 |

> 현재 적용본의 알람·OPERATE 접점을 장비 안전 차단의 근거로 사용하지 마세요. 접점 정격과 실제 외부 회로 동작은 출고 배선도 및 제조사 확인이 필요합니다.

## RS-485 연결

RS-485 A/B는 전용 통신 단자에 연결합니다. 위 25pin 표에 RS-485 신호를 임의 배정하지 마세요. 마스터와 보드의 극성·주소·속도·패리티를 맞춥니다. 종단 저항은 실제 버스 끝단 하드웨어를 확인하며 패널 TERM 값만으로 연결 여부를 판단하지 않습니다.

# 5. REMOTE 접점 운전

## 외부 시작·정지

| 순서 | 조작 |
| --- | --- |
| 1 | 출력 정지 및 전원 OFF 후 COM(9)과 REMOTE(22)를 승인된 외부 접점 회로에 연결합니다. |
| 2 | REMOTE 접점을 OPEN(OFF)으로 둔 상태에서 전원을 켭니다. |
| 3 | 패널에서 REMOTE를 선택하고 SET으로 저장합니다. 주파수와 출력 프로파일을 확인합니다. |
| 4 | 접점이 OPEN 상태임을 한 번 확인한 뒤 SHORT(ON)하면 시작합니다. |
| 5 | 접점을 OPEN으로 바꾸면 정지합니다. LCD의 STOP을 확인합니다. |

> 전원 투입 또는 REMOTE 모드 진입 시 이미 ON인 접점만으로 시작되지 않을 수 있습니다. 먼저 OFF로 만든 뒤 ON으로 전환하세요. 외부 ON이 유지되면 패널·통신으로 정지한 뒤 다시 시작될 수 있으므로, REMOTE 운전의 정지는 외부 명령도 OFF로 만드세요.

## 외부 8 POWER 선택

접점 1=COM과 SHORT(활성), 0=OPEN(비활성)입니다. BCD라는 명칭을 사용하지만 아래 3비트 조합으로 PWR1~PWR8을 선택합니다.

| BCD3 (10) | BCD2 (23) | BCD1 (11) | 선택 |
| --- | --- | --- | --- |
| 0 | 0 | 0 | PWR1 |
| 0 | 0 | 1 | PWR2 |
| 0 | 1 | 0 | PWR3 |
| 0 | 1 | 1 | PWR4 |
| 1 | 0 | 0 | PWR5 |
| 1 | 0 | 1 | PWR6 |
| 1 | 1 | 0 | PWR7 |
| 1 | 1 | 1 | PWR8 |

외부 PWR 변경은 운전 중에도 반영될 수 있습니다. 일반 운용은 REMOTE OFF → BCD 변경 → 선택 확인 → REMOTE ON 순서로 진행하세요. 외부 접점과 패널에서 동시에 다른 PWR를 선택하지 마세요.

## 확인할 사항

REMOTE LED와 선택 PWR가 의도한 값인지 확인합니다. 시작하지 않으면 접점을 OFF→ON 했는지, 알람이 있는지, 출력 프로파일과 전원 상태가 유효한지 확인하세요. SENSOR가 OPEN인데도 시작되는 현상은 현재 인터록 비활성 상태와 관련됩니다.

# 6. FREQ SET: 주파수 설정

## 기본 주파수 프로파일

| 채널 | 기본 주파수 | 기본 LC BIT |
| --- | --- | --- |
| CH01 | 400 kHz | 0000 |
| CH02 | 600 kHz | 0000 |
| CH03 | 800 kHz | 0000 |
| CH04 | 1,000 kHz | 1111 |
| CH05 | 1,200 kHz | 0000 |
| CH06 | 1,400 kHz | 0000 |
| CH07 | 1,600 kHz | 0000 |
| CH08 | 1,800 kHz | 0000 |
| CH09 | 2,000 kHz | 0001 |
| CH10 | 2,300 kHz | 0000 |

저장값이 있으면 위 기본값보다 우선합니다. CH10 기본값은 현재 2300 kHz입니다. 이전 매뉴얼의 2200 kHz 표와 혼용하지 마세요.

## 채널 선택과 프로파일 편집은 서로 다릅니다

평소에는 정지 선택 화면의 FREQ CH에서 승인된 채널만 선택합니다. 프로파일 자체를 수정할 때 아래 FREQ SET 절차를 사용합니다.

| 순서 | 설정 절차 |
| --- | --- |
| 1 | 정지 화면 → MODE 약 1.5초 → 1.FREQ SET → SET |
| 2 | MODE로 CH → FREQ → BIT 순서로 편집 항목 이동 |
| 3 | CH: UP/DOWN으로 편집할 CH01~CH10 선택 |
| 4 | FREQ: UP/DOWN으로 주파수 조정. 기본 변화 단위 1 kHz, 범위 300~2300 kHz |
| 5 | BIT: 승인된 LC 릴레이 조합 선택. 0000~1111의 16단계 |
| 6 | SET 저장. MODE 길게는 저장 후 상위 메뉴, SET 약 3초는 저장 후 초기 화면 복귀 |

> 주파수·BIT를 바꾸면 편집 중에도 내부 값과 릴레이 미리보기에 반영됩니다. 뒤로 가기는 취소 기능이 아닙니다. 작업 전 값을 기록하고, 승인된 부하·조건에서만 변경하세요.

E는 프로파일의 기대 BIT, A는 제어부에 적용된 BIT 코드입니다. A 표시는 릴레이 접점이 실제로 움직였다는 물리적 피드백이 아닙니다.

# 7. LC BIT와 Auto Tuning 표시

LC BIT는 4개 릴레이의 조합입니다. 왼쪽부터 RELAY4(bit3), RELAY3(bit2), RELAY2(bit1), RELAY1(bit0)이며 1은 ON, 0은 OFF 명령입니다.

| BIT | RELAY4 | RELAY3 | RELAY2 | RELAY1 | 계산 L |
| --- | --- | --- | --- | --- | --- |
| 0000 | OFF | OFF | OFF | OFF | 1.94 µH |
| 0001 | OFF | OFF | OFF | ON | 2.63 µH |
| 0010 | OFF | OFF | ON | OFF | 4.14 µH |
| 0011 | OFF | OFF | ON | ON | 4.83 µH |
| 0100 | OFF | ON | OFF | OFF | 6.64 µH |
| 0101 | OFF | ON | OFF | ON | 7.33 µH |
| 0110 | OFF | ON | ON | OFF | 8.84 µH |
| 0111 | OFF | ON | ON | ON | 9.53 µH |
| 1000 | ON | OFF | OFF | OFF | 8.74 µH |
| 1001 | ON | OFF | OFF | ON | 9.43 µH |
| 1010 | ON | OFF | ON | OFF | 10.94 µH |
| 1011 | ON | OFF | ON | ON | 11.63 µH |
| 1100 | ON | ON | OFF | OFF | 13.44 µH |
| 1101 | ON | ON | OFF | ON | 14.13 µH |
| 1110 | ON | ON | ON | OFF | 15.64 µH |
| 1111 | ON | ON | ON | ON | 16.33 µH |

계산값은 고정 1.94 µH에 각 ON 릴레이의 0.69 / 2.20 / 4.70 / 6.80 µH를 더한 참고값입니다. 실제 부품 공차·배선·부하를 포함한 측정값과 다를 수 있습니다.

BIT 편집 표시 예

```text
START(3SEC):AUTO
BIT:1111 16/16
```

> 현재 적용본에서는 Auto Tuning이 비활성화되어 있습니다. 화면에 START(3SEC):AUTO가 남아 있어도 버튼을 길게 눌러 자동 튜닝할 수 없습니다.

기존 설명서의 AUTO TUNE DONE, NO DETECT, TIMEOUT 운용 절차는 이 적용본의 일반 사용자 절차에 포함하지 않습니다. LC와 주파수 조합은 제조사가 확인한 설정을 사용하세요.

# 8. POWER SET: 출력 프로파일

PWR1~PWR8에는 LOW, HIGH, DEF를 저장합니다. 현재 LOW/HIGH는 출력 조정 범위와 전압 환산에도 사용됩니다. 알람 정지는 비활성 상태이므로, 이 값을 설정했다고 LOW/HIGH 보호가 동작하는 것은 아닙니다.

| 항목 | 의미와 제약 |
| --- | --- |
| CH | 편집할 PWR1~PWR8 |
| LOW | 프로파일 하한. 통상 0.30~2.50 W 안에서 HIGH보다 작게 설정. |
| HIGH | 프로파일 상한. 통상 0.30~2.50 W 안에서 LOW보다 크게 설정. |
| DEF | 프로파일 선택·START 시 사용하는 기본 설정. LOW~HIGH 사이로 제한. |

## 기본값

| POWER | LOW | DEF | HIGH |
| --- | --- | --- | --- |
| PWR1 | 0.30 W | 0.50 W | 2.50 W |
| PWR2 | 0.30 W | 0.75 W | 2.50 W |
| PWR3 | 0.30 W | 1.00 W | 2.50 W |
| PWR4 | 0.30 W | 1.25 W | 2.50 W |
| PWR5 | 0.30 W | 1.50 W | 2.50 W |
| PWR6 | 0.30 W | 1.75 W | 2.50 W |
| PWR7 | 0.30 W | 2.00 W | 2.50 W |
| PWR8 | 0.30 W | 2.25 W | 2.50 W |

## 설정 절차

STOP → MODE 길게 → UP/DOWN으로 2.POWER SET 선택 → SET → MODE로 CH / LOW / HIGH / DEF 이동 → UP/DOWN 변경 → SET 저장.

일반 변화 단위는 0.05 W입니다. LOW < HIGH와 LOW ≤ DEF ≤ HIGH가 유지되도록 다른 값이 함께 보정될 수 있으므로 저장 전에 세 값을 모두 확인하세요. 경계에서는 표시가 일반 변화 단위와 다를 수 있습니다.

DEF 편집 표시 예

```text
P1 CH01 0400k
D:0.50W V12.5
```

> DEF 옆의 V는 설정값에 대응하는 목표 전압입니다. W 설정은 전압으로 환산되어 제어되므로 실제 RUN 추정 전력이 설정 W와 일치한다고 보장하지 않습니다. LOW/HIGH를 바꾸면 같은 DEF에서도 목표 전압이 달라질 수 있습니다.

설정 범위는 실제 장비의 승인 출력 정격을 대신하지 않습니다. DEF를 변경하면 해당 POWER의 기존 조정 지점이 초기화될 수 있으므로 변경 전 기록하세요.

# 9. RUN 중 조정과 저장

## 일반 운전은 승인된 프로파일로 시작합니다

아래 조작은 운전 중 변경이 허용된 작업에서만 사용하세요. RUN 중에는 일반 선택 모드와 설정 메뉴로 들어가지 않으며, 모드·주파수 채널·출력 프로파일 변경은 정지 후 진행합니다.

| RUN 화면 | MODE 짧게 | UP / DOWN |
| --- | --- | --- |
| 기본 계측 화면<br>IxxxxmA Vxx.x | 주파수 조정 화면으로 이동 | 출력 설정 환산값을 0.05 W 단위로 조정하여 목표 전압 변경 |
| 주파수 조정 화면<br>Fxxx.xk CHxx | 기본 계측 화면으로 복귀 | 주파수 명령을 1 kHz 단위로 조정 |

RUN 주파수 조정 예

```text
0.48W*   0400kHz
F400.0k CH01
```

표시되는 주파수는 하드웨어 설정으로 계산하므로 버튼을 한 번 눌러도 표시 변화가 일정하지 않을 수 있습니다. RUN의 W는 계측 추정값이며 UP/DOWN의 설정 증가량과 동일하게 변하지 않을 수 있습니다.

## RUN 중 SET의 의미

현재 선택된 주파수 채널과 PWR 조합에 대해 조정된 주파수·게이트 듀티 지점을 저장합니다. 일반적인 POWER SET의 DEF 또는 현재 목표 전압 전체를 저장하는 조작과는 다릅니다. 정지·재시작하면 프로파일이 다시 적용되므로 운전 조건이 그대로 유지된다고 가정하지 마세요.

> RUN 중 SET 저장 과정에는 출력이 일시 정지된 뒤 다시 시작되는 동작이 포함됩니다. 연속 출력이 필요한 공정 중에는 사용하지 마세요.

## 전압 상한 안내와 알람 구분

조정 상한에 도달한 안내

```text
 BUCK OVER VOLT
LIMIT V38.0
```

위 LIMIT V38.0 화면은 더 이상 목표 전압을 올릴 수 없다는 일시 안내이며, 반드시 보호 정지를 뜻하지는 않습니다. ALARM STOP과 함께 BUCK OVER VOLT가 표시되면 보호 정지이므로 12쪽의 조치를 따르세요.

## 변경 후 확인

전류·전압·추정 전력의 변화를 관찰합니다. 승인 조건을 벗어나거나 이상이 있으면 정지하고 원인을 확인하세요. 정지 후 다음 시작에 사용할 FREQ CH와 PWR를 다시 확인합니다.

# 10. EXT / RS-485 운전

## 패널 통신 설정

출력을 정지하고 패널에서 EXT를 선택 → SET 저장 → MODE 길게 → 3.EXT:RS485 → SET으로 진입합니다. MODE로 BAUD / ADDR / TERM / PARITY를 이동하고 UP/DOWN으로 값을 바꿉니다.

| 필드 | 설정값 | 설명 |
| --- | --- | --- |
| BAUD | 9600 / 19200 / 38400 / 115200 | 통신 속도 bps |
| ADDR | 1~247 | 같은 버스의 장치마다 다른 주소 사용 |
| TERM | OFF / ON | 설정 기록만 수행. 실제 종단 저항 전환 안 함. |
| PARITY | NONE-8-1 / EVEN-8-1 | 데이터 8비트, 정지 1비트 |

통신 설정 예

```text
 EXT:RS485 SET
BAUD:9600
```

설정 변경은 통신에 즉시 반영됩니다. SET으로 저장한 후 설정 화면에서 나오고 PC/PLC의 통신 조건을 동일하게 맞추세요. 기본값은 주소 1 / 9600 bps / NONE-8-1이며 기존 저장값이 있으면 다를 수 있습니다.

## 마스터에서 운전하기

| 순서 | 기능 |
| --- | --- |
| 1. 확인 | 출력 정지, 패널 EXT, 사용할 주파수·출력 프로파일 저장 상태를 확인합니다. |
| 2. 읽기 시험 | FC03 / 실제 주소 0x0000 / 수량 6으로 상태를 읽습니다. |
| 3. 시작 | FC06 / 0x0000에 1. 시작 처리가 끝난 뒤 RUN 상태를 읽습니다. |
| 4. 감시 | RUN과 계측값을 읽습니다. 운전 중 설정 쓰기는 정지를 제외하고 거부됩니다. |
| 5. 정지 | FC06 / 0x0000에 0. RUN=0과 패널 STOP을 확인합니다. |

> 통신이 끊겼다고 자동으로 출력이 정지하지 않습니다. 외부 설비에서 필요한 정지 수단을 확인하세요. RS-485 시작은 패널에 선택된 프로파일을 적용하며 임의 W·주파수 지정 운전 기능과 동일하지 않습니다.

기능 코드·주소·CRC 예제·설정 저장 조건·현재 통신 타이머 제한은 별도 배포한 「RS-485 통신 프로토콜 v1.0」을 참조하세요. 본 매뉴얼의 통신 설명은 기본 조작 요약입니다.

# 11. 알람 표시와 대응

## 현재 사용하는 보호 표시

| LCD 표시 | 의미 | 사용자 조치 |
| --- | --- | --- |
| OVER CURRENT | 과전류 감지 | 출력 정지 확인. 부하·케이블·설정 변경 이력을 기록하고 점검 요청. |
| CUR SENSOR FLT | 전류 센서 이상 또는 포화 감지 | 반복 재시작하지 말고 센서·배선 점검 요청. |
| ALARM STOP<br>LOW START VOLT | 시작에 필요한 전압 준비 실패 | 입력 전원·부하·프로파일 확인. 반복 시 전원부 점검 요청. |
| ALARM STOP<br>BUCK OVER VOLT | Buck 전압 이상 감지 | 전원부·피드백 점검 요청. LIMIT V38.0 안내와 구분. |

과전류 표시 예

```text
OVER CURRENT
I0500mA V28.0
```

과전류·전류 센서 오류 화면의 I/V는 오류 발생 시 기록한 값입니다. 표시값을 현재 정상 운전값으로 해석하지 마세요.

## 원인 확인과 해제

① 외부 REMOTE 명령을 OFF로 하고 출력 정지를 확인합니다. ② 화면과 당시 설정을 기록합니다. ③ 배선 점검이 필요하면 전원을 끄고 제조사 절차에 따라 점검합니다. ④ 원인을 제거한 뒤 알람 화면에서 SET을 짧게 눌러 표시를 해제합니다. ⑤ 재시작 전에 승인된 설정과 외부 명령을 다시 확인합니다.

> SET은 오류 표시를 지우는 조작이며 고장 원인을 고치는 조작이 아닙니다. 같은 알람이 반복되면 재기동을 중단하고 점검을 요청하세요. REMOTE가 ON인 채 알람을 해제하면 다시 시작될 수 있습니다.

## 이 적용본에서 기대하면 안 되는 과거 알람

| 기존 표시 | 현재 상태 |
| --- | --- |
| ERR1 LOW ALARM / ERR2 HIGH ALRM | LOW/HIGH 알람 정지 비활성. 낮거나 높은 출력에 대한 이 알람을 기대하지 않음. |
| ERR7 SNS OFF / ERR8 SNS RUN | SENSOR 인터록 비활성. SENSOR OPEN에 따른 이 알람을 기대하지 않음. |
| ERR5 TRANS ALM / ERR6 SET ERROR | 표시 정의는 있으나 현재 정상 운전 경로의 자동 발생 기능은 확인되지 않음. |

위 과거 표시가 실제 장비에 나타나면 펌웨어 적용본이 이 문서와 같은지 확인하고 제조사에 문의하세요.

# 12. 저장과 문제 해결

## 저장되는 항목

SET으로 저장한 패널 운전 모드, 선택 주파수 채널·PWR, 채널별 주파수·BIT, PWR별 LOW/HIGH/DEF, RS-485 설정은 전원을 껐다 켜도 복원됩니다. 유효한 저장값이 없을 때만 기본값을 사용합니다.

| 항목 | 저장 방법 / 주의 |
| --- | --- |
| 패널 선택·설정 | SET 저장 후 비프 2회 확인. 편집 중 값 변경이 즉시 반영될 수 있고 화면을 나갈 때도 저장될 수 있음. |
| 취소 | 별도 취소 기능 없음. 되돌리려면 기록한 이전 값을 다시 입력하고 저장. |
| RUN 조정 지점 | RUN 중 SET은 주파수·게이트 듀티 지점 저장. 출력이 일시 정지될 수 있음. |
| 통신으로 변경한 값 | 통신 쓰기만으로 영구 저장이 보장되지 않음. 통신 설명서의 저장 동작 확인. |
| 공장 초기화 | 이 적용본에 일반 사용자용 전체 초기화 메뉴 없음. 임의 리셋 조합을 사용하지 않음. |

## 증상별 확인

| 증상 | 확인·조치 |
| --- | --- |
| START를 눌러도 시작 안 됨 | 짧게 눌렀다 놓았는지, 설정 화면이 아닌지, 알람·저장 실패·시작 전압 오류가 있는지 확인. |
| STOP인데 주파수가 0000kHz | 정지 기본 화면의 정상 표시. FREQ CH 선택 화면에서 설정 주파수 확인. |
| START(3SEC):AUTO가 동작 안 함 | 현재 Auto Tuning 비활성. 수동 프로파일 사용. |
| SENSOR를 열어도 정지 안 됨 | 현재 인터록 비활성. 이 입력을 안전 정지 수단으로 사용하지 않음. |
| LOW/HIGH를 넘겨도 알람 없음 | 현재 LOW/HIGH 알람 정지 비활성. 외부 확인 및 제조사 문의. |
| REMOTE에서 시작 안 됨 | REMOTE 모드·9/22 접점·OFF→ON 전환·현재 알람 확인. |
| 정지 후 다시 시작됨 | REMOTE ON 유지 여부 확인. 외부 RUN 명령부터 OFF. |
| RS-485 응답 없음 | A/B, 주소, 속도, 패리티, 정지 1비트, 실제 종단 구성 확인. |
| 저장값이 복원되지 않음 | SET 성공음·현재 편집 채널 확인. 3회 비프가 반복되면 저장부 점검 요청. |
| RUN W와 설정 W가 다름 | 설정값의 전압 환산과 계측 추정값 차이. 승인 운전 조건·측정 상태 확인. |
