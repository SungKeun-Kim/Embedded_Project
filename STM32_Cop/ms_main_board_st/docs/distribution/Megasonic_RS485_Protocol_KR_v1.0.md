# 1. 연결과 최초 설정

## 배선 및 패널 설정

PC의 USB–RS-485 변환기 또는 PLC의 RS-485 포트를 보드의 RS-485 A/B 단자에 연결합니다. A/B의 극성 명칭은 장치마다 다를 수 있으므로 양쪽 제품의 신호 정의를 맞추세요. 커넥터 핀 번호와 신호 기준선 연결은 해당 보드 회로도·배선도를 따릅니다.

```text
PC / PLC (마스터)  ── RS-485 A/B ──  메가소닉 보드 (슬레이브)
```

PA2/PA3는 MCU와 트랜시버 사이의 UART 신호이며 외부 A/B 단자가 아닙니다. 종단 저항은 버스 양 끝 장치의 실제 하드웨어 구성으로 확인합니다. 패널 TERM ON/OFF는 현재 설정 기록만 수행하며 저항을 전기적으로 전환하지 않습니다.

| 순서 | 조작 |
| --- | --- |
| 1 | 출력을 정지하고 패널 MODE에서 EXT를 선택한 뒤 SET으로 저장합니다. |
| 2 | 정지 화면에서 MODE를 길게 눌러 SETTING MODE로 진입하고 3.EXT:RS485를 선택합니다. |
| 3 | MODE로 BAUD → ADDR → TERM → PARITY 항목을 이동하고 UP/DOWN으로 수정합니다. |
| 4 | SET으로 저장한 뒤 설정 화면에서 나옵니다. PC/PLC도 같은 조건으로 맞춥니다. |

> 패널에서 BAUD·ADDR·PARITY를 변경하면 통신에 즉시 반영됩니다. 설정 도중 마스터의 접속이 끊길 수 있습니다.

## 지원 통신 조건

| 항목 | 현재 구현 |
| --- | --- |
| 주소 | 1~247. 주소 0 브로드캐스트는 처리하지 않음. |
| 통신 속도 | 9600 / 19200 / 38400 / 115200 bps |
| 데이터 / 정지 비트 | 데이터 8비트, 정지 1비트 고정 |
| 패리티 | 패널: None 또는 Even. 레지스터: None / Even / Odd |
| 흐름 제어 | 없음. 송수신 방향은 보드가 자동 전환. |

## 첫 읽기 시험

마스터에서 Holding Registers(FC03), 시작 주소 0, 수량 6을 선택합니다. 연결 시에는 출력 시작 명령 없이 읽기만 시험하세요. 예제 요청은 다음과 같습니다.

```text
01 03 00 00 00 06 C5 C8
```

응답의 데이터 12바이트는 순서대로 RUN, 목표 주파수, Buck 목표값, 주파수 읽기, 현재 Buck 제어값, 상태 플래그입니다. 값의 의미는 3장을 참조하세요.

# 2. 프레임과 통신 처리

## 바이트 형식

```text
[주소 1B] [기능 1B] [데이터 N B] [CRC Low 1B] [CRC High 1B]
```

모든 레지스터는 unsigned 16-bit입니다. 레지스터 주소·수량·값은 상위 바이트부터 보내고, CRC만 하위 바이트부터 보냅니다. 예제의 01 03 등은 16진수 바이트이며 ASCII 문자열이 아닙니다.

CRC-16/Modbus: 초기값 0xFFFF, 반전 다항식 0xA001. CRC는 주소부터 데이터 마지막 바이트까지 계산합니다.

| 기능 | 요청 데이터(CRC 앞) | 정상 응답 데이터(CRC 앞) |
| --- | --- | --- |
| 03 읽기 | 시작 주소(2B) + 수량(2B) | 바이트 수(1B) + 값(2B × 수량) |
| 06 단일 쓰기 | 주소(2B) + 값(2B) | 요청 8바이트 전체를 그대로 에코 |
| 10 다중 쓰기 | 시작 주소(2B) + 수량(2B) + 바이트 수(1B) + 값들 | 시작 주소(2B) + 수량(2B) |

## 요청 크기와 주소 범위

FC03은 수량 1~61을 검사하지만 모든 주소가 실제로 존재해야 합니다. 읽기 가능한 연속 구간은 0x0000~0x000B(12개), 0x0010~0x0019(10개)입니다. 0x000C~0x000F를 가로지르는 요청은 실패합니다.

FC10은 RX 버퍼 128바이트 안에서 사용해야 하므로 전송 수량 상한은 59개(9+2×59=127바이트)입니다. 이는 주소 59개가 지원된다는 뜻이 아닙니다. 실제 쓰기 가능 구간과 운전 조건을 모두 만족해야 합니다.

> FC10은 앞 레지스터부터 순서대로 적용합니다. 뒤에서 오류가 나도 앞에서 변경된 값은 되돌리지 않습니다. 시작·정지·통신 설정·리셋은 FC06으로 각각 전송하세요.

## 마스터 운용 시작값

| 항목 | 연동 시험용 권장 시작값 |
| --- | --- |
| 요청 간격 | 한 번에 한 요청만 전송. 응답 완료 후 최소 10 ms 유휴. |
| 상태 폴링 | 200 ms 간격부터 시작하여 실측 후 조정. |
| 읽기 응답 대기 | 1000 ms부터 시작. 최대 응답 시간 보장값은 아님. |
| START 응답 대기 | 5000 ms부터 시작. 선충전 대기(최대 2500 ms)·설정 저장 등이 포함됨. |

프레임의 바이트는 중간 지연 없이 한 번에 전송하세요. START 응답이 늦어도 다른 요청을 겹쳐 보내지 마세요. 응답 누락 시 통신을 복구하고 RUN 상태를 읽어 결과를 확인합니다. 현재 타이머 제한은 8장에 설명합니다.

# 3. 운전 레지스터

주소는 실제 프레임에 넣는 0 기반 주소입니다. 괄호는 십진수입니다. R=FC03 읽기, W=FC06/FC10 쓰기. W는 아래 표와 별개로 운전 중 제한을 받습니다.

| 주소<br>(십진수) | 권한 | 항목 | 값 / 단위 | 설명 |
| --- | --- | --- | --- | --- |
| 0x0000<br>(0) | R/W | 출력 RUN/STOP | 0=정지, 1=시작 | 읽기: 운전 상태. 시작은 EXT에서만 허용. |
| 0x0001<br>(1) | R/W | 목표 주파수 | 3000~23000<br>×0.1 kHz | 4000=400.0 kHz. 채널 번호가 아님. |
| 0x0002<br>(2) | R/W | Buck 제어 목표값 | 0~1000<br>×0.1% | 901~1000 입력은 900으로 제한. 게이트 PWM 듀티가 아님. |
| 0x0003<br>(3) | R | 주파수 읽기 | ×0.1 kHz | 0x0001과 같은 목표값. 실측 주파수가 아님. |
| 0x0004<br>(4) | R | 현재 Buck 제어값 | ×0.1% | 소프트 스타트·추종 중의 current_duty. |
| 0x0005<br>(5) | R | 상태 플래그 | 비트 필드 | bit0=RUN, bit1=소프트 스타트. |
| 0x0006<br>(6) | R/W | 제어부 운전 모드 | 0=NORMAL<br>1=REMOTE, 2=EXT | 패널 선택 모드·저장값과 자동 동기화되지 않음. |
| 0x0007<br>(7) | R/W | 펄스 ON 시간 | 100~60000 ms | 호환용 보관값. 현재 펄스 동작 미구현. |
| 0x0008<br>(8) | R/W | 펄스 OFF 시간 | 100~60000 ms | 호환용 보관값. 현재 펄스 동작 미구현. |
| 0x0009<br>(9) | R/W | 스윕 시작 주파수 | 3000~23000<br>×0.1 kHz | 호환용 보관값. 현재 스윕 동작 미구현. |
| 0x000A<br>(10) | R/W | 스윕 종료 주파수 | 3000~23000<br>×0.1 kHz | 시작값과 종료값의 대소 관계 검사 없음. |
| 0x000B<br>(11) | R/W | 스윕 시간 | 500~60000 ms | 호환용 보관값. 현재 스윕 동작 미구현. |

> 운전 중에는 0x0000=0(정지)만 쓸 수 있습니다. 운전 중 0x0000=1을 다시 보내도 예외 0x02가 반환됩니다. 읽기는 운전 모드와 무관하게 허용됩니다.

## 주소 표기와 단위

40001 형식을 사용하는 마스터라면 표시 번호=40001+실제 주소입니다. 예: 0x0000 → 40001, 0x0006 → 40007, 0x0010 → 40017. 통신 프레임에는 40001을 그대로 넣지 않습니다. 도구가 0 기반인지 1 기반인지 확인하세요.

주파수 4000은 400.0 kHz, Buck 제어값 450은 45.0%입니다. Buck 값은 전력[W]이나 실제 FET 게이트 듀티가 아닙니다. 0x0001·0x0002의 값은 START/STOP에서 패널 프로파일로 다시 설정될 수 있습니다.

| 주소<br>(십진수) | 권한 | 항목 | 값 / 단위 | 설명 |
| --- | --- | --- | --- | --- |
| 0x0010<br>(16) | R/W | 슬레이브 주소 | 1~247 | 쓰기 직후 새 주소 적용. |

| 0x00FF<br>(255) | W | MCU 재시작 | 0x1234 | 정지 상태에서 즉시 리셋. 정상 응답 보장 없음. |

## 계측값 읽는 방법

0x0013부터 7개를 읽으면 전류 raw·센서 핀 전압·전류 mA·전압 raw·추정 전력·순방향 raw·반사 raw를 한 번에 얻습니다. 0x0017은 펌웨어 버전이 아니라 추정 전력입니다.

0x0017은 전류 영점 보정, 무신호 판정, 작은 전류 무시, 9.99 W 상한 처리를 포함합니다. 순방향/반사 RF 전력의 교정된 측정값이나 실제 초음파 출력 보증값으로 해석하지 마세요.

## 현재 제공하지 않는 항목

전력[W] 목표값 쓰기, 주파수/출력 채널 선택, LC 릴레이 선택, 알람 상세 코드·리셋, 실제 게이트 듀티, 펌웨어 버전, 통신 종단 제어, 명시적 Flash 저장 명령은 현재 레지스터 맵에 없습니다.

0x00FF는 읽기 불가입니다. 이 표와 3장에 없는 주소는 사용하지 마세요.

# 5. 운전 순서와 저장 동작

## 권장 연동 순서

| 단계 | 동작 |
| --- | --- |
| 1. 패널 준비 | 정지 상태에서 EXT 모드와 사용할 주파수·출력 프로파일을 선택하고 저장합니다. 설정 화면에서 나옵니다. |
| 2. 통신 확인 | FC03으로 0x0000(RUN), 0x0005(상태), 0x0006(모드=2)를 확인합니다. |
| 3. 출력 시작 | FC06으로 0x0000=1 전송. 정상 응답 뒤 RUN과 소프트 스타트 상태를 읽습니다. |
| 4. 운전 감시 | RUN·상태·계측값을 폴링합니다. RUN=0이면 LCD의 알람·운전 상태도 확인합니다. |
| 5. 출력 정지 | FC06으로 0x0000=0 전송. FC03으로 RUN=0을 확인합니다. |

START는 알람, SENSOR 입력, 전류 센서 상태, 설정 저장, Buck 선충전 등 내부 조건을 통과해야 성공합니다. 성공 응답은 그 시점의 시작 처리를 뜻하며 이후 보호 정지까지 보장하지 않습니다.

## 접근 제한

| 상태 / 명령 | 현재 코드 동작 |
| --- | --- |
| 읽기 | 모든 모드에서 허용. |
| 정지 상태의 설정 쓰기 | NORMAL·REMOTE·EXT 모두에서 주소·값이 유효하면 허용. |
| 출력 시작(0x0000=1) | 정지 상태이고 제어부 모드가 EXT일 때만 허용. |
| 운전 중 쓰기 | 0x0000=0만 허용. 나머지는 예외 0x02. |

> 0x0006 쓰기는 제어부 모드만 바꾸며 패널의 선택 모드와 저장값을 함께 바꾸지 않습니다. REMOTE 접점 동작과 충돌하지 않도록 실제 운전 모드는 패널에서 EXT로 설정하세요.

## 설정 유지 및 전원 재투입

Modbus 쓰기 자체는 Flash 저장을 요청하지 않습니다. 통신 주소·속도·패리티는 나중에 패널 저장이나 START 전 저장 경로에 포함될 수 있으므로, 항상 휘발성 또는 항상 영구 저장이라고 가정하면 안 됩니다. 영구 통신 설정은 패널에서 설정·저장 후 전원을 재투입하여 확인하세요.

직접 쓴 주파수·Buck 목표값은 패널 프로파일을 편집하지 않습니다. START에서 선택된 출력 프로파일을 적용하면서 두 값이 다시 설정되고, STOP에서도 선택된 주파수·출력 프로파일이 적용됩니다. 통신만으로 임의 주파수·전력을 지정해 운전하는 용도로 사용하지 마세요.

# 6. 정상 요청·응답 예제

모든 예제는 슬레이브 주소 1 기준이며 CRC를 포함합니다. 실제 설정과 다르면 주소를 바꾸고 CRC를 다시 계산해야 합니다.

## 6.1 상태 플래그 1개 읽기

```text
요청: 01 03 00 05 00 01 94 0B
응답 예: 01 03 02 00 00 B8 44
```

응답 예는 정지·소프트 스타트 아님(0x0000)입니다. 상태값 0x0001=RUN, 0x0003=RUN+소프트 스타트. bit2~15는 현재 0이며 알람 상세나 통신 활성 상태로 사용할 수 없습니다.

## 6.2 통신 설정 3개 읽기

```text
요청: 01 03 00 10 00 03 04 0E
기본 설정 응답: 01 03 06 00 01 00 00 00 00 1C B5
```

데이터 0001 / 0000 / 0000은 주소 1 / 속도 인덱스 0(9600) / 패리티 0(None)을 뜻합니다.

## 6.3 계측값 7개 읽기

```text
요청: 01 03 00 13 00 07 F5 CD
```

응답: 01 03 0E 뒤에 레지스터 값 7개(14바이트), 마지막에 CRC 2바이트가 옵니다. 예를 들어 0x0015의 값 00 7B는 123 mA, 0x0017의 값 00 32는 0.50 W입니다.

## 6.4 출력 정지

```text
요청 및 정상 응답: 01 06 00 00 00 00 89 CA
```

모든 모드에서 허용됩니다. 통신 프레임이 처리될 때 정지하므로 통신 불능 시에는 실행할 수 없습니다. REMOTE에서 외부 RUN 접점이 활성 상태이면 정지 후 다시 시작될 수 있습니다. 정지 후 RUN을 다시 읽으세요.

## 6.5 출력 시작

```text
요청 및 정상 응답: 01 06 00 00 00 01 48 0A
```

전제: 패널 EXT 선택·저장, 정지 상태, 유효한 프로파일과 시작 조건. 조건을 만족하지 않으면 예외 0x02입니다. 응답 대기 중 START를 반복 전송하지 마세요.

# 7. 설정 쓰기와 예외 예제

## 7.1 단일 레지스터 쓰기 형식

```text
목표 주파수 400.0 kHz 요청/응답: 01 06 00 01 0F A0 DD 82
```

정지 상태에서만 허용됩니다. 0x0FA0=4000입니다. 이는 레지스터 형식 예제이며 다음 START에서 주파수가 유지된다는 뜻은 아닙니다. START는 패널 프로파일을 다시 적용합니다.

## 7.2 여러 레지스터 쓰기 형식

```text
요청: 01 10 00 07 00 02 04 03 E8 03 E8 32 87
응답: 01 10 00 07 00 02 F0 09
```

0x0007·0x0008에 각각 1000 ms를 저장하는 형식 예제입니다. 정지 상태에서만 허용되며 현재 펄스 출력 기능은 실행되지 않습니다.

## 7.3 예외 응답

```text
[주소] [요청 기능 OR 0x80] [예외 코드] [CRC Low] [CRC High]
```

| 코드 | 현재 반환 조건 |
| --- | --- |
| 0x01 | 미지원 기능. 예: FC04, FC05 등. |
| 0x02 | 잘못된 읽기 주소 또는 쓰기 실패. 범위 오류·읽기 전용 주소·운전 중 제한·시작 거부도 포함. |
| 0x03 | 프레임 최소 길이 부족, FC03 수량 0 또는 61 초과, FC10 수량/바이트 수/길이 오류. |

| 예 | 요청 → 응답 (CRC 포함) |
| --- | --- |
| 없는 주소 읽기 | 01 03 00 0C 00 01 44 09<br>→ 01 83 02 C0 F1 |
| 범위 초과 쓰기<br>Buck 값 1001 | 01 06 00 02 03 E9 E9 74<br>→ 01 86 02 C3 A1 |
| 수량 0 읽기 | 01 03 00 00 00 00 45 CA<br>→ 01 83 03 01 31 |

CRC 불일치, 다른 슬레이브 주소, 주소 0, 4바이트 미만 프레임은 응답 없이 무시합니다. 예외 0x02만으로 알람 원인을 구분할 수 없으므로 LCD와 RUN 상태를 함께 확인하세요.

# 8. 현재 구현의 제한과 문제 해결

## 통신 설정 변경 시 주의

주소(0x0010)는 쓰기 처리 중 즉시 변경됩니다. FC06 정상 응답은 요청을 복사하므로 이전 주소로 돌아오고 다음 요청부터 새 주소를 사용합니다. 속도(0x0011)와 패리티(0x0012)는 정상 응답을 보내기 전에 UART가 변경되어 마스터가 응답을 놓칠 수 있습니다. 한 항목씩 변경하고 새 설정으로 재접속하여 읽어 확인하세요.

Odd(2)는 UART에서 즉시 사용할 수 있지만 패널의 정규화·저장·복원 경로에서는 None(0)으로 바뀝니다. 지속 사용은 패널이 지원하는 None 또는 Even으로 맞추세요. 재시작(0x00FF=0x1234)은 응답을 보내기 전에 리셋되며 전원 투입 때처럼 저장된 설정을 복원합니다.

## 프레임 타이밍 제한

현재 시스템은 170 MHz인데 TIM4 분주값은 72 MHz를 전제로 한 71로 고정되어 있습니다. 따라서 코드가 의도한 3.5문자 유휴시간과 실제 타임아웃이 일치하지 않습니다. 연속된 바이트 전송을 사용하고 프레임 중간에 지연을 넣지 마세요. 정확한 프레임 경계·최대 응답 시간·통신 호환성은 보드에서 실측해야 합니다.

통신 단절 자동 정지 타이머는 현재 Modbus 경로에 없습니다. RUN=0과 실제 알람 종류는 별개이고, 상태 bit2도 알람 표시로 구현되어 있지 않습니다. 통신 연결 상태나 알람 유무를 예약 비트로 판단하지 마세요.

## 증상별 확인

| 증상 | 확인할 내용 |
| --- | --- |
| 응답 없음 | 주소·속도·패리티·정지 1비트, A/B 극성, 실제 종단 배치, CRC, 단일 마스터 여부. |
| 통신이 간헐적으로 끊김 | 프레임을 한 번에 전송하는지, 요청이 겹치는지, 바이트 사이 지연·타이머 영향이 있는지 확인. |
| 읽기 예외 0x02 | 미정의 주소 0x000C~0x000F 또는 0x00FF를 읽는지 확인. |
| 쓰기 예외 0x02 | RUN 여부, 쓰기 가능 주소와 범위, START의 EXT·센서·알람 조건 확인. |
| START 후 설정값이 달라짐 | 패널 프로파일 재적용 동작. 0x0001·0x0002 직접 쓰기는 프로파일 편집이 아님. |
| 재부팅 후 통신 조건이 달라짐 | Modbus 쓰기의 저장 보장 없음, Odd→None 정규화, 패널 저장 상태 확인. |

> 현재 구현의 제한을 문서화한 것이며 펌웨어를 변경한 것은 아닙니다. 현장 연동은 읽기 시험 → 정지 시험 → 준비된 프로파일로 시작 시험 순서로 확인하세요.

## 기존 문서와 혼용하면 안 되는 항목

기본값은 8N1이며 None에서 정지 2비트가 아닙니다. 주파수 레지스터는 채널 번호가 아닌 ×0.1 kHz입니다. 정지 중 설정 쓰기는 EXT 외 모드에서도 허용됩니다. 쓰기 값 범위 오류는 현재 예외 0x02이며, 상태 알람 비트·전력 설정·버전 읽기 등 과거 문서의 항목은 현재 제공되지 않습니다.
