# v4.6 현장시험 — 최대출력 점화 하한 168기준틱

작성일: 2026-10-16

기존 128틱 펌웨어에서 **장비 화면 표시 약83%부터 상단 전압이 흔들렸다**는 사용자 관찰에 따라,
v4.5의 최대출력 점화를 133에서 **168기준틱**으로 늦춘 비교시험 버전이다.
보정 2를 포함하면 최대출력 점화 위상은 170/332이다.
저출력·중출력 입력 곡선은 v4.5 그대로 두고, 더 이른 점화 요청만168에서 제한한다.

## 화면 표시값을 사용한 계산

83%는 실제 PWM 듀티나 소비전력이 아니라 화면 설정값이라는 사용자 확인을 반영했다.
처음 검토한 `308 - (308-128)*0.829 = 158.78`은 조광 유효 범위를 직접0~100%로
환산한다는 전제의 계산이므로 **최종168틱 선정에는 사용하지 않았다**.

동봉된 주제어기 참고 소스 `TSO_16A/init_adc.c`의 `pl_display()` 및 `pl_disp_te()`:

```text
input = floor(ad_data[0] / 10), 최대90
화면 표시 = input + 10                   (10~100, 정수 표시)
OCR2 = floor(input * (253-25) / 90) + 25
```

`TSO_16A/init_time.c`는 Timer2 위상보정 PWM을 선택한다.
참고 코드가 현장 주제어기와 같다는 전제에서 듀티는 OCR2/255로 계산한다.
이 표시 체계에는82.9라는 별도 단계가 없으므로,83보다 아래의 실제 표시 단계 **82**를 시험 기준으로 잡았다.

| 화면 설정 | input | OCR2 | 추정 PWM 듀티 |
|---|---:|---:|---:|
| 82 | 72 | 207 | 81.1765% |
| 83 | 73 | 209 | 81.9608% |
| 100 | 90 | 253 | 99.2157% |

현재 ATtiny85의 ADC 설정은5V 기준61~880(약0.3~4.3V)이고,
이전 설명에는 PWM을 반전한 뒤 평활하는 회로가 기록되어 있다.
현장 입력 전압을 새로 측정한 것은 아니므로 다음 **전압 모델**을 사용한다.

```text
HIGH=5.0V, LOW=0.3V인 반전 PWM을 이상적으로 평활한다고 가정:
Vadc = 5.0*(1-D) + 0.3*D

화면82: D = 207/255
Vadc = 1.184706V
ADC  = Vadc/5*1023 = 242.390824

기존128틱 버전의332틱 기준 연속 근사:
phase = 128 + (ADC-61)*(308-128)/(880-61)
      = 167.866115
늦은 방향으로 올림 -> 168기준틱
```

LOW를0.2V로 가정하면 같은 화면82의 추정치는164.22기준틱이다.
두 모델 중 더 늦은0.3V 모델의168을 시험값으로 택했다.
실제 입력 회로의 저레벨/고레벨/리플/이득, VCC, 주제어기 버전은 아직 실측·대조하지 않았다.
따라서168은 **화면82% 부근을 목표로 한 보수적 추정 시험값**이며,
실제 화면82.9%와 정확히 같다는 보정값이나 전력82.9%를 보장하는 값이 아니다.
기존 펌웨어의2단계 정수변환, 반주기 보정 및 ISR 차이도 있어 완전히 같은 파형을 재현한다고 단정하지 않는다.

## 변경 내용

```text
v4.5 입력 위상 = 133 + floor((ADC-61)*175/819), 범위 밖은133/308에 포화
v4.6 실제 요구 위상 = max(v4.5 입력 위상, 168)
ADC>=900이면 기존과 같이OFF
```

`MIN_DIM_BASE=168`은 실제 점화의 하한이고 `INPUT_MIN_DIM_BASE=133`은 기존 입력 곡선의 기준이다.
전체 볼륨 구간을168~308로 다시 비례 배분하지 않는다.
따라서 상단에서는 볼륨을 더 올려도 출력이 더 증가하지 않는 구간이 생긴다.
그 구간이 화면에서 정확히 어디부터인지도 입력 회로에 따라 달라진다.
ADC0~224의 목표 위상은168이고,ADC225부터 기존 v4.5 곡선이 이어진다(225에서도168).

- v4.5 대비 최대출력 점화 지연 증가: **35기준틱**.
- 최초128 기준 대비 지연 증가: **40기준틱**.
- 기준값 분모332, offset2, 최저출력308, 기본 펄스20, 종료 여유16 유지.
- 부팅 대기1초,8반주기 동기화,ADC899 ON/900 OFF,출력 상승 제한 및 신호 손실 차단 유지.
- 저출력의 단축 게이트 펄스와 입력 곡선 유지.
- 주제어기 소스 및 퓨즈 E2/DF/FF 변경 없음.

## 실제 점화 시간

아래는 **PB2 검출 상승엣지 기준**이며 실제 AC 0V와 동일한 기준점은 아니다.
틱 시간을 주파수에 따라 바꾸는 것이 아니라 실측 반주기에 비례해 계산한다.

| 명목25µs 틱의 예시 | v4.5 점화 | v4.6 점화 | 늦춰진 시간 | v4.6 게이트 폭 |
|---|---:|---:|---:|---:|
| 약60Hz, 반주기333틱 | 135틱 / 3.375ms | 171틱 / 4.275ms | 0.900ms | 20틱 / 0.500ms |
| 50Hz, 반주기400틱 | 163틱 / 4.075ms | 205틱 / 5.125ms | 1.050ms | 24틱 / 0.600ms |

반올림을 생략한 정확한 주파수별 위상 환산에서는60Hz 약0.879ms,50Hz 약1.054ms 늦다.
333틱 예시의 종료는191틱이며 다음 검출까지142틱(명목3.55ms)이 남는다.
400틱 예시의 종료는229틱이며171틱(명목4.275ms)이 남는다.

고출력의 기존128+2도 기준상 검출 후 약3.25ms에 점화하므로,
화면83%에서 흔들렸다는 사실만으로 제로크로스와 게이트가 겹쳤다고 확정할 수 없다.
최대출력의 점화를 늦추면 현재 반주기의 초반에서는 멀어지지만 다음 검출까지 여유는 오히려 줄어든다.
이번 변경 목적은 출력 상단을 낮춰 증상 변화 여부를 비교하는 것이다.
MOC3021 계열은 임의 위상 구동용이지만 실제 부하 점화·유지 조건은 별도이다.
[onsemi MOC3021 계열 데이터시트](https://www.onsemi.com/pdf/datasheet/moc3023m-d.pdf).

## 빌드·검증

- AVR GCC7.3.0 / Atmel AVR5.1.0 / ATTiny Arduino1.5.2로 클린 빌드.
- Flash2,134/8,192바이트,정적RAM46/512바이트(스택 별도).
- 새 ELF 검사: ISR133 + 원자구간32 + 진입 등10 =175/200CPU클럭.
- w64devkit GCC16.1.0으로 **현재 소스를 포함한 호스트 시험을 새로 컴파일**하여 실행.
- 주파수/클럭/입력60조합,검출폭60조합,응답24조합,250~500틱 ×141위상 종료 여유 통과.
- ADC0~1023 전 범위에서168 제한,기존 하단 곡선 일치,ON/OFF 경계 및50/60Hz 최대출력 펄스 확인.
- 현재 시험 소스를 새로 컴파일한 simavr1.7로 새 AVR 바이너리42조합 모두 통과(종료코드0).
  50/60Hz × CPU6.8/8.0/9.2MHz × 최대/최소 출력 × 검출폭3종의36조합과,
  ON 경계4390mV 입력6조합을 검사했다. Timer1 모델 보완 및 아날로그 부하 미모사 한계는 test/README 참고.
- MCU 기록 및 실제 부하 시험은 수행하지 않았다. 기존v4.5 시험 통과를v4.6 시험으로 대신하지 않는다.

호스트 컴파일러는 [w64devkit 공식 배포](https://github.com/skeeto/w64devkit/releases/tag/v2.8.0)에서
받아 SHA256을 확인한 뒤 프로젝트 `.pio/host-tools` 안에만 풀었다. 시스템PATH는 영구 변경하지 않았다.

## 현장 비교

1. 새 HEX 이름의 **v4_6 / 168Tick / Cap**을 확인한다. v4.5 롤백 파일은 별도로 보관한다.
2. 같은 장비·부하·전원 조건에서 표시50,80,82,83,85,90,100을 비교한다.
3. 상단에서 볼륨을 올려도 전압이 증가하지 않는 것은 제한 기능의 정상 결과다.
4. 낮은 출력 시작,START/STOP/재START,운전 중 볼륨 변경도 확인한다.
5. 흔들림이 남으면 표시값과 함께 가능할 때PB3 DC전압,VCC,PB2-PB0 지연/폭을 기록한다.
   이 값으로 화면 표시와 실제 점화의 대응을 보정할 수 있다.
6. 실제50Hz 부하 동작은 별도 확인한다. 시뮬레이션은 아날로그 회로/부하를 모사하지 않는다.

직전v4.5 소스·HEX·시험은 `backup/v4_5_before_max_output_limit/`에 보관했다.
