# v4.8 — 최대출력143기준틱

2026-10-16

사용자가140틱(v4.7) 시험에서 DC전압이20V 이상 회복되었다고 보고했다.
그 결과를 기록하고 요청에 따라 최대출력 지연 하한을 **140 -> 143기준틱**으로 조정했다.
전압 회복 보고를 흔들림 해소나 실제50Hz 검증 완료로 해석하지 않는다.

## 변경 범위

실행 로직에서 변경한 설정은 `MIN_DIM_BASE`의140 -> 143이다.
v4.5 입력곡선133~308을 유지하면서143보다 이른 점화만143으로 제한한다.
보정2,최저출력308,기본펄스20,종료여유16,ON899/OFF900,부팅/동기화/보호 동작은 동일하다.
반주기마다 최대10기준틱씩 출력을 올리는 동작도 유지한다.
새 최대출력 위상은 **(143+2)/332 = 145/332**이다.

| 명목25µs 타이머 예시 | 약60Hz /333틱 | 50Hz /400틱 |
|---|---:|---:|
| v4.7(140) 최대출력 점화 | 3.550ms /142틱 | 4.275ms /171틱 |
| **v4.8(143) 최대출력 점화** | **3.625ms /145틱** | **4.375ms /175틱** |
| v4.7 대비 추가 지연 | **75µs** | **100µs** |
| 최대출력 게이트 폭 | 0.500ms /20틱 | 0.600ms /24틱 |
| 최대출력 게이트 종료 | 4.125ms /165틱 | 4.975ms /199틱 |
| 게이트 종료 후 다음 검출까지 | 4.200ms /168틱 | **5.025ms /201틱** |

시간 기준은PB2 검출 상승엣지이며 실제AC0V와 같다는 뜻은 아니다.
위 값은 정수 반올림 예시다. 반올림 전 위상비로 계산하면 추가지연은60Hz 약75.3µs,50Hz 약90.4µs다.
143은 고정 대기 틱 수가 아닌332분모 기준값으로,50/60Hz 모두 실측 반주기에 비례한다.
50Hz의 종료 여유는 위 표와 같으며,실제 부하/DC리플/점화 성공의 확인 범위는
`v4_7_140틱_50Hz_검토.md`의 한계를 동일하게 적용한다.143의 실제 전압 변화량은 단정하지 않는다.

## 검증

- 새 소스 클린 빌드: Flash2134/8192바이트,정적RAM46/512바이트(스택 별도).
- 새 ELF의 ISR 시간:133 + 원자구간32 + 진입 등10 =175/200CPU클럭.
- 현재 소스를 포함한 호스트 시험을 새로 컴파일하여 실행했다.
- 주파수/클럭/입력60조합,검출폭60조합,응답24조합 및ADC1024단계143 제한 통과.
- 반주기250~500틱 × 위상143~308(166단계)의 종료 여유 통과.
- 저출력 곡선,ON/OFF 경계,동기화 손실/복구,START/STOP/재START,점화 순간 노이즈 차단 통과.
- 현재 시험 소스를 재컴파일한 simavr에서 새 AVR 바이너리42/42조건 통과,종료코드0.
  50/60Hz × CPU6.8/8.0/9.2MHz × 최대/최소출력 × 검출폭3종의36조건과,
  ON경계4390mV 입력6조건을 확인했다. 로그는 배포 패키지에 포함한다.
- MCU 업로드 및 실제143틱 부하 시험은 수행하지 않았다.

직전140틱 소스·HEX·시험 코드는 `backup/v4_7_before_cap143/`에 보관했다.
배포 파일 이름의 **v4_8 / 143Tick**을 확인하고 SmartProg에서 기록 후 Verify한다.
퓨즈E2/DF/FF는 동일하며 HEX에 포함되지 않는다.
