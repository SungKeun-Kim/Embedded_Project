# v4.9 — 최대출력150기준틱

2026-10-16

사용자 요청으로 최대출력 점화 하한을143에서 **150기준틱**으로 조정했다.
실행 소스에서 변경한 설정은 `MIN_DIM_BASE` 하나이며 보정2는 유지한다.
최대출력 점화 위상은 **(150+2)/332 = 152/332**이다.
입력곡선133~308을 계산한 뒤150보다 이른 요청만150으로 제한한다.
저출력 동작,ON/OFF 경계,기본 펄스폭,종료 여유,동기화 및 보호 기능은 동일하다.

| 명목25µs 타이머 예시 | 약60Hz /333틱 | 50Hz /400틱 |
|---|---:|---:|
| v4.8(143) 최대출력 점화 | 3.625ms /145틱 | 4.375ms /175틱 |
| **v4.9(150) 최대출력 점화** | **3.800ms /152틱** | **4.575ms /183틱** |
| v4.8 대비 추가 지연 | 175µs | 200µs |
| 최대출력 게이트 폭 | 0.500ms /20틱 | 0.600ms /24틱 |
| 게이트 종료 후 다음 검출까지 | 4.025ms /161틱 | 4.825ms /193틱 |

PB2 검출 상승엣지 기준의 정수 반올림 예시이며 실제AC0V 기준은 아니다.
150은 고정 지연 틱 수가 아닌332분모 위상 기준값으로,50/60Hz 모두 실측 반주기에 비례한다.
기존143틱보다 출력 상한을 조금 낮추는 방향이며 실제 DC전압 변화량은 예측하지 않는다.

## 검증 및 파일

- 새 소스 클린 빌드: Flash2134/8192바이트,정적RAM46/512바이트(스택 별도).
- ISR133 + 원자구간32 + 진입 등10 =175/200CPU클럭.
- 현재 소스를 포함한 호스트 회귀시험 재컴파일 및 통과.
- ADC1024단계의150 제한,주파수/클럭/입력60조합,검출폭60조합,응답24조합 통과.
- 반주기250~500틱 × 위상150~308(159단계)의 종료 여유 및 점화 순간 노이즈 차단 통과.
- AVR 바이너리 통합시험 42/42조건 통과(exit 0): 50/60Hz, CPU 6.8/8.0/9.2MHz, 입력 및 검출폭 조합.
- Intel HEX 체크섬/주소/EOF 및 ELF에서 추출한 BIN과 2134바이트 일치 확인.
- 실제MCU 기록 및150틱의 실물 부하 시험은 수행하지 않았다.
- 시뮬레이터의Timer1 모델 보완과 아날로그 부하 미모사 한계는 test/README 참고.

SmartProg용: `R_Type_2+150Tick_Cap_Min308_Guard16_50_60Hz_v4_9.HEX`.
직전143틱은 `backup/v4_8_before_cap150/`에 보관했다.
퓨즈E2/DF/FF는 동일하다. HEX에는 퓨즈가 포함되지 않으며 기록 후Verify로 읽기 비교한다.
