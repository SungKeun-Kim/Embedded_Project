# v4.7 — 최대출력140기준틱 및50Hz 검토

2026-10-16

사용자가168기준틱(v4.6) 시험에서 최대출력 DC전압이 약25V 낮게 나온다고 보고했다.
이에 요청한 **140기준틱**으로 최대출력 제한을 완화한다. 보고된25V의 정확한 비교 기준,
측정점,부하전류,평활용량은 확정하지 않았으므로 전압 회복량을 선형 비례로 계산하지 않는다.

## 변경

- 최대출력 지연 하한 `MIN_DIM_BASE`:168 -> **140**.
- v4.6보다28기준틱 빠르고,v4.5(133)보다7기준틱,최초128보다12기준틱 늦다.
- 보정2를 포함한 최대출력 점화 위상: **142/332 = 반주기의 약42.77%**.
- v4.5 입력곡선133~308을 계산하고140보다 이른 요청만140으로 제한한다.
- 저출력/중출력 곡선,최저출력308,기본펄스20,종료여유16 및 최소여유 보정 유지.
- ADC899 ON/900 OFF,부팅1초,8반주기 동기화,반주기별 출력상승 제한,신호 손실 차단 유지.
- 퓨즈E2/DF/FF,Timer1 분주/TOP,핀 배치 변경 없음.
- 50Hz용 고정140틱 지연이나 별도 주파수 분기는 추가하지 않는다. 기존 실측 반주기 비례 계산을 사용한다.

140은332분모의 **위상 기준값**이다. 실제50Hz에서140×25µs만 기다리는 설정이 아니다.

```text
점화틱 = round(실측 반주기틱 * (140+2) / 332)
기본 게이트폭틱 = round(실측 반주기틱 * 20 / 332)
최종 종료틱 = min(점화틱+기본폭틱, 실측 반주기틱-종료여유틱)
```

## 명목25µs 타이머의 시간 비교

모든 시간은 **PB2 검출 상승엣지 기준**이다. 실제AC0V와 검출 엣지의 오차가 자동 보정되는 것은 아니다.

| 항목 | 약60Hz /333틱 | 50Hz /400틱 |
|---|---:|---:|
| v4.5(133+2) 최대출력 점화 | 3.375ms | 4.075ms |
| v4.6(168+2) 최대출력 점화 | 4.275ms | 5.125ms |
| **v4.7(140+2) 최대출력 점화** | **3.550ms /142틱** | **4.275ms /171틱** |
| v4.6 대비 앞당김 | 0.725ms | 0.850ms |
| v4.5 대비 추가 지연 | 0.175ms | 0.200ms |
| v4.7 최대출력 게이트 폭 | 0.500ms /20틱 | 0.600ms /24틱 |
| v4.7 최대출력 게이트 종료 | 4.050ms /162틱 | 4.875ms /195틱 |
| 게이트 종료 후 다음 검출까지 | 4.275ms /171틱 | **5.125ms /205틱** |
| 최저출력 점화(기존 유지) | 7.775ms /311틱 | 9.325ms /373틱 |
| 최저출력 게이트 폭(기존 유지) | 0.150ms /6틱 | 0.200ms /8틱 |
| 최저출력 종료 후 다음 검출까지 | 0.400ms /16틱 | 0.475ms /19틱 |

위 표는 정수 반올림 예시다. 이상적 위상비로 계산한140과168의 차이는
정확한60Hz에서약0.703ms,50Hz에서약0.843ms이며 양자화 때문에 표와 조금 다르다.

## 50Hz에서 기대할 수 있는 동작

**정상적인 ZC 입력을 전제로,50Hz에서도 같은 위상을 유지하며 동작할 근거가 있다.**

1. 50Hz 반주기는10ms,명목400틱으로 허용창250~500틱에 들어간다.
   CPU6.8~9.2MHz(명목8MHz의±15%) 시험 가정에서도340~460틱으로 창 안이다.
   이 범위는 시험 가정이며 MCU의 전 온도/전압 정확도 보증이 아니다.
2. 점화 지연과 펄스폭이 실측 반주기에 비례한다. 50Hz 최대출력 펄스는600µs로,
   60Hz보다 짧아지지 않는다. 종료 후 다음 검출까지5.125ms의 여유가 있다.
3. ZC HIGH 허용 상한은반주기/4,50Hz에서명목2.5ms이다.
   최대출력 점화4.275ms보다 앞서 LOW 복귀 확인이 끝나도록 설계되어 있다.
   HIGH 고착/과도한 폭/점화 순간 HIGH는 기존대로 차단한다.
4. 50Hz에서340~460틱을1틱씩 훑은 정상상태 계산 결과:

| 항목 | 최대출력140 | 최저출력308 |
|---|---:|---:|
| 검출 후 점화 | 4.265~4.290ms | 9.324~9.350ms |
| 게이트 폭 | 588~616µs | 156~206µs |
| 게이트 종료 후 다음 검출까지 | **5.097~5.147ms** | **468~496µs** |

이 계산은 정상 반주기를정확히10ms로 환산한 정수 양자화 모델이며,실제 부하/검출회로의 파형은 모사하지 않는다.
전체 허용주기250~500틱과169개 위상에서는 별도 호스트 시험으로 주기 단축 허용량+2틱 지터 후의 종료 여유도 검사한다.

## DC전압과 흔들림에 남는 한계

140은168보다 일찍 점화하므로 최대출력을 회복하는 방향이다. 그러나 정류·평활·트라이악 유지전류·부하·피드백이
함께 작용하므로25V 중 몇V가 회복되는지,기존 고출력 흔들림이 재발하는지는 코드만으로 확정할 수 없다.

50Hz에서는 전파정류의 충전 기회 간격이60Hz의약8.33ms에서10ms로 늘어난다.
일정 부하전류와 같은 평활용량의 단순 방전 모델 `ΔV≈I/(2fC)`에서는50Hz 리플이60Hz보다약20% 커진다.
이는 현재 위상제어/비선형 부하의 실측 예측값이 아닌 근사 추론이다.
제조사 설계에서도50/60Hz의 평활용량 조건을 구분한다.
[TI TIDUEQ2 p.14 식7~10](https://www.ti.com/lit/ug/tidueq2/tidueq2.pdf).

따라서 점화 타이밍이 정상이어도50Hz에서DC전압 골이나 피드백이 달라질 수 있다.
최저출력의 짧은 펄스에서 실제 래치/유지전류 충족 여부도 실보드 확인 대상이다.
MOC3021 계열 제조사도 펄스폭과 트리거 전류 특성을 별도로 제시한다.
[onsemi 데이터시트 Figure5](https://www.onsemi.com/pdf/datasheet/moc3023m-d.pdf).

## 검증 기록

- 클린 빌드: Flash2134/8192바이트,정적RAM46/512바이트(스택 별도).
- 새 ELF 시간 검사: ISR133 + 원자구간32 + 진입 등10 =175/200CPU클럭.
- 새 소스를 포함한 호스트 시험:주파수/클럭/입력60조합,검출폭60조합,응답24조합 통과.
- 허용주기251단계×위상169단계,ADC1024단계의140 제한 및 v4.5 하단곡선 일치 통과.
- 최초 호스트 시험은47Hz/CPU8.8MHz/반주기468틱에서 실패했다. 기존 시험이 매반주기200틱에 넣는 노이즈가
  이번140위상의 점화200틱과 정확히 겹쳤고,펌웨어가 의도대로 해당 반주기를 차단한 것이 원인이었다.
- 연속 점화 시험의 노이즈를점화 이전에 배치하고,점화 순간 노이즈는333/400/468틱에서
  해당 반주기 차단 및 다음 정상 반주기 복구를 별도 검증했다. 펌웨어의 노이즈 보호는 변경하지 않았다.
- 현재 시험 소스를 재컴파일한 simavr에서 새 AVR 바이너리42/42조건 통과,종료코드0.
  50/60Hz × CPU6.8/8.0/9.2MHz × 최대/최소출력 × 검출폭3종의36조건과,
  ON경계4390mV 입력6조건을 확인했다. 로그는 배포 패키지에 포함한다.
- simavr의Timer1 CTC 모델 보완과 아날로그 부하 미모사 한계는 test/README 참고.
- 실제 MCU 기록,실제50Hz 부하 시험은 수행하지 않았다.

## 현장 확인

같은 전원·부하에서v4.6(168)과v4.7(140)의 최대DC전압과 흔들림을 비교한다.
표시80/83/90/100 부근의DC평균뿐 아니라 가능하면최저/최고값을 기록한다.
50Hz에서는 최저출력 연속점화,최대출력DC리플,START/STOP/재START 및 부하 오류 유무를 확인한다.
파형을 기록할 때PB2 검출과PB0 게이트를 함께 보면 타이밍 문제와 부하측 문제를 구분하는 데 도움이 된다.

직전v4.6 소스/HEX/시험은 `backup/v4_6_before_cap140/`에 보관한다.
