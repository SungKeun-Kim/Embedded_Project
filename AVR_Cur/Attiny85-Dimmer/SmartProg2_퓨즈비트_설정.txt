SmartProg2 퓨즈비트 설정 가이드 - ATtiny85
================================================================================

[퓨즈비트 설정값]
─────────────────────────────────────────────────────────────────────────────
LFUSE (Low Fuse):   0xE2
HFUSE (High Fuse):  0xDF
EFUSE (Extended):   0xFF
─────────────────────────────────────────────────────────────────────────────

[설정 의미]
─────────────────────────────────────────────────────────────────────────────
LFUSE = 0xE2
  - 내부 8MHz 오실레이터 사용
  - 클럭 분주 없음 (CKDIV8 비활성화)
  - 시작 지연 시간 설정

HFUSE = 0xDF
  - SPIEN 활성화 (ISP 프로그래밍 가능)
  - EESAVE 비활성화 (칩 지우기 시 EEPROM도 지워짐)
  - BODLEVEL = 111: 브라운아웃 감지(BOD) 비활성화
  - 기존 문서의 2.7V 설명은 오류였음. 이번 수정에서 퓨즈 값은 변경하지 않음.

EFUSE = 0xFF
  - 셀프 프로그래밍 비활성화
─────────────────────────────────────────────────────────────────────────────

[SmartProg2 설정 순서]
─────────────────────────────────────────────────────────────────────────────
1. SmartProg2 실행
2. Device 선택: ATtiny85
3. "Fuse" 탭으로 이동
4. 퓨즈비트 값 입력:
   - Low Fuse:  E2
   - High Fuse: DF
   - Ext Fuse:  FF
5. "Write Fuse" 버튼 클릭
6. 확인 후 "Flash" 탭에서 hex 파일 업로드
   - 프로젝트 루트의 firmware.hex 사용
─────────────────────────────────────────────────────────────────────────────

[주의사항]
─────────────────────────────────────────────────────────────────────────────
⚠️ 퓨즈비트 설정은 칩의 동작 방식을 변경합니다
⚠️ 잘못된 설정 시 칩을 프로그래밍할 수 없게 될 수 있습니다
⚠️ 특히 클럭 소스 관련 설정은 신중하게 변경하세요
⚠️ SPIEN 비트는 절대 비활성화하지 마세요 (ISP 불가능해짐)

✓ 위 설정값은 platformio.ini와 일치하도록 최적화되었습니다
✓ 8MHz 내부 클럭으로 동작합니다 (board_build.f_cpu = 8000000L)
─────────────────────────────────────────────────────────────────────────────

[작업 순서]
─────────────────────────────────────────────────────────────────────────────
1단계: 퓨즈비트 먼저 설정 (위 값 사용)
2단계: firmware.hex 파일 업로드
─────────────────────────────────────────────────────────────────────────────

[최종 코드 사양]
─────────────────────────────────────────────────────────────────────────────
- Timer 주기: 명목 25μs (40kHz), Timer1 폴링
- 실제 반주기에 비례한 위상 제어: 50Hz/60Hz 공용 v4.5
- 출력 전력 범위: 실제 부하에서 측정 필요 (위상 비율과 전력 비율은 다름)
- 트리거 펄스: 기본60Hz 약500μs / 50Hz 약600μs, 최저출력에서는 약150/200μs 예시
- ADC 읽기: 명목 10ms 간격 (내부 RC 편차에 따라 실제 시간 변동)
- 상세 사양과 보드 시험: 코드_설명서.txt, 50Hz_60Hz_검증가이드.md
─────────────────────────────────────────────────────────────────────────────

[핀 연결 확인]
─────────────────────────────────────────────────────────────────────────────
ATtiny85 DIP-8:
  1 (RESET/PB5)  - ISP 프로그래밍용
  2 (PB3/ADC3)   - 아날로그 입력 (0.3~4.3V, 약 4.4V 이상 OFF) ✅
                   → 4.3V: 최소 출력 요구, 0.3V 이하: 최대 출력 요구
  3 (PB4)        - (예비)
  4 (GND)        - 그라운드
  5 (PB0)        - 트라이악 제어 출력 ✅
  6 (PB1)        - 동기화 상태 디버그
  7 (PB2/INT0)   - 제로크로스 입력 ✅
  8 (VCC)        - 5V 전원
─────────────────────────────────────────────────────────────────────────────
