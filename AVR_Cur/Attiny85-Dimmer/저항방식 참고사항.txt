================================================================================
  AC220V 60Hz 제로크로스 검출 — 저항 방식 (트랜스 T1 대체) 참고사항
  대상: Attiny85 Dimmer (PB2=ZVC, 폴링/INT0, Timer1 25us 상태머신)
  회로: R28/R29 22k+22k, EL354N, D8, R30||C8, R6 4.7k
================================================================================

■ 1. 회로 구성 요약
--------------------------------------------------------------------------------
  [AC 입력]
    L01 ── R29 (22kΩ 2W) ── EL354N LED ── R28 (22kΩ 2W) ── N01
    총 직렬 저항 44kΩ → If(피크) 약 7mA @ 220V

  [출력 / 스트레치]
    EL354N Pin4 ── R6 (4.7k) ── +5V
    Pin4 ── D8(Anode) ──|>|── ZVC ──→ PB2 (ATtiny85)
    ZVC ──┬── C8 (1nF, MLCC102) ── GND
          └── R30 (100kΩ) ── GND          ← R30과 C8은 병렬(GND), 직렬 아님

  ※ R30–C8을 직렬(ZVC─R30─C8─GND)로 두면 충전이 느려져
     25us High를 MCU가 인식하지 못할 수 있음 → 반드시 병렬.


■ 2. 트랜스 방식 vs 저항 방식
--------------------------------------------------------------------------------
  항목              12V 트랜스 (기존)        220V 저항 (신규)
  ─────────────────────────────────────────────────────────
  ZVC High 폭       ~375us (60Hz)          raw ~21us / 스트레치 ~50~100us
  상승엣지↔0V       ~190us 앞 (이론)       ~10us 앞 (이론, 스트레치와 무관)
  ZC_OFFSET(현재)   16틱 (400us)           0~1틱 (25~0us) 로 재조정 필요
  폴링(25us)        여유 큼                 raw만 쓰면 누락 가능 → 스트레치 or INT0
  절연              T1 + 옵토               옵토 출력만 (입력측은 상전압)
  발열              트랜스                  저항 (44k, 약 1W급 분산)


■ 3. ZVC 펄스 폭과 트리거(조광) — 서로 무관
--------------------------------------------------------------------------------
  - 펌웨어는 ZVC High "폭"을 쓰지 않고 "상승 엣지" 1회만 사용한다.
  - 트리거 시점 = 상승엣지 → ZC_OFFSET 대기 → minDim~maxDim 지연 → 500us 게이트
  - 펄스가 375us → 100us로 줄어도 minDim/maxDim "가용 범위"가 넓어지지 않는다.
  - 회로 변경 후 조정 대상: ZC_OFFSET (상승엣지와 AC 0V의 시간차 보정)
  - TRIGGER 500us, minDim/maxDim 캘리브는 주기(≈333틱@60Hz) 기준 → 보통 유지


■ 4. ZC_OFFSET (현재 코드)
--------------------------------------------------------------------------------
  const uint8_t ZC_OFFSET = 16;   // 16 × 25us = 400us

  동작: ZVC 상승엣지 검출 후 S_ZC_OFFSET에서 16틱 대기 → 이후 S_DELAY(조광)

  [저항 방식 예상값]
    220V 직결 + EL354N → 상승엣지가 0V보다 약 10us 앞 (이론)
    25us 틱 환산 → 0.4틱 → 실측/튜닝: 0 또는 1틱

  ※ D8 + R30||C8 스트레치는 "하강(폭)"만 늘리고 상승엣지 위치는 거의 변하지 않음.
  ※ 16틱 그대로 두면 0V 기준이 약 390us 늦어져 위상 어긋남.


■ 5. 펌웨어: 폴링 vs INT0
--------------------------------------------------------------------------------
  [현재]
    Timer1 ISR (25us): PB2 폴링으로 상승엣지 + 상태머신 전체
    INT0: 미사용 (PB2는 INT0 핀과 동일)

  [저항 + raw ZVC ~25us]
    25us 폴링으로는 엣지 누락 가능 → INT0 전환 또는 출력 스트레치 필요

  [권장 테스트 순서]
    1차: R30||C8 스트레치 + 기존 폴링 유지
    2차: 폴링 불안정 시 INT0(상승엣지) + Timer1 상태머신 유지
         - INT0: ZC 검출, MIN_ZC_PERIOD(7ms) 가드, state==IDLE일 때만
         - Timer1: ZC_OFFSET → DELAY → TRIGGER (기존과 동일)
    ※ 폴링 실패 시 C8 제거는 INT0용(raw ~25us)일 때만 검토.
       폴링 유지 목적이면 C8 유지(스트레치).

  [예전 INT0 불안정과의 차이]
    INT0에서 지연/트리거까지 처리하면 타이밍 어긋남 → ZC만 INT0, 시간축은 Timer1


■ 6. Timer1 폴링과 최소 펄스 폭
--------------------------------------------------------------------------------
  샘플 주기: 25us (OCR1C=24 @ 8MHz)
  안정 검출: High 폭 ≥ 50us 권장 (이론 최소 >25us)
  12V 트랜스 ~375us → 약 15샘플/펄스, 여유 큼
  220V raw ~21us → 경계/누락 가능
  스트레치 ~50~100us → 폴링 OK


■ 7. R30 / C8 튜닝 (60Hz, 폴링 유지 시)
--------------------------------------------------------------------------------
  R30 = 100kΩ, C8 = 1nF → τ = 100us (방전 기준)
  체감 High 폭 대략 80~100us (raw ~21us + 방전 꼬리)

  더 짧게: C8 = 470pF, R30 = 100k → τ ≈ 47us → ~55~70us
  더 길게: C8 = 1nF 유지, R30 조정


■ 8. AC220V + 오실로스코프 — 안전
--------------------------------------------------------------------------------
  ※ AC 220V와 MCU GND를 일반 오실로스코프 프로브 GND로 공통 연결 금지
     (접지 경로 통해 합선·감전·장비 손상 위험)

  [안전 측정]
    - 프로브 GND → MCU GND (5V)
    - 프로브 tip → ZVC (PB2)
    - AC 220V는 프로브에 연결하지 않음
    → 펄스 폭, 8.33ms 간격(60Hz) 확인 가능
    → AC 0V와 상승엣지 시간차는 직접 측정 불가

  [AC까지 보려면]
    - 차동 프로브, 입력 절연 오실로스코프, 또는 측정용 절연 트랜스 2차만 사용


■ 9. ZC_OFFSET 실기 튜닝 (오실로스코프 없이)
--------------------------------------------------------------------------------
  1) ZC_OFFSET = 1 (25us) 로 시작
  2) 최대 밝기(minDim 근처)에서 깜빡임·윙윙거림 확인
     - 불안정 → 0 또는 1 비교
     - 너무 늦게 점화 느낌 → ZC_OFFSET 감소 (1 → 0)
  3) 최소 밝기(maxDim 근처) 확인
  4) PB1 디버그 LED: ZC마다 토글, 누락 시 상시 ON(캘리브 실패) 등 확인
  5) 0틱 vs 1틱 중 밝기·안정이 나은 값 선택 (이론 ~10us → 틱 해상도 한계)


■ 10. 입력측 안전 (양산·PCB)
--------------------------------------------------------------------------------
  - L01 퓨즈 (250VAC)
  - MOV (275VAC급 등)
  - R28/R29: 금속산화막 무화염 2W, 2개 직렬로 고압 분담
  - 220V–5V PCB creepage/clearance (제품 등급에 따름, 3~6mm 이상 참고)
  - R2 (2.2k) 제거 — 전류 제한은 R28+R29만


■ 11. 부품 참고 (현재 회로도 기준)
--------------------------------------------------------------------------------
  R28, R29 : 22kΩ 2W (직렬 44kΩ)
  U2       : EL354N
  R6       : 4.7kΩ
  D8       : UF4007 (1N4148 등으로 대체 가능)
  R30      : 100kΩ (ZVC–GND)
  C8       : 1nF MLCC102 (ZVC–GND, R30과 병렬)
  출력     : ZVC → PB2 (7번 핀)


■ 12. 체크리스트 (저항 방식 전환 시)
--------------------------------------------------------------------------------
  [ ] R30–C8 병렬 배선 확인 (직렬 X)
  [ ] R28/R29 22k×2, R2 미실장
  [ ] ZVC → PB2 연결
  [ ] ZC_OFFSET 16 → 0 또는 1 로 변경 후 재튜닝
  [ ] 1차: 폴링 + 스트레치로 ZC 검출 확인
  [ ] 2차: 필요 시 INT0 + Timer1 분리
  [ ] 최대/최소 밝기 위상 안정 확인
  [ ] 60Hz: lastZcPeriod ≈ 333틱(8.33ms) 부근 확인 (선택)
