# v4.3 — START 및 볼륨 응답 개선

수정일: 2026-10-14

## 시험 결과와 변경 이유

사용자는 v4.2의 60Hz 부하 시험에서 최대·최소 출력은 괜찮았으나 START 및 볼륨 반응이 늦다고 보고했다. 메인 MCU는 볼륨이 50% 이상인데 전류 피드백이 없으면 에러를 발생시키며, 판정 시간은 사용자 추정 약0.5초다. 정확한 판정 시간과 START/전원 투입의 관계는 아직 확인되지 않았다.

이전 소스 `backup/pre_50_60hz/main.cpp`에도 `QUIET_START_CYCLES=50`, `SOFT_START_CYCLES=10`, `delay(50)`이 있다. 그런데 Timer1 설정에서 `TIMSK`를 덮어써 Timer0 인터럽트를 끈다. 설치된 ATTinyCore의 기본 `delay()`는 `micros()`에 의존하므로 이 상태에서는 의도한 50ms를 보장할 수 없다. 따라서 주석만 보고 이전 실사용 대기도 실제 2.5초였다고 단정할 수 없다. 이전 실사용 HEX와 이 소스가 동일한지도 확인되지 않았다.

v4.2는 Timer1로 정상적인 시간 간격을 적용해 2.5초 비점화와 0.5초 최소출력 유지를 실제로 수행했다. 이후에도 50ms마다 위상 기준10씩만 출력을 올려 최소→최대에 약0.8초가 더 필요했다. 이 동작은 메인 MCU의 피드백 판정과 맞지 않는다.

## 변경 내용

| 항목 | v4.2 | v4.3 |
|---|---|---|
| SG3525 비점화 대기 | 명목2.5초 | 제거 |
| 최소출력 고정 유지 | 명목0.5초 | 제거, 첫 점화 반주기만 최소출력 |
| 볼륨 ADC 갱신 | 명목50ms | 명목10ms |
| 출력 상승 제한 | ADC 갱신마다 위상 기준10 | 유효 반주기 예약마다 위상 기준10 |
| 최소→최대 상승 | 약0.8초 | 16반주기: 60Hz 약133ms / 50Hz 약160ms |
| 전원 투입 안정화 | 명목1초 | 유지 |
| 동기화 | 온전한 반주기8회 | 유지 |
| 최대/최소 위상, 게이트 폭, 종료 여유 | 136/290, offset2, pulse20, guard20 | 유지 |

`updateInput()`은 요구값 `targetPhase`를 갱신한다. `processEdge()`는 유효한 ZC마다 실제 적용 위상을 계산하고 예약 성공 시 `outputPhase`를 갱신한다. ADC 반복 호출만으로 상승 제한이 빨리 진행되지는 않는다. 예약 시각을 놓치면 해당 반주기를 건너뛴다. OFF 입력은 게이트와 예약을 즉시 취소한다. 이미 도통한 트라이악의 부하전류를 게이트만으로 강제 차단하는 기능은 아니다.

50Hz에서도 기다리는 원시 틱을 고정하지 않는다. 측정 반주기와 위상 기준값의 비율로 점화 시각, 게이트 폭, 종료 여유를 계산한다. ZC 검출 폭 검증과 신호 손실 시 비점화도 유지한다.

## 확인한 응답 범위

전원이 켜지고 동기화가 완료된 뒤 START를 입력하는 조건에서 소스 시험 및 실제 AVR 바이너리 모사 결과:

- 첫 게이트: START 후35ms 미만.
- 최대출력 위상의 게이트: START 후200ms 미만.
- 연속 출력 중 최소→최대 볼륨 변경: 소스 시험에서200ms 미만.
- 출력 감소: 다음 ADC 갱신 및 유효 반주기에 반영. 소스 시험에서35ms 미만.
- OFF: 다음 ADC 갱신 때 예약/게이트 취소. 명목10ms 간격이며 내부 RC 편차에 따라 달라진다.

게이트 출력 시각에 대한 검증이며, 실제 전류 피드백의 크기/발생 시각은 모사하지 않았다. 0.5초 내 피드백 오류가 사라졌다고 아직 보장할 수 없다.

전원 투입과 START가 동시에 들어오면 부팅1초와 ZC8회 검증이 먼저 적용되므로 0.5초 제한에 맞지 않는다. 부팅 대기는 사용자가 앞서 요청한 SMPS 안정화 목적이며 이번 SG3525 대기 제거와 구분하여 유지했다. 동기화가 유지된 일반 STOP→START에서는 부팅 대기를 반복하지 않는다.

## 검증 결과

- AVR 빌드 성공: Flash2030/8192바이트, 정적RAM46/512바이트. 스택 별도.
- 기존 주기/클럭/ADC60조합, 검출 폭60조합, 251주기×155위상 경계 및 누락/고착/복구/순환 시험 통과.
- 응답 시험24조합: 50/60Hz × RC−15/0/+15% × START 시점4종. START, 볼륨 상승/감소, OFF, 재START 통과.
- AVR 바이너리36조합: 50/60Hz × CPU6.8/8.0/9.2MHz × 최대/최소 입력 × 검출폭3종. OFF 부팅 후2초에 START,4초에 STOP,4.1초에 재START. 두 START 응답과 마지막1초의 정상 펄스 수/위상/폭/종료 여유 통과.
- ISR본문133클럭, 원자 구간36클럭, 진입 등10클럭을 합친 보수적 경로179/200클럭 이내.
- simavr의 Timer1 모델 보완 조건 및 아날로그 부하 미모사 한계는 `test/README` 참고.
- 이번 작업에서 보드 라이팅과 실제 부하 시험은 수행하지 않았다.

## 라이팅 및 재시험

파일: `R_Type_2+136Tick_Guard20_50_60Hz_v4_3.HEX` 또는 동일한 루트 `firmware.hex`.
MCU/퓨즈는 기존 ATtiny85, E2/DF/FF 그대로다. 직전 소스·HEX는 `backup/v4_2_before_response_update/`에 보존했다.

전원 안정화 후 볼륨50% 이상에서 START, STOP/START 반복, 운전 중 볼륨 상승/감소를 확인한다. 메인 MCU 전류 피드백 오류 유무와 최대·최소 출력의 깜빡임 재발 여부를 함께 기록한다. 가능하면 START/PB3 입력, PB0 게이트, 전류 피드백의 시간 관계를 측정한다. 전원과 START가 동시에 들어오는 운용인지도 확인한다.
