
This file describes fuse settings for ULTRASONIC controller

Fuse High Byte: NEVER TOUCH THIS BYTE

Bit Name  Bit No  Description                      Default                    Setting
S8535C      7     Select AT90S8535 compatibility   1 (unprogrammed)           1 (unprogrammed)
                  mode
WDTON       6     WDT always on                    1 (unprogrammed,           1 (unprogrammed)
                                                     WDT enabled by WDTCR)
SPIEN(1)    5     Enable Serial Program and Data   0 (programmed, SPI prog.   0 (programmed
                  Downloading                        enabled)
CKOPT(2)    4     Oscillator options               1 (unprogrammed)           1 (unprogrammed)
EESAVE      3     EEPROM memory is preserved       1 (unprogrammed,           1 (unprogrammed)
                  through the Chip Erase             EEPROM not preserved)
BOOTSZ1     2     Select Boot Size (see Table 93   0 (programmed)(3)          0 (programmed)(3)
                  for details)
BOOTSZ0     1     Select Boot Size (see Table 93   0 (programmed)(3)          0 (programmed)(3)
                  for details)
BOOTRST     0     Select Reset Vector              1 (unprogrammed)           1 (unprogrammed)
