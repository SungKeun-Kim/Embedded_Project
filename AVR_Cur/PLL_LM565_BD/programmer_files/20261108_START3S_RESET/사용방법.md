# PRO ISP 4 기록용 파일

2026-11-08, 두 MCU에 실제 기록하고 읽기 검증을 통과한 START 3초 복구 버전이다. PRO ISP 4에서의 기록은 아직 시험하지 않았다.

## 불러올 파일

| 연결 MCU | Flash에 불러올 파일 | 기록 데이터 크기 |
| --- | --- | ---: |
| ATmega8 | `FLASH/ATmega8_FLASH_20261108_START3S_RESET.hex` | 6,443바이트 |
| ATmega16A | `FLASH/ATmega16A_FLASH_20261108_START3S_RESET.hex` | 5,486바이트 |

두 파일 모두 표준 Intel HEX다. 호환성을 위해 데이터 레코드와 종료 레코드만 사용하며, 실제 주소별 Flash 데이터는 직전 검증본과 완전히 동일하다. 시작 주소는 0이다. 파일의 텍스트 크기와 위 기록 데이터 크기는 다르다.

## 기록 순서

1. REMOTE를 정지로 두고 연결한 MCU에 맞는 장치를 선택한다. 장치 서명을 확인하고, 서명 불일치를 무시하는 설정은 사용하지 않는다.
2. **현재 장치의 EEPROM을 먼저 읽어서 별도 파일로 저장한다.** 퓨즈와 잠금값도 읽어 기록해 둔다.
3. 해당 MCU의 파일을 **Flash 영역**에 불러온다. EEPROM 파일은 Flash 영역에 불러오면 안 된다.
4. 기록 과정의 Chip Erase가 EEPROM까지 지우는지 확인한다. 프로그램이 EEPROM 백업·보존·복원을 지원한다면 그 기능을 사용한다. 지원 여부가 불명확하면, 지운 뒤 2번에서 읽은 현재 EEPROM을 다시 기록하고 검증한다. **EEPROM 쓰기를 선택하지 않았다고 해서 Chip Erase 때 보존되는 것은 아니다.**
5. Flash를 기록한 뒤 Verify/읽기 비교를 실행한다. EEPROM도 보존 또는 복원됐는지 읽기 비교한다. 기존 장비에서는 퓨즈·잠금값을 변경하지 않는다.
6. 두 MCU가 이 버전인지 확인하고 장비를 시작한다. 기록 후 START 복구 동작은 아래 순서로 확인한다.

PRO ISP 4 소프트웨어 버전에 따른 실제 메뉴 이름은 확인하지 않았으므로, 위 설명은 수행할 작업 기준이다. HEX 파일에 퓨즈 설정이나 프로그래머 작업 순서는 포함되어 있지 않다.

## EEPROM 파일은 복원용 백업이다

펌웨어 업데이트를 위해 새 EEPROM 초기값을 넣을 필요는 없다. **기존 장치의 현재 설정을 보존하는 것이 기본**이다.

| MCU | 선택적 복원 파일 | 백업 시점 |
| --- | --- | --- |
| ATmega8 | `EEPROM_BACKUP/ATmega8_EEPROM_BACKUP_20261108_005851.hex` | 2026-11-08 업로드 전 백업 |
| ATmega16A | `EEPROM_BACKUP/ATmega16A_EEPROM_BACKUP_20261108_010304.hex` | 2026-11-08 업로드 전 백업 |

- 두 파일 모두 EEPROM 주소 `0x0000~0x01FF`, 총 512바이트다. EEPROM 메모리 영역에 시작 주소 0으로 기록한다.
- **이 파일을 만든 지금의 실시간 장치 내용은 아니다.** 마지막 업로드 백업과 바이트 단위로 동일하다.
- ATmega8 백업에는 기존 AD5280 코드 **233**이 들어 있다. 이후 자동 튜닝으로 저장값을 바꿨다면 이 백업을 기록할 때 그 최신값이 사라진다.
- 현재 EEPROM을 읽을 수 있으면 먼저 그 값을 보관하고 복원한다. 동봉 파일은 이 장비를 백업 시점으로 복원해야 할 때만 사용한다.
- 다른 발진기나 새 보드의 공통 초기값으로 사용하지 않는다. 기기별 설정·튜닝값이 달라질 수 있다.

## 적용된 동작과 확인

- 정상 STOP에서 START 약 3초: 자동 튜닝 시작, PWM 약 50%.
- 전체 튜닝 시간 약 1분 제한. 시간 초과 시 새 튜닝값을 저장하지 않고 직전 AD5280 값으로 복귀한다.
- 시간 초과 오류에서 REMOTE 정지 → START를 놓았다가 새로 약 3초 누름 → 부저 해제·STOP 복귀. 정상 STOP의 미세 출력은 유지한다.
- 과전류·AD5280 통신 실패·복구 통신 실패 등은 START로 해제하지 않으며 전원 재시작이 필요하다.
- 모의 시험 14개와 두 MCU 스택 검사를 통과했다. 실제 START 오류 복구 동작은 사용자 확인이 남아 있다.

## 업로드 완료 표시

기존 USBasp 스크립트는 검증을 마친 뒤 EEPROM의 별도 알림 표식을 기록하여 LCD에 `UPLOAD COMPLETE`를 띄운다. **이 패키지의 Flash 또는 EEPROM 백업 파일을 쓰는 것만으로는 해당 문구가 표시되지 않는다.** PRO ISP 4의 기록·Verify 성공 결과로 완료 여부를 확인한다. `ATMEGA8 ONLINE`은 통신에 따른 기동 알림이며 Flash 검증을 대신하지 않는다.

`manifest.json`에는 원본 백업 경로, 파일 SHA-256, 메모리 데이터 비교 결과, 읽어 둔 퓨즈값을 기록했다. 퓨즈값은 기록 이력이며 자동 적용용 설정이 아니다.
